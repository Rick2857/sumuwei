## 2. 不主张（写死；激活与文档一律照抄）

```text
· **不**主张"她不再重复同一件事"——只主张"约定有终态、结清后可被程序明确陈述"（A11 若未下降，如实记）
· **不**主张"她能判断他到底有没有到场"——判据只认用户报告 / 真实动作结果
· **不**主张"到期 = 失约"——到期只是时间过去（A5 有词表判据）
· **不**主张"约定一定被识别"——识别有门槛（A1），漏识别是**已知边界**
· **不**主张"这修好了 M11 的 `L-M11-40`"（越界承诺是措辞层问题，`DR-11` 下无守卫）
```

## 3. 证据与纪律

```text
· 每个门把证据写进 `artifacts/m10.1/<runId>/`（`manifest.json` 记 `wp` / `head` / `phases` / `counts`）；
· **先提交工具、再产出证据**（head 必须绑定产生它的那次脚本提交）；
· 真实库一律走**副本**（`cpSync` + 沙箱 env；源目录前后比摘要），**从不打开**生产库本体；
· 计数型判据必须自检**非零分母**（分母 0 ⇒ `MEASUREMENT INVALID`，不是 PASS）；
· 判据若要改 ⇒ 本契约修订 + 前后读数**都留**（旧读数不回写）。
```

④ `commitmentTokens` / `goalTokens` 缺省 0 与激活值 ⑤ 识别门槛与"漏识别是已知边界"
