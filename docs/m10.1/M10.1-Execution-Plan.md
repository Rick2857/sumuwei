## 0. 目标与非目标

```text
目标（可判定的三条）：
  ① 双方合意的约定能被识别并成为**承诺**（带可核对判据 + `dueAt`/`dueBasis`）
  ② 承诺有**终态**：达成 / 取消 / **到期**（新增 `COMMITMENT_EXPIRED`，不含失约指控）
  ③ 承诺的**当前状态与结清**能作为**程序事实**进 prompt；**已结清/已过期 ⇒ 明确"不要再提"**
非目标：
  · 不解决"她永不重复"（D12）；不判"他到底去没去"（只认报告）；不改历史（D10）；
  · 不新增外部能力；不改 Seed；不动 M10 的既有判定与标签。
```


## 3. R-26 的**对照判据**（这是本里程碑存在的理由，必须可判）

```text
对照实验（与 R-26 同一段真实对话的形状，生产副本 + 真模型）：
  档 A：**本里程碑之前**的行为（现状）        —— 期望：结清后**仍然提**（R-26 的读数 23 次）
  档 B：**本里程碑之后**（有承诺 + 结清事实）  —— 期望：结清后**不再提**（或显著下降）
判据形式：结清后 N=10 轮里"提及该约定"的轮数（档 A vs 档 B），**两条读数分列**，不做合成总分。
⚠️ 若档 B 没有下降 ⇒ **如实记"没有测出效果"**（与 M11 的 `L-M11-18` 同一纪律），不得改写读数。
```

## 4. 已知风险（先写下来，免得收口时才发现）

```text
① **漏识别**：识别有门槛（`D03`/`D04`）⇒ 有些约定不会被记下。这是**设计边界**，不是缺陷。
② **误识别**：把闲聊判成约定 ⇒ 靠"必须给出处 + 单方不算 + 含糊不算"三道闸（WP1/WP2 的负控）。
③ **到期语义的措辞风险**：一旦写进 prompt 的是"你失约了"就是**凭空指控** ⇒ WP3 有专门判据。
④ **两个额度叠加**：目标状态 + 约定状态可能一起挤上下文 ⇒ WP4 要断言"谁被丢、谁不可裁"。
⑤ **与 M11 慢路径的资源竞争**：两条慢路径同轮触发 ⇒ 需要"同轮只跑一条"或排队（WP5 判据）。
⑥ **时间口径**：相对时间（"明天"）跨零点 ⇒ `dueBasis` 必须记口径；WP3 有跨零点用例。
```
