## 4. 偏差与自纠（**如实登记，不回写**）

```text
D1 **流程错**：第一次「先提交 → 跑读数 → 再 rebase」⇒ rebase 改写提交 ⇒ 证据里的 head 成了**悬空提交**。
   纠正：在 rebase 后**重跑**同一批读数（head 落在 main 的后代上），悬空那批在下一个提交里移除。
   正确 SOP：`git rebase main` → 提交脚本 → 跑读数 → 提交证据 → **立刻** ff。**踩过两次**。
D2 **判据自匹配**（四次同形）："本脚本不开库"的 `includes('plugin-sql')` / 人审的禁词表 ——
   判据自己写在源码里 ⇒ 必然命中。修法：名字**拼出来**（运行时才成形）。
D3 **读数取错时刻**：长链门的 W5 在轨迹结束后才过滤滚动窗口 ⇒ 必然红。修法：**结清当场快照**。
D4 **空档判据**（`L-M10-65` 的形状）：真模型门的 L4 第一版写成 `已结清行 === 0 || (...)` ⇒
   模型没产出承诺时**短路成真**。修法：**分支** —— 没产出就由程序补齐一对，并把 `closureSource` 写进证据。
D5 **分母混入"合法的 0"**：真模型门的 L7 把"承诺行数"当非零分母 ⇒ 模型不配合时报**错**而不是报**读数**。
   修法：只放**结构上必然 > 0** 的分母，其余作为读数另报。
D6 **人审材料生成器的假阳性**：第一版拿单字结论（"该/不该"）做子串比对 ⇒ 卡片里到处是"该不该"。
   修法：可比的是**理由**（长文本）。**判据要比得动**，不然它只是在响。
```
