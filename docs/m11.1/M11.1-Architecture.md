# M11.1 实现候选架构

2026-10-02，IN PROGRESS。新增能力、迁移、Seed及Memory语义变更均为NONE；ADR-085与ADR-087的阈值、生命周期、20秒/单请求和300/800额度不变。本文件描述当前已接线的机制，不宣布阶段验收通过。

生产启动与轮后入口共用`reflection-runtime.ts`。调度器先捕获有界窗口、判合格事件与跳过事件；执行器收到窗口上界及合格事件身份集合，SQL同时限制范围、身份和条数。跳过原生`character`/旧别名`assistant`或工具来源不会楔死水位，也不会重新进入候选窗口。

执行器在请求前展开完整来源链，按原始对话事件去重、读真实会话、当前归因、用户/角色作用域及撤销集。模型实际支持与反例分别展开，反例不凑支持根数。提交前再次复核支持集合及版本；模型等待在事务外，审查/调整事件与折叠在短事务内原子完成。来源不可用时失败关闭，不以缺读数当成usable。当前资格适配的完整跨域矩阵尚未验收，不能由接线控制推导所有原域资格已覆盖。

输入身份来自捕获窗口中的不可变源节点，领域提交所生成的反思/调整事件不会反过来改变该身份。业务提交后、任务水位提交前崩溃时，重开仍能识别已提交身份，不再次请求模型或写业务事件。格式/传输/期限失败记failed且不推进水位；旧失败保留。运行器和调度器使用同一close fence与abort信号，关闭后零晚写另有事务内负控。

实际入模时，TurnGateway通过当轮回调重读当前可用增强与程序事实包。来源遗忘/撤回先挡本轮，再沿现有生命周期幂等补失效事件；不可读只挡当轮，不永久撤回。真实trace只描述当轮入模与最近任务结局。不会用全部历史failed行把已恢复状态永久渲染为失败。

候选provider仍发恰好一次既有OpenAI兼容POST。早期`reflection-prompt@2`明确可选字段省略、风险稳定建议与修订坐标约束；当前版本为下述prompt@4。事件的promptVersion与modelVersion记录真实prompt和配置模型。fetch与响应体都受同一个20秒期限，解析错误仍交内核判格式错误，不混为传输失败。各开发探针保留，当前没有完整语义PASS。

测量面分开记录模型语义选择、原域资格/根图、程序放行、实际packet与用户可见回复。独立真人金标不从程序根数回算。语义判定器@2采用完整分母、最差轮和冻结阈值；行为判定器采用独立场景、两轮聚类、A/B/C配对及逐槽/逐轮读数。未评分回复不能变成行为PASS。

配对采集先关闭单一基线库，再复制成A/B/C独立库，逐字核对全树摘要后打开。每个场景/轮自己的基线与对话/trace/事件身份分列。共享请求账本在出站前持久预约，失败和中断占分母；重复身份和1700上限均失败关闭。三组并行只等待极短的预约锁，不重试模型请求。原文、prompt、trace正文与密封key只进已验证ignore的local目录；公开证据保存必要元数据和哈希。

M10.1的WP4c与WP5已经交付。新联调使用真实Goal/Commitment提案、放行口、事件和投影，再走实际TurnGateway验证八种三预算组合。普通Goal理解解析约定草案仍返回unknown_field（commitment未入白名单）；这是交付边界中的真实FAIL，未接管M10.1修复。交付的约定桥直接映射路径可以合法创建承诺，程序结清后实际packet包含“已结清、不要再提”，反思不重启它。A12的生产约定慢路径/独立水位联调仍未交付，不能用脚本显式串行代替生产证明。
