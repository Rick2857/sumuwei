## 0. 口径

```text
① 契约判据 ≠ 读数。判据写"必须观察到什么"；读数写"这次观察到了什么"。
② 每个判据必须**可判**：要么有程序判据，要么明确标 `AWAITING HUMAN REVIEW`。
③ 正控非零：只证明"该拒的都拒了"不能证明链路可用（AGENTS.md §6.3）。
④ 非零分母：计数型判据必须自证"真的量到了东西"（AGENTS.md §6.8）。
⑤ 失败档不回写：FAIL / INVALID / NOT RUN 原样保留，修复后出**新**读数（TD-16）。
```

**通用拒收语义**：任何"不合格"的输入都必须得到**具名拒收码**，且**零副作用**
（不写世界账本、不写记忆、不写域事件、不推进水位、不入模）。

## 1. 身份与词汇（`S8-A01` – `S8-A06`）

| 编号 | 判据 |
|---|---|
| `S8-A01` | 提交身份是 `story:<storyId>@v<ver>#<runId>.e<revision>`，且**可解析回原样**（读回逐字段相等） |
| `S8-A02` | 观测身份是 `story:<storyId>@v<ver>#<runId>.<eventId>`，且每条观测**恰好**映射到一条 `parent_commit_id` |
| `S8-A03` | **一次提交的 N 个可见条目只算 1 个根**（`rootKey` 去重后计数；N ≥ 1 时根数恒为 1） |
| `S8-A04` | `EvidenceKind` 旧四值语义**逐字不变**；新增 `story_event` 只做追加；旧数据解码与折叠结果不变 |
| `S8-A05` | `sourceConversationEventIds` **仍然只指对话**；故事引用只能走 `sourceStoryRefs` |
| `S8-A06` | 故事来源的 `experienceScope` 在记忆 / 反思 / 上下文 / 习惯四处**都被保留**，不升级为 `reported` 或外部事实 |

## 2. 来源安全（`S8-A07` – `S8-A12`）

| 编号 | 判据 |
|---|---|
| `S8-A07` | 故事事实**不可能**写成 `conversation_events`：`canWriteStoryFactAsConversationEvent() === false` **且**构造器对 `sourceKind='story_fact'` 的声明**真的抛错**（负控，不是"没人这么写"） |
| `S8-A08` | `canSupportExternalFact('STORY_OBSERVATION') === false`（模拟结局**永不**支持"现实中已录取"这类结论） |
| `S8-A09` | 未选分支 / 隐藏节点 / 作者后台设定 / 模型虚构事件：**无账本行** ⇒ 读取口 `story_root_unconfirmed` / `story_root_invisible` 拒收，状态与习惯**零变化** |
| `S8-A10` | 错 `storyVersion` / 跨 `runId` / 跨用户 / 不存在提交：分别得到**具名**拒收码，且不互相混同 |
| `S8-A11` | 客户端自报"已合作 / 属于某用户 / 这是第二次会话"的字段**一律不被采信**（服务端绑定字段只能由服务端写） |
| `S8-A12` | 循环 lineage 与超限遍历**仍然拒收**（`lineage_cycle` / `lineage_limit_exceeded` 不变） |

## 3. 独立性与门槛（`S8-A13` – `S8-A18`）

| 编号 | 判据 |
|---|---|
| `S8-A13` | `rootCount` = `rootKey` **去重**后的个数；派生路径（观测/记忆/领域事件/反思）**不加票** |
| `S8-A14` | `conversationCount` = **不同** `interaction_ref` 的个数；两个 `runId` / 两次 replay / 两个节点 / 两份快照**都不** +1 |
| `S8-A15` | 门槛逐字：**≥ 3 独立根 · ≥ 2 真实会话 · 未解决冲突 = 0**；任一条不满足 ⇒ 具名拒收（`insufficient_roots` / `insufficient_conversations` / `conflicting_support`），零采纳 |
| `S8-A16` | 纯故事经历（无服务端确认的真实交互）**不能**满足 `S8-A15` 的会话条件 —— 如实拒收，不绕门槛 |
| `S8-A17` | 模型**不能**填 `rootCount` / `conversationCount` / "这是独立证据"（提案里出现即拒收） |
| `S8-A18` | 没有故事输入的**旧对话链**：计数语义与行为**逐字保持**（回归判据） |

## 4. 状态（`S8-A19` – `S8-A24`）

| 编号 | 判据 |
|---|---|
| `S8-A19` | 合法实际合作 ⇒ Affect 产生**非零**预期更新，且提案可追到**原始故事根**（`commit_id`） |
| `S8-A20` | `MAX_AFFECT_DELTA_PER_EVENT = 0.25` **不放宽**：越界提案被拒（正控/负控各一次） |

| `S8-A23` | 隐藏作者设定 / NPC 评价冒充用户 / 重复提交 ⇒ **零额外**状态变化（同一次提交重复消费 ≤ 1 次影响） |

## 5. 反思、采纳与入模（`S8-A25` – `S8-A30`）

| 编号 | 判据 |
|---|---|
| `S8-A25` | 故事结果触发**可达**且**确定性**（第七种触发 `story_outcome`）；**不**伪造 `GOAL_COMPLETED` 等领域事件 |
| `S8-A26` | 窗口有界：≤ 50 条 / 每条 ≤ 300 码点；超界 ⇒ `windowTruncated = true`（不假装看全） |

| `S8-A29` | 入模记录的是**裁剪后实际入模**的 slot / revision / 有效来源 / section（**不是**候选数量）；额度不足 / 未启用 / 来源失效 ⇒ 如实"未入模" |
| `S8-A30` | 只更新**已有三个槽位**；`scope` 只有 `current_character_user`；不新增槽、不改 Seed、不动信任/人格/用户事实/世界事实 |

## 6. 生命周期（`S8-A31` – `S8-A36`）

| 编号 | 判据 |
|---|---|
| `S8-A31` | 每个合格提交对**每个**消费者**至多一次**已提交影响（重试 / 重放 / 补扫均不重复加状态） |
| `S8-A32` | 世界已落盘而角色未消费 ⇒ 重启恢复**不漏**；角色已提交而水位未推进 ⇒ 恢复**识别既有结果** |
| `S8-A33` | 失败**不**提前推进成功水位 |

| `S8-A36` | 撤回认知使用资格后：旧反思/槽位**不再入模**；replay / 换 run / 重启**不复活**；新合法反馈走**新候选** |
