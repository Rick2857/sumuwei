### 2.1 ✅ 已完成的那一个（预检）

**为什么先做它**：它守的是这条通道**最要紧的判据**（15 条具名拒绝，全部在调模型之前）。

**它的三段式形状**（这一轮把负控**分成两件不同的事**）：

```text
① 正控（系统按设计工作）      ：20 项全过 ⇒ PASS
② 负控（**系统**的真破坏）    ：15 条真不合格的输入各自被**正确具名**地拒
③ 量具有效性（**量具**的负控） ：把期望码表**故意错位一条** ⇒ **必须**报 20 项失败
④ 恢复                        ：撤掉错位 ⇒ 回到 0 失败
⑤ `measured_count = 20`       ：不许"零断言全绿"
```

⚠️ ② 与 ③ 是两件事，**两个都要有**：

```text
② 证明**被测对象**会在该拒的时候拒
③ 证明**判据本身**会在不该过的时候不过 —— 没有它，"全绿"可能只是因为它什么都没在比
```

实测读数（三段式一次跑完）：
```text
正控 20 项 / 失败 0
错位后失败数 = 20（> 0 ⇒ 判据不是恒真的）
恢复后失败数 = 0
verdict = PASS · EXIT 0
```
