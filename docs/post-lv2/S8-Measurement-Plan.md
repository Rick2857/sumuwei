## 1. 量具设计（**每个新判据都要走三段式**）

纪律（AGENTS.md §6.7）：**正控**（合法输入 ⇒ 量具安静）· **负控**（注入假象 ⇒ **必须响**）·
**恢复**（放回真实实现 ⇒ 重新安静）。只做正控的量具与"什么都不检查"在输出上**无法区分**。

| # | 量具 | 正控（必须安静） | 负控（必须响） | 恢复 |
|---|---|---|---|---|
| `M1` | 提交身份解析器 | 真实 `commit_id` 解析回四个分量 | 改一位 revision / 去掉 `@v` / 换成分隔符 ⇒ 判不可解析 | 还原字符串 ⇒ 再次通过 |
| `M2` | 观测 → 提交映射读取口 | 真实已提交提交的可见条目 ⇒ 命中其父提交 | 手工插入一个**可见集合里没有**的条目 ⇒ `story_root_invisible`；**无行**（隐藏分支）⇒ `story_root_unconfirmed` | 删掉注入行 ⇒ 回到命中 |
| `M3` | 因果去重键（`rootKey`） | 一次提交的 3 个观测 + 其派生的记忆/域事件/反思 ⇒ `rootCount = 1` | 把派生节点伪造成"独立根"（缺 `sourceStoryRefs` 的直连对话根）⇒ 计数**必须**分辨（该 +1 就 +1，不该 +1 就不 +1） | 还原引用 ⇒ 回到 1 |
| `M4` | 真实会话映射器 | 两条 `user_choice` 提交、两个不同 `interaction_ref` ⇒ `conversationCount = 2` | 两个 `runId` 同一会话 / 同一会话两次 replay / 无 `interaction_ref` 的 `system` 提交 ⇒ **不** +1 | 还原 ⇒ 回到 2 |
| `M5` | 故事资格判定器（Affect） | 合法实际合作提交 ⇒ 合格 | 隐藏条目 / 错版本 / 跨 run / 已撤回 / 不存在 ⇒ 各自具名拒收 | 还原 ⇒ 合格 |
| `M6` | 关系资格判定器 | 绑定当前真实用户的 `user_choice` ⇒ 合格 | NPC 台词 / 作者预设夸奖 / 剧情内信任 / 他人会话 ⇒ `story_feedback_not_real_interaction` | 还原 ⇒ 合格 |
| `M7` | 故事触发检测器（`story_outcome`） | 一条合格已提交故事结果 ⇒ 产出**恰好一条**触发 | 未提交/未消费/已撤回结果 ⇒ 0 条触发；伪造 `GOAL_COMPLETED` 的路径**不存在**（静态断言） | 还原 ⇒ 再次一条 |
| `M8` | 实际入模读取器 | 采纳成立且额度足够 ⇒ 读到 slot/revision/来源/section | 额度 0 / 采纳未启用 / 来源已失效 ⇒ 读不到（且**不**假报） | 还原额度 ⇒ 读到 |
| `M9` | 撤回读时屏蔽 | 未撤回 ⇒ 原样 | 撤回后：账面投影**仍**在（不物理删），但**读时**资格为无效 ⇒ 依赖它的反思/槽位不再入模；replay **不能**绕过 | 撤销撤回标记（仅测试内）⇒ 恢复 |
| `M10` | 消费幂等计数器 | 同一提交重试 3 次 ⇒ 影响计数 = 1 | 删掉消费身份/水位 ⇒ 恢复时**重复**消费 ⇒ 必须被断言捕获 | 还原 ⇒ 回到 1 |
| `M11` | 世界账本量具自检 | 提交数 / 观测数 / 根数 / 会话数**全部 > 0** | 把语料换成空集 ⇒ `MEASUREMENT INVALID`（**不是** PASS） | 还原语料 ⇒ 重新非零 |

**`M11` 是本工作包的"非零分母"闸**：任何汇报"非法来源采纳 = 0"的读数必须先证明
`分母 > 0`（扫过多少提交 / 多少根 / 多少候选），否则报 `MEASUREMENT INVALID`。
