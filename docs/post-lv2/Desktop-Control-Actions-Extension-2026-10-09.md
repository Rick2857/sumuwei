## 实现

| 动作 | 参数与执行 |
| --- | --- |
| `double_click` | `window/index/name`，同单击的控件与前台核对，固定左键两次 |
| `switch_app` | 完整 `window` + 数字整数 `handle`，精确定位并验证实际前台句柄 |
| `launch_app` | 应用目录中的完整 `name`，精确匹配后提交启动，无模型路径或命令参数 |
| `desktop.inspect.apps` | 只读系统应用目录，可按 `query` 过滤，帮助确认启动名称 |

决策器、重新规划器、工具目录与最终回复同步使用新协议。应用/窗口目标在执行时重新解析，不靠猜测标题或模糊应用名。读回明确区分“启动请求提交”和“窗口出现”。默认开关仍关闭，当前正式环境已有桌面权限设置保持原样。
