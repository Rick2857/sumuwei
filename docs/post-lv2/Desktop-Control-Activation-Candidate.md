# 桌面控制：生产激活候选（2026-10-05）

> ⚠️ **本文件不激活任何东西**。它是"如果要开，开的到底是什么、怎么开、怎么回滚"的候选说明。
> 激活需要**用户显式裁定**（先例：[`ADR-105`](../adr/ADR-105-role-tool-decision-activation.md) /
> `ADR-048` / `ADR-065` 都是"只做状态修订"的独立载体）。

---

## 1. 现在的状态

```text
代码缺省：CHARACTER_DESKTOP_INSPECT_ENABLED = false
          CHARACTER_DESKTOP_OPERATE_ENABLED = false
⇒ 桌面两项**恒登记、未授权**：用户显式要求会得到一条可审计的 `permission_denied`
  （模型据此如实说"没启用"），而**不是**"装作没听懂"（先例 ADR-045 D-12）。
⇒ 与本次改动前**逐字**同形的行为：普通聊天里没有任何桌面动作。
```

本轮已完成的（**不是**激活）：
```text
独立运行时已装好（固定 windows-mcp 0.8.7）
离线硬门 43/0 · 实机只读门 14/0 · 角色决策矩阵 18 项未覆盖 0
真实操作档 = NOT RUN（需用户在场）
```

---

## 2. 激活要改什么（**只有两行**）

```dotenv
# .env（**只追加**，不改任何既有行）
CHARACTER_DESKTOP_INSPECT_ENABLED=true
CHARACTER_DESKTOP_OPERATE_ENABLED=true
```

⚠️ 建议**分开裁定**：
```text
① 只开 inspect：她可以"看一眼屏幕"。R1（读）· 不产生任何动作。
② 再开 operate：她可以点一次 / 输一次（**任务级 R2**）。这一步会动用户的鼠标键盘。
```

---

## 3. 激活会带来什么（逐条，不含"或许"）

```text
· 工具目录里多两行（`desktop.inspect` / `desktop.operate`），角色决策可以提出它们。
· 每提出一次桌面查看：一个新 Python 进程（≈2.0s）+ 一段有界的桌面文字进当轮 prompt。
· 每提出一次桌面动作：同一个进程 + **真实**鼠标/键盘输入（会抢焦点）。
· 账本 / trace / 开发者面**只多引用**（无正文）；输入的正文经私有暂存，不进账本。
· 记忆 / 关系 / 情绪 / 信念：**一个字节都不写**。
· 任务级风险额度：打开 `operate` 后，任务里的 R2 档整体可用（见 `L-DC-05`）。
```

---

## 4. 回滚（一行）

```dotenv
# 删掉那两行，或改回 false
CHARACTER_DESKTOP_INSPECT_ENABLED=false
```
```text
⇒ 权限不授予、适配器不构造、任务能力清单里没有它们 ⇒ 回到本次改动前的行为。
⇒ **不删**独立 venv（回滚不删环境：删了下次再开就要重装）。
```

---

## 5. 激活前**建议**先做的一件事

```bash
# 要你在场（它会真的动鼠标键盘；目标由本门自己创建，跑完收掉）
pnpm desktop-control:act --i-am-here
```
```text
它做两件事：在一个**本门自建的临时记事本**里真输入一段哨兵文本（然后读回，
确认那段文字真的落到了控件里）、再真点一次同一个控件。
⇒ 这一条能把 `L-DC-09` 从 NOT RUN 变成一条真实读数。
```

---

## 6. 激活后**仍然**不主张的（与激活无关，写在这里是防误读）

```text
· 不主张"她能代替用户操作电脑"：闭集只有 click / type，没有快捷键 / 滚动 / 拖拽 / 启动应用。
· 不主张"任何窗口都能看"：绘图类界面读不到（L-DC-03）；提权窗口不保证（L-DC-04）。
· 不主张"完全后台"：她与用户**共用**桌面（会抢焦点）。
· 不主张"没有隐私代价"：桌面文字（含她自己的界面）会进当轮 prompt（L-DC-07/L-DC-10）。
```
