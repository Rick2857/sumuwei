## 使用与边界

下次正常启动后，在 QQ 本人私聊发送普通 PNG/JPEG 图片，或通过皮套已有图片上传入口发图，即可自然接着聊天。后续文字追问会重新带上近期原图；无须重复描述，也无须规定发图顺序。暂时不支持 GIF/WebP、闪照、视频、语音消息或聊天文件。

近期原图保留是有界上下文，不是永久无限视觉记忆。图片可能看不清，模型也可能判断错误；缺失原图的指令约束不等于逐句机械验证。自然生产首用、真实 QQ 图片 URL 行为、网页上传与朗读体验仍需观察，隔离真模型短链不能代替这些读数。

本轮配置启用：用户回复“启用不过不用再重启共存入口直接关闭即可”，仅追加 `CHARACTER_IMAGE_INPUT_ENABLED=true` 并读回；没有 schema 迁移。检查时原共存核心 PID 51732 与编排者 PID 41752 均已退出，6751 / 6752 / 12394 无监听，生产租约未被持有，因此没有可继续正常停机的运行进程。原 owner 无 `cleanClose` / `endedAt`，不补造关库成功，也不通过重启制造读数；按用户要求维持入口关闭。机器配置记录为 `artifacts/post-lv2/image-input/activation-config.json`。回滚关闭开关，下次正常启动时生效，历史附件与账本保留。
