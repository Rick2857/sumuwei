# 后 Lv2 媒体来源 / 交付 / 取消契约（Media Source, Delivery & Cancellation Contract）

状态：**ACCEPTED / DESIGN FROZEN**。日期：2026-10-03。载体 ADR：[ADR-091](../adr/ADR-091-post-lv2-world-boundary-and-story-source.md)（§4/§5）。
计划：[Post-Lv2-Storyline-Embodiment-Realtime-Plan-2026-10-02.md](../research/Post-Lv2-Storyline-Embodiment-Realtime-Plan-2026-10-02.md) §6–§8。
范围：**S2 身体 / S3 基础语音 / S4 持续对话协调**。本契约只冻结判据与阈值，不产生读数。

---

## 1. 三本账（**不得**互相代替）

```text
生成账   LG 回复守卫后的文本 / SpeechIntent        replyId, segmentId
合成账   TTS 服务侧"合成完成"                      audioId, synthesizedAt
交付账   **客户端上报**的播放事实                  queued/started/finished/cancelled, playedFrom/playedTo, deliveryUnknown
```

| 禁止的等价替换 | 为什么 |
|---|---|
| `LG 已生成` ⇒ `已播出` | 生成不等于到达；字幕与语音可能都没发生 |
| `TTS 合成完成` ⇒ `已播出` | 合成完成只证明有音频文件 |
| `播放确认` ⇒ `真人听懂了` | 播放确认只证明**客户端报告已播放** |
| 断线 ⇒ `已播放` | 断线时状态**必须**是 `unknown` |

## 2. 判据

| ID | 判据 | 量具 |
|---|---|---|
| **M1** | 至少 6 类任务状态（listening / 已接收并处理 / tool.running / 音频实际播放 / 当前有效 Affect / interrupted·failed·idle）**由真实 LG 状态触发**，逐项可对账 | 状态事件 ⟷ 表现消息同 case 读回 |
| **M2** | ≥ 4 类情绪表现；表情**带版本来源**；缺对应资源时**回到中性**，不卡住轮次 | 表现消息 + 资源缺失负控 |
| **M3** | 故障 / 中断**不会**继续播放旧嘴型；`idle` 可随机取已有待机动作；`thinking`/`speaking`/执行状态**必须**跟实际事件一致 | 中断负控 + 状态对账 |
| **M4** | 换皮套后**角色 ID / Seed 指纹 / 故事 revision 不变**；重连读取**最新**状态，**旧版本包不得覆盖新状态** | 换壳对账 + 过期包负控 |
| **M5** | 中文输入输出**实际走 LG 正式轮次**；最终转录才成为用户输入；检查后文本与字幕**一致**（同一 `replyId`） | 转录/回复/字幕三方同 ID 对账 |
| **M6** | **先检查后合成**：不存在"先播未检查 token 再在字幕里修正"的路径 | 静态断言 + 负控（注入未检查文本必须被拒） |
| **M7** | 60 次首反馈样本（40 普通 + 10 检索/任务 + 10 冷启动/故障）中**没有一次超过 10 秒**；报 max 与全部超标案例；失败样本**保留在全分母** | 同钟测量（浏览器/播放端） |
| **M8** | 有意义语音延迟记录 p50/p95/max；普通短轮 p95 目标 ≤ 5 s（未达即 `FAIL`，未测即 `NOT RUN`） | 同钟测量 |
| **M9** | 六类重叠交互各 ≥ 5 次真实发生：讲话期间本地召回/显式查证、角色短插话、强信号停止、用户打断、证据触发中途纠正、话题改变后过期结果；另测误触发/否定引用/回声/断线/重复包 | 六组成员 + 负控组 |
| **M10** | 取消目标 = 停止过期工作与表达；**不撤销**已提交的用户消息/记忆/外部副作用；不能取消的外部动作仍按原 `actionId` 记录且**不重新执行、不注入新话题**；**正式写入轮次继续串行** | 副作用幂等对账 + 并发写负控 |
| **M11** | 后续语音上下文**据可确认的已播放部分**构造；未播出的句子**不得**被表述为"我刚才已经告诉过你"；重连默认**不自动重播** | 上下文构造读回 + 负控措辞检测 |
| **M12** | 直播/示例**不得**用 fixture 时序代替真人体验：至少一份**真实麦克风 + 真实扬声器/耳机**演示能读回事件顺序 | 真人演示记录 |

## 3. 阈值（WP0 冻结；未测 `NOT RUN` / 未达 `FAIL`）

| 指标 | 阈值 |
|---|---|
| 输入后首个可感知反馈 | **每次 ≤ 10 000 ms**（报 max 与超标案例） |
| 有意义语音延迟（普通短轮） | 目标 **p95 ≤ 5 000 ms** |
| 本地确认有效停止后停播 | **≤ 250 ms** |
| 服务取消 / 旧包失效 | **p95 ≤ 500 ms** |
| 明确快速信号首反馈 | **p95 ≤ 500 ms** |

- 时延使用**浏览器/播放端同一时钟**；服务端时间**只对账**，**不能**直接相减不同机器的时钟。
- **不靠音频文件生成完成时刻**计算"停播"；分别保存**声卡实际播放**与服务时刻。

## 5. 证据与隐私

- 声音 / 完整转录 / 真人材料 → `artifacts/post-lv2/local/`（gitignore）。
- trace 与公共证据只存**必要引用与测量**；**不新增隐藏推理日志**。
- 预录音、fixture 或 mock 通过**不能**代替真实麦克风、实际皮套、真实 TTS 与合法外部检索的各自读数。

## 6. 本契约**不**主张什么

- 不主张开放域自由插话的品质、连续多小时稳定性或多人环境能力（另做加强评价，不从短演示外推）。
- 不主张"任何时候都能合理反驳"这一开放域能力已解决。
- 不主张 Lv4 的 10 秒数字能证明 Lv4.5 的自然度。
- 不主张上游 README 的低延迟数字是本机证据（必须实测）。
