# M7 已知局限（Known Limitations）

> 日期：2026-09-26。状态：**与 [Gate-Decision](M7-Gate-Decision.md) 同一时点**。
> 纪律：局限是**登记**，不是道歉——每条写清"边界在哪、证据是什么、何时重审"。
> 编号沿用 `L-M7-NN`；不与 M6.1 的 `L-M61-NN` 混用（分列纪律）。

## L-M7-01 · 锚点语义：日常聊天不推锚，侵蚀持续

```text
边界   lastInteractionAt 只随关系证据域事件（IMPACT/ORIGIN）推进；
       没有规则命中的日常聊天不推锚 ⇒ 距上次互动持续增长 ⇒ 读回如实显示
       "距上次互动 X 小时"。
证据   wp5 门 P5（读时派生侵蚀）· wp6 门 P5b（事件间侵蚀结算）。
定性   契约行为，不是缺陷（ADR-064 §5.1；WP5 交接 §6 已登记）。
重审   若用户裁定"日常陪伴也应计互动"，走 ADR 修订锚点语义——那是
       语义变更，不是 bug 修复。
```

## L-M7-02 · 日基规则在真实时钟下不可验证

```text
边界   R-1（≥10 条跨 ≥2 自然日）与 >24h 侵蚀需要多日跨度；spawn-per-run
       的真模型运行在数小时墙钟内完成 ⇒ 单自然日 ⇒ 不可触发。
证据   离线门合成时间线（wp6 P5/P7 全绿）；长轨迹冻结单 §2 如实登记。
定性   已知边界：长轨迹不主张覆盖日基规则；它们的证明只在合成时间线上。
重审   若未来有跨多日的真实使用读数，可对照离线算式复核。
```

## L-M7-03 · 规则覆盖是冻结词形判据，不是语义理解

```text
边界   附录 A 的 r1–r5 是词形模式（带句级守卫）；覆盖面外的表述
       （同义改写、外语、隐晦表达）不触发关系变化。
证据   wp3 精度探针的三轮校准记录（正控命中/负控安静的具体数字留档）。
定性   设计取舍（ADR-064 D-4）：确定性优先；语义扩展走预留的 LLM
       evaluator 位（新 ADR），不在词形层加启发式。
重审   WP6-B 读数若显示漏报率不可接受 ⇒ 开 D-4 的 LLM evaluator 里程碑。
```

## L-M7-04 · TD-06 只有定义与量具，没有行为读数

```text
边界   四界定义（回应当前输入/复读/挟持/正常连续性）已冻结、量具材料
       已自证（13/13），但真模型基线读数 NOT RUN。
证据   [TD-06 定义](M7-WP6-TD06-Definition.md) · td06 门（含关键词去重
       不可行性证明）· 冻结单 §7（不因冻结自动开跑）。
定性   M7 离线面的诚实边界；G1 §6.4 的行为观察仍是最新行为事实。
重审   【已重审，2026-09-26】基线读数已出：语料短形 诱导中招 0/6（§6.1）
       + 长形 0/34（轨迹中后段抽样，§6.6）——两面干净，"行为/装配层
       修复预期"以读数销账（裁定与边界见 Gate-Decision §6.6；销的是
       修复预期，不是 M6.1 的 L-M61-01 本体登记）。
```

## L-M7-05 · 生产入口仍是单用户控制台

```text
边界   多目标隔离在存储/评估器/投影层已验证（wp4 N2 · wp6 N2：
       user-2 的证据不进 user-1 的投影，未建档目标失败关闭），
       但生产装配（src/main.ts）只有单用户控制台入口。
定性   范围边界（计划 §8：不新增渠道）；多渠道多用户隔离 = TD-20 的
       准入阻断项，M7 不冒充已证明。
重审   微信/QQ 渠道包开工前按 TD-20 验收。
```

## L-M7-06 · 关系状态不是长期记忆

```text
边界   RelationshipState 是 owner 视角的内部投影：不自动进记忆、
       不进她的自述事实面；注入块带版本行（关系投影 rN）供审计。
定性   认知边界（计划 §8 + INV-CI 纪律）：任何"把关系读数写回记忆"的
       需求都是 Privileged Cognitive Operation，须走 Cognitive Integrity 审查。
重审   M9 Belief 若要消费关系状态，按其准入门重新裁定。
```

## L-M7-07 · 攒尾窗策略的容量上界

```text
边界   尾窗 ≥2000 条事件时强制 flush（RELATIONSHIP_TAIL_EVENT_CAP）：
       零提案的超长尾会周期性评估一次（有界，不失控）；正常节奏下
       零提案尾窗自限（R-5 每 100 条合格消息才再触发）。
证据   wp6 P5a（持有）· P5b（消费）· 调度器常量与注释。
定性   装配层策略（ADR-064 附录 A 不受影响）；上界防的是"永远不评估"
       的极端形状。
重审   真实使用若出现频繁的 2000 强制 flush（说明规则长期零命中），
       那是 L-M7-03 的漏报信号，不是调度问题。
```

## L-M7-08 · Live Smoke 未跑（prompt 组装变更的既定要求）

```text
边界   M7 改了 prompt 组装（关系注入块）⇒ 计划 §7.3 要求生产等价
       Live Smoke；未跑 ⇒ "用户看到的回复随关系状态变化"只有
       Level 2 结构性证据（注入块在场 + 措辞映射），没有 Level 1 读数。
定性   授权边界（需测试端点）；与 WP6-B 同一授权面，不分别申请。
重审   授权后 `pnpm with-test-model pnpm m4.5:ci:full` + WP6-B。
```
