## 0. 为什么 TD-06 挡在 M7 产品门前

M7 的关系采信链是：**本轮输入的显式表述** → 规则 → 提案 → 域事件。
如果她（模型层）在"复读上一轮"或"被旧话题挟持"的状态下生成，用户看到的
是答非所问；更糟的是，用户在**旧话题语境**里说的关系表述（"我错怪你了"
指向的是上一件事）可能被采信进**本窗口**的关系证据。
M7 的评估器只读**当前窗口的用户事件**（ADR-064 附录 A），这挡住了
"把旧轮文本再算一次"的机器路径；但"用户本轮说的话在回应旧话题"这件事
本身是**语义层**事实，机器路径不判它——所以行为层的读数（本量具）是
产品门前必须有的那一块。

## 1. 四界的操作化定义（判定契约）

判别的**公共轴**只有两条，全部四界都从它们推导：

```text
轴 A（ uptake ）：本轮用户输入里的新内容——问题、回答、披露、请求——
                 在她的回复里有没有被接住（承认、回应、顺着说）。
轴 B（ add/displace ）：她的回复对"旧内容"（往轮话题、既有主题）是
                 叠加（在接住本轮的基础上带出）还是替代（顶掉了本轮）。
```

### 1.1 回应当前输入（RESPONDS_TO_CURRENT）——合格基线

她的回复满足：**轴 A 成立**。回复里有只有** given 本轮输入**才说得通的
内容——回答了本轮的问题、对本轮的披露作出了反应、接住了本轮的请求。
至于她同时有没有带出旧话题、有没有重复她惯常的关心句式：**不在本界判**，
交给 1.4。

### 1.2 正常连续性（NORMAL_CONTINUITY）——不得误报的合法行为

以下三类行为**全部是合格**的，任何把它们报成复读/挟持的量具都是**坏量具**：

```text
C-1 人格主题复现：她的关心句式、口头禅、价值主张（"早点睡""别硬撑"）
    跨轮反复出现——这是人格的连续性，不是复读。判别：主题复现
    与轴 A 无关，可以与"接住本轮"并存。
C-2 用户点名的回指：用户本轮主动提起旧话题（"上次说的那本书"），
    她顺着展开——旧话题是被本轮输入**引入**的，不是她挟持来的。
C-3 开放线索的跟进：用户此前留下的、未关闭的线索（她自己问过的问题、
    用户答应过要做的事），她在接住本轮之余**追加**一句跟进。
    判别：跟进是叠加（轴 B = add），且轴 A 仍成立。
```

### 1.3 复读（REPETITION_PRESSURE）——要抓的失败形态①

**同时**满足以下两条件才算（缺一不可——只满足 (a) 是人格主题复现）：

```text
(a) 压力复现：在一个连续轮窗内，她的回复的**主导动作**是近乎同一的
    施压/说教/建议（同一要求、同一劝告、同一责备句式）；
(b) uptake 缺席：本轮输入的新内容没有得到任何接住——用户问了新问题
    她不答、用户给了新信息她不接、用户转移了话题她不理。
```

操作化判别：把她的回复按"主导动作"归一到一句话（她这一轮主要在干什么），
跨轮比较主导动作是否同构；再看本轮输入的新内容在回复里有没有**任何**
承接痕迹（指代、回答、情绪反应都算）。**两条都是语义级判断**，
不是词形重叠——"早点睡"连续三轮出现但每轮都先接住了用户的话 = C-1 合格。

### 1.4 挟持（TOPIC_HIJACK）——要抓的失败形态②

**同时**满足以下三条件（比复读多一条"来源判别"）：

```text
(a) 旧话题回涌：她主动重新提起一个**此前已关闭或已被用户搁置**的话题
    （用户明确换过话题、已经聊完、或明确说过"先不聊这个"）；
(b) uptake 缺席：本轮输入的话题被完全顶掉（同 1.3(b)）；
(c) 非用户引入：该旧话题**不是**本轮输入带进来的（区别于 C-2）。
```

操作化判别：先判"本轮话题在她回复里占不占主位"；再判"回复的主位话题
在往轮里是什么状态（开放/关闭/被搁置）"；最后判"是谁把它带回来的"。
三条都是语义级判断。

### 1.5 边界裁决表（量具与人工复核共用）

```text
情形                                   │ 裁决
───────────────────────────────────────┼──────────────────
接住本轮 + 重复惯常关心句式             │ 合格（C-1）
接住本轮 + 追问旧开放线索               │ 合格（C-3）
用户点名旧话题 + 她顺着展开             │ 合格（C-2）
未接住本轮 + 连续同构施压               │ 复读（1.3）
未接住本轮 + 主动回涌已关闭话题         │ 挟持（1.4）
未接住本轮 + 回复内容与往轮和本轮都无关 │ 另案（幻觉域，归 M6.1 量具，不归 TD-06）
部分接住 + 主导动作是施压               │ 按主导动作判（1.3），部分接住记入复核备注
```

**"不以关键词去重"的落点**：本契约的任何一条都不以"句式/词形重复"为
充分条件。词形重复最多是**候选生成**的线索（M6.1 long-scan 的既有定位：
候选器从宽、判定另做），永远不是判定本身。

## 2. 与 M7 关系链的耦合（采信边界）

```text
· 机器侧（已冻结，本文件只登记）：关系证据 = 当前窗口的 user_message
  事件（ESTABLISHED 资格），评估器不读她的生成、不读旧窗口文本
  （ADR-064 附录 A）⇒ "复读她的旧话"不可能直接触发关系规则。
· 语义侧（本量具的职责）：用户**本轮**说的话如果实际在回应旧话题
  （"我错怪你了"指向上一件事），关系采信在机器上仍然成立——
  这不是缺陷：用户对关系的表述以**用户说出那轮**为准，与话题归属无关。
  TD-06 的读数因此**不阻塞**关系采信链，只阻塞"用户可见行为质量"的
  产品门结论。
```
