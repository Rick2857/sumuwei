## 1. 激活了什么（**一行**）

```text
.env:  CHARACTER_MEMORY_SEMANTIC_MODE=shadow  →  on
       （注释里逐字记了批准语与回滚方式）
代码缺省：**没有动** —— `flags.ts` 的语义模式仍由检索策略版本推导（与其它激活同一条纪律：
         代码缺省保守，`.env` 才开）。
```

**它改变了什么**：`shadow` 是"算分但不参与排序"（观察档）；`on` 是"语义分数**真的参与**排序"。
⇒ 从这一刻起，真实对话里语义通道**会影响**召回排序。

## 3. 回滚（**一行**）

```text
把 `.env` 的 `CHARACTER_MEMORY_SEMANTIC_MODE` 改回 `shadow`（或删掉那一行 ⇒ 由策略版本推导回缺省）。
⇒ 语义分数**立刻**不再参与排序；已建好的索引、派生四表、水位**全部保留**（它们不是事实权威，可重建）。
```

## 4. 本 ADR **不主张**（逐条）

```text
· **不**主张"召回质量变好了"：激活只让**已有的分数**参与排序；质量要另立判据（M9.5 的校准/验证读数
  是在**隔离库/副本**上取得的，见 `M9.5-Gate-Decision.md`）。
· **不**主张"她记得更准了"（`DR-11`：措辞层没有启发式守卫）。
· ⚠️ **不**主张 `D-5` 已做：**它没做** —— 那条裁定（给词面命中加保护 / 重跑校准链）仍是 `WP7-B` 的
  一个**未完成前置**，本次激活**在它之前**发生。⇒ 如实登记为**已知缺口**，不是"已覆盖"。
· **不**主张收益：真库 `active` 记忆 **1** 条 ⇒ 语义排序**今天排不出差别**；收益受**记忆体量**限制
  （与 `TD-22` 末段同一条）。
· **不**主张 `TD-22` 关闭（持久游标正在做；`N4`/`N5` 换代断电点未测）。
· **不**主张 `M9.5 = PASS`：那要 `WP8`（观察与收口），而观察需要**真实流量** ⇒ **`FIRST-USE NOT OBSERVED`**。
· **不**主张首次真实使用已被观察：本轮**没有**跑真实对话（那是用户自己的动作）。
```
