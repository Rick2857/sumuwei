# ADR-147：公开发行版将 Lv2.5 保留为可选功能

日期：2026-10-20。状态：ACCEPTED（源码分发决定）。

用户要求推送改动，同时明确“不用删除远端中有关 level2.5 的内容，把它剥离出来变成可选功能即可”。

1. 保留公开仓库所有原有 Lv2.5 专用实现、内容与历史材料，不导入私有检出的删除补丁。
2. 新增单一可选入口 `src/features/lv25/index.ts`。普通聊天主入口只持有类型引用；运行器、内容包和选择模型由原有启用分支或显式故事命令动态加载。
3. 三个故事开关仍缺省 false。开启后沿用既有提交、来源资格、模型决策期限和认知校验，不降低原有门槛，不扩大行动权限。
4. 保留历史 schema 和来源词汇，不删除或迁移接收者的数据。源码发布不表明任何运行环境已经启用。
5. FC-T04 的逐边依赖登记由 main 的内容包依赖移交给可选入口，不增加目录级豁免。新增默认零加载、显式加载、提前加载反例及恢复检查。

运行配置与验收边界见 [可选功能说明](../OPTIONAL-LV25.md)。部署记录、真实配置、运行证据和私有 Git 历史不属于本次公开分发。
