**写入面（全部，无其它）**：1 条 `AFFECT_ORIGIN` 域事件 + 投影行 + 4 条

边界未落 ⇒ replayed 分路重放空历史 + A==B 平凡成立 + 补边界。

## 5. 激活效果与不改变的主张

**效果**（候选说明书 §1 既定后果）：下一次真实对话轮起，情绪输入理解走
语义评估器（有上下文分类提案 → 程序主导类别 → 固定有界增量 → Validator →
`AFFECT_IMPACT` → 同一 `affect:character` 投影）；词形路径停用（不删除）。
慢路径语义照旧（本轮回复用已提交状态；语义完成最早下轮可见，不承诺同轮）。

**激活不新增任何主张**：`L-M85-01…18` 全部照旧——含 `L-M85-11` 已裁定
残差终态（关键假阳 2/29 = 0.0690，人审维持）、`L-M85-14`（测试端点 ≠
生产端点）、`L-M85-18`（本 ADR 关闭）；不主张任意同义句识别正确、不主张
识别用户真实心理、不主张多用户就绪、不主张"她有了感受"；能力影响矩阵 =
**NONE**（无新外部能力）；语义判定永不自动进长期记忆；M9 不因此获得
事实来源资格。
