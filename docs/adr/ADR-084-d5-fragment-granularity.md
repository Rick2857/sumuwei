# ADR-084 · `D-5` —— 词面片段粒度 **2 字 → 3 字**（冻结区语义变更）

> **状态**：`PROPOSED`（**冻结区**改动：`src/kernel/app/memory/**` ⇒ 按 `AGENTS.md` §3 要**新里程碑 + ADR + 全套 `m4:*`**）

> **授权**：用户 2026-10-01 逐字 **「同意改片段粒度」** + **「D-5 是走冻结区程序改片段粒度」**
> **前置**：[`ADR-083`](ADR-083-d5-graded-lexical-strength.md)（词面强度）· 语料 `m9.5-d5-adversarial@5`

## 1. 问题（**量出来的，不是推出来的**）

`D-5` 要"**有限提高词面权重**"，但三组读数依次否掉了它：
```text
① 二值词面（@3）      ⇒ A1（要压过语义 0.99 诱饵）与 A5（改述不被弱重叠压过）**无交集** ⇒ 无值达标
② 强度 = 命中数/总数  ⇒ 真实精确命中的上限只有 **0.500**（2 字滑窗的分母把上限压住了）⇒ 无值达标
③ (戊) 最长命中片段比 ⇒ 上限修好了（目标 **1.000**），但 **A5 的噪声也拿到 1.000** ✗
   ⇒ 因为"**2 字的偶然重叠**"与"**2 字的实质命中**"在这个粒度下**无法区分**
```

**假设对照读数（`@5`，3 字片段，**不是系统**）**：
```text
A1: decoy=0.000  target=**1.000** ✓        A2: 三条诱饵 0.000 · target=**1.000** ✓
A3: high=1.000   low=1.000     ✓（同强度 ⇒ 回归守卫不受影响 ✓）
A4: relevant=1.000  irrelevant=**0.000** ✓（偶然重叠不再算命中）
A5: paraphrase=0.000  noise=**0.000** ✓✓ ★ 关键：噪声不再算命中 ⇒ 改述在任何权重下都赢
```

⇒ **结论**：冲突**不在聚合公式、也不在权重**，而在**片段粒度** ✓ —— **3 字能把两者分开** ✓。

---

## 2. 决策

**`lexicalFragments` 的片段长度：2 → 3 字。**

```text
⚠️ 这会**同时**改变 `lexicalOverlapHits` 的"命中"含义 ⇒ 属**语义变更** ✓（不是"追加能力"）
⚠️ 因此按 `AGENTS.md` §3：要**新里程碑 + ADR（本文件）+ 全套 `m4:*`** ✓
```

### 2.1 为什么必须改**共享的**那个函数（而不是强度函数自己用 3 字）
```text
`ADR-083` §0 ① 的硬约束：**强度与"命中与否"必须同源**
⇒ 若只有强度函数用 3 字、而 `lexicalOverlapHits` 仍用 2 字，就会出现
   "**判为命中但强度 0**"（或反之）的自相矛盾 ✗ ⇒ 那条约束**就是为此而设的** ✓
```

### 2.2 代价（**如实登记**）
```text
· "命中"变得**更严**：2 字片段能命中的一些句子，3 字可能一个都不中
  ⇒ **召回面会收窄** ⇒ ⚠️ 这正是 `memory-coverage:verify`（覆盖率量具）要给出的前后对照 ✓
· 它**同时**影响 `LexicalSemanticJudge`（判别器，第 5 步）—— 那里也要重跑它的门 ✓
```

## 7. ★★ **全套 `m4:*` 的读数（2026-10-01 实跑）—— 如实报红**

```text
m4:test                     ❌ **254 通过 / 4 失败**
m4:verify                   ✅ 142 / 0
m4:mutation-safety:verify   ✅  20 / 0
m4:nl-mutation:verify       ✅  38 / 0
memory-coverage:verify      ✅ 自检 PASS（47 项全部符合期望）   ← ⚠️ **没红**（见下）
```

**4 个失败全部落在 `LexicalSemanticJudge`（第 5 步判别器）**：
```text
1. 语义判别器 :: LexicalSemanticJudge：唯一词面命中 → 选中；零命中 / 多命中 → 判不出来
2. 目标解析 :: 第 5 步：判别器判得出来 → resolved / via = model_resolver
3. 目标解析 :: 第 5 步：判别器判不出来 → ambiguous（**不挑一条**）
4. 目标解析 :: 判别器返回候选集外的 id → **抛错**（不接受它凭空决定一条记忆）
   ⇒ 失败信息逐字：「判别器返回了候选集外的 id **却被接受** —— 它可以凭空决定一条记忆」⚠️⚠️
```

⇒ **这是一次"如实红"，不是噪声** ✓，而且**必须分开看两类**：
```text
【甲】1–3 是**期望值变了**：3 字粒度让"词面命中"更严 ⇒ 原本"唯一命中"的夹具变成"零命中"
      ⇒ 判别器的输出从 `resolved` 变成 `ambiguous` ⇒ 与硬编码期望不符 ✓
      ⇒ 这是**这次改动的直接代价**（召回面收窄在判别器上的形态 ✓）

【乙】4 是**安全性质不再被触达** ⚠️：那条断言测的是"判别器凭空返回候选集外的 id 时**必须抛错**" ✓
      而 3 字之后夹具**走不到那条路径**（没有唯一命中 ⇒ 提前 ambiguous ✓）⇒ 断言失败 ✓
      ⇒ **⚠️ 这不是"性质坏了"，而是"它不再被这条夹具覆盖"** ✗
      ⇒ **不许**把这条断言删掉了事 —— 那会让一条**真的安全性质**失去覆盖 ✓
         （`DR-11` 那一类"措辞层没有守卫"的教训：**能查/能拦**才是买到的，丢掉覆盖就是丢掉它 ✓）
```

### 7.1 因此本 ADR 的**完成判据要加一条**
```text
⑤ **4 个失败必须逐个处置**，且**分类**：
   · 1–3（期望值变了）⇒ **改期望**要**显式写明"因为片段粒度变了"** ✓（不是悄悄改成绿的 ✓）
   · 4（安全性质失去覆盖）⇒ **必须补一条夹具**，让"候选集外的 id 必须抛错"**重新被触达** ✓
     （例如直接构造一个返回域外 id 的假判别器 —— 不依赖"先有唯一命中" ✓）
⚠️ **在 ⑤ 做完之前，本改动不得称为完成** ✓
```

### 7.2 ⚠️ `memory-coverage:verify` **没红**，这一点要说清
```text
它的自检 PASS（47 项符合期望）⇒ 说明**它量到的那批句子的期望仍然成立** ✓
⚠️ 但这**不等于**"召回面没有收窄" —— 它的语料是**它自己那 47 项** ✓，
   而本改动的收窄发生在**判别器那一条路径**上（见 7 的 4 个失败 ✓）
⇒ **不许**用"覆盖率门绿了"来抵消 4 个失败 ✓（两个量具量的是**不同的东西** ✓）
```
