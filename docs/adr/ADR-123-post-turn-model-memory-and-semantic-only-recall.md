# ADR-123 — 轮末统一模型记忆判定与纯语义召回

2026-10-09 · ACCEPTED / IMPLEMENTED · PRODUCTION ACTIVATED（本页末节记录用户授权和执行读数）。

用户裁定：每轮结尾由模型直接判断所有记忆操作，接受调用量增加；先回复，后台统一处理，本轮只说收到、待处理；检索只走语义。测试必须包括字面相似而语义不同的材料。

本次是 post-Lv2 的追加能力，不改 M4 事件 payload、原生 validator/reducer 或旧模式默认行为。历史流程与历史证据保留。原因是事件 679 的一次性提醒曾被显式写入路径误判为 `preferred.address=拔一下插头`；召回发生在写入之后，不是这次错误入库的来源。

1. `CHARACTER_MEMORY_WRITE_MODE=post_turn_model` 替代本轮同步的规则意图/内容抽取和旧 LangMem 自动抽取。每个已完成回复的受信用户事件直接调用模型，普通聊天、问句、提醒也调用，不做关键词筛选，不做模型兜底分支。其它 actor 只推进任务水位，不产生用户事实。
2. 模型一次返回 none/transient/long_term/mutation，以及至多四个 create/correct/forget/dispute/restore 提案。学校使用 person_fact，长期称呼/提醒方式使用 preference；importance/confidence 分别由模型给出，不固定为 .80。明确指代的目标可借助同会话最近 12 行解释，最多提供当前用户的 50 条记忆；新事实的证据仍只能是本轮原文。
3. 本轮注入 pending 程序事实，尚未执行的记忆操作不能声称完成。记忆专用完成词受回复守卫约束，提醒等其它动作仍由对应执行结果守卫；这仍是有限的措辞保证，不宣称自然语言完全无误。
4. 程序只验证结构、原文引用/取值、受信来源、当前用户归属、目标/版本、冲突、幂等和权限，不再用词面规则或另一个语义分类器决定去向。enum/scale 值允许规范值；text 值不得自行改写。空/null 的可选字段正规化为缺省，不为变更猜目标。
5. 提案进入 LG 原生 validator → DomainEvent → reducer/store。更正原子地建立新记录并 supersede 旧记录，明确改回旧取值时复用 M9.1 原生 restatement 复活；遗忘保留可审计的 retracted 状态。同内容不得无授权复活，restore 要求明确授权、已撤回/被取代目标和无冲突。整批任何一项失败全部回滚。
6. 复用一个共享消费者、持久任务/连续水位、三次失败停住、最多三次具名恢复授权、事务终结闸和关库前收拢。模型调用在事务外且不阻塞本轮回复。启动建立新的 cutover，后续重启续跑；不自动重判旧历史。受信用户没有回复时等待；trace 已终结为 failed 的失败/取消对话不提案，推进水位避免堵住后续已完成对话。读状态和恢复命令按当前模式选择处理器，日志只加去向/计数，失败任务保留受控原因码，不保存模型错误正文。
7. `CHARACTER_MEMORY_RECALL_MODE=semantic_only` 强制语义 on。候选按语义分数排序；词面分数/命中、目标/共同经历捷径及词面降级退出此模式。相关性仍通过已有语义阈值与领先间隔；保留来源/归属/状态/预算等资格边界。探针失败或没有分数即无命中，trace 如实记录原因。旧模式保留原排序与降级语义。
8. 冻结对照语料覆盖称呼/叫人做事、长期提醒偏好/一次提醒、陈述/问句/引用/假设/角色扮演、真实经历/虚构、更正/遗忘/存疑/恢复及相似非授权表述。真实模型测试同时检查提案和原生落库/状态/零写入。离线夹具仅证明程序行为，不冒充模型语义成绩；失败档保留。

验证与限制见 [执行记录](../post-lv2/Model-Memory-Decision-2026-10-09.md)。生产切换按 AGENTS.md 单独授权，受控关闭与快照之后修改上述两个档位并重启/读回。代码默认仍为旧模式；实现阶段的实验未打开或改动真实库。既有错误记录不自动删除；明确长期保存的学校与提醒偏好不批量清理。
