# ADR-065 —— M7 关系层生产激活（真实聊天启用关系状态）

- 状态：**ACCEPTED / EXECUTED**（2026-09-26，用户显式批准）
- 关系：**只做状态修订**。本 ADR **没有**改 ADR-064 的正文一个字节——它的七项设计裁定、
  附录 A 规则集、认知边界（计划 §8）全部继续有效。被修订的**唯一**一项是
  ADR-064 `D-6` 的激活边界：`production_activation: NOT_APPROVED` → **`ACTIVATED`**。
- 先例：ADR-048（M5.5 生产激活）——同样是"只做状态修订、不重写设计"的载体。

## 1. 授权

用户在 M7 收口（标签 `m7-complete` · 盲审门关闭 · 宣告完成）之后，先问"生产激活未发生
对我的实际使用有什么影响"，得到逐层说明（flag 管到哪 / 状态是否默默累积 / 激活会发生什么，
含**历史回放**语义与回滚路径），然后显式指示："好的现在激活"。
本 ADR 是那次确认的裁定载体。

## 3. 生效范围（爆炸半径，逐条）

| 维度 | 激活前 | 激活后 |
|---|---|---|
| ORIGIN 建档 | 不播种 | **首次真实模式 open() 播种**（0.85/0.60 设定基线，走完整放行链，幂等） |
| 关系评估 | 整条链休眠 | 开机追赶 + **每轮后尾窗评估**（语义命中即消费；零提案则持有给 R-1 跨日累积） |
| 关系注入块 | 不注入 | **每轮注入**（trust/closeness/在案/侵蚀，`relationship` section 唯一渲染） |
| 旧 M6.1 关系轴 | 照常渲染 | **退役**（`relationshipAxes=false`，不双权威——ADR-064 §6） |
| prompt 基线 | 与 M6.1 逐字一致 | 多一个 `relationship` section（WP5 门证过注入形状） |
| 长期记忆 | 不受影响 | **仍不受影响**（关系状态是 owner 视角投影，不自动进记忆——计划 §8 认知边界） |
| 模型调用 | — | 评估链**零模型调用**（规则是冻结词形判据）；只有正常聊天本身的调用 |
| 真实库结构 | v9 | **v9 不变**（零迁移） |

**历史回放（本次激活裁定的语义）**：水位无行时从 **0** 起
（`relationship-scheduler.ts` `watermarkRow?.processedThroughSequence ?? 0`）⇒
首次真实 open() 的追赶评估窗口 = **全部历史对话**（1..latest）。过去对话里的
感谢/指控/撤回/里程碑会**一次性**把状态从 0.85/0.60 基线推到"设定基线 + 实际历史"
的位置。用户在激活前已被告知此语义（"激活 = 历史一次性回放"）并据此授权。
回放是一次性的：水位前进后，后续只评估新事件。

## 4. 本 ADR **不**主张什么

```text
· 不主张"她从此不复读/不挟持"——TD-06 读数（诱导中招 0/6）是当前输入下的
  行为读数，不外推；行为修复是后续独立工作（L-M61-01）
· 不主张关系状态解决了记忆问题——M6.1 的长程回忆衰减/更正渐蚀（L-M61-xx）
  原样保留；关系读数不冒充记忆修复
· 不主张规则覆盖全部语义——规则集是冻结词形判据（ADR-064 附录 A），
  覆盖面外的表述不触发；扩展走 D-4 预留的 LLM evaluator 位
· 不主张多用户生产就绪——生产入口仍是单用户控制台（TD-20 边界）
· 不改变 M4.x/M5.x/M6.x 的任何既有语义与历史证据
```

## 5. 回滚（两档）

```text
① 停用（一步）：.env 那行改 false 或删掉并重启 ⇒ 回到"整条链休眠 +
   旧轴渲染"的 M6.1 等价状态。已写入的 ORIGIN 与回放事件保留在账本里
   （投影是派生的，事件是事实记录），不再被未来评估消费。
② 清除（破坏性，需单独授权）：从激活 boot 自动留下的 pre-open verified
   snapshot（INC-01 纪律：每次真实 open 前都有）恢复 ⇒ ORIGIN 与回放事件
   一并消失，回到激活前逐字节状态。走 db:restore 的 dry-run → apply 程序。
```

## 6. 保留的 STOP 条件（激活之后仍然成立）

```text
· 关系状态永不自动进长期记忆（计划 §8；与 D-7 同族纪律）
· 她的生成内容永不推动关系（Assistant Fact Firewall：wp3 负控证过）
· 规则集改动必须回 ADR-064 裁定（附录 A 是冻结面，不加启发式）
· 评估链失败不拦聊天（失败不抛，下一轮尾窗补洞——与 memory job 同款纪律）
· 出现"绕过放行口写关系状态"的任何改动都必须回到裁定
```
