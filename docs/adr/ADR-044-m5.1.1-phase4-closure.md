## 6. 本次关闭**不**主张什么（能力边界）

```text
· **不**代表具备**后台自主任务**能力：`CHARACTER_MEMORY_BACKGROUND_ENABLED` 仍是 NOT-WIRED；
  延期能力（DC-1 / DC-2 / DC-3）**不**随 D01 一起关闭。
· **不**代表实现 **Break-Glass**：`M511-G8 = NOT RUN` 如实保留（缺证据 = NOT RUN，不是 PASS）。
· **不**代表开放**通用记忆注入**：`K-31`（`conversation-store.ts` 的通用入口）仍 `OPEN / DEFERRED / NON-BLOCKING`。
· **不**代表**措辞保证**：`DR-11` 逐字 —— 机械保证只到"采信 / 排序 / prompt 标签"，
  措辞正确性只能由 Live Smoke 与 eval 场景**观察**。本步的观察材料（三段真实回复）**明确显示**：
  带标签的那条她仍然说"记得"，而 agent-runner 提交的那条她仍然说"记住了"。
  ⇒ 本次关闭买到的是**可查、可审计、可降档**，**不是**"她不会再说错"。
· **不**代表 `M5.5` 已开始：M5.5（Web Search & External Evidence）需要**另立执行计划**。
· **不**代表可以打标签：里程碑标签仍需用户**单独批准**。
```

## 8. Alternatives

| 备选 | 否决理由 |
|---|---|
| 直接修改 ADR-043 的 §8 / §6 `L-7` | 它自己是 `DESIGN FROZEN`，编辑约定要求"新开一次 ADR 修订并引用本文件" |
| 把 WP11 改造成关闭门 | 会让"历史读数"与"当前读数"再次混在一个门里；且违反 R-52 的"WP11 不能借此关闭 D01" |
| 不写 ADR，只在报告里改状态 | 状态迁移缺少**可追溯的裁定载体**；ADR-043 §8 会永远停留在一个已经不成立的值上 |
| 重跑真实模型 Smoke 以"再确认" | 重复消费模型**不产生新证据**（措辞是随机的），却会让冻结的观察材料漂移 |
| 顺手把 DC-1/DC-2/DC-3 / K-31 一起关掉 | 它们**不是** D01 的组成部分；合并关闭会让"到底关掉了什么"无法回答 |
