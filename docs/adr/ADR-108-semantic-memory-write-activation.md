# ADR-108：所有正式聊天入口的语义记忆写入兜底

状态：ACCEPTED / ACTIVATED（2026-10-06；完整回归 EXIT 0 后开启生产配置并正常重启 QQ，见激活追加记录）。用户明确要求“把语义功能也开启应用于写入”，并补充“所有的聊天中，不仅仅是 qq”。本授权覆盖共用入口的实现、隔离验证、生产配置激活及已运行 QQ 入口的正常重启。

## 问题与决定

生产的 M9.5 `CHARACTER_MEMORY_SEMANTIC_MODE=on` 只负责召回。显式写入原先仅装配规则意图检测器；`LlmContentExtractor` 的开关也未开启。“请记住……”在规则句首守卫处返回无意图，尚未到达内容抽取。

1. 复用已有 `LlmMemoryIntentClassifier` 和 `LlmContentExtractor`，在 `src/main.ts` 的共享 `buildMemoryWriter` 接线。正式 CLI、stdio bridge、QQ、使用正式 bridge 的语音/Live2D 共用；独立测试入口可显式关闭。
2. 用既有 `CHARACTER_MEMORY_LLM_EXTRACTOR_ENABLED` 同时控制意图与内容兜底。代码缺省仍为 false；生产 `.env` 经本次授权设 true。规则命中保持旧路径；未命中才调用模型。回滚设 false 后正常重启。
3. 仍仅处理用户明确要求的长期记忆操作。未开启后台自动抽取，不把所有对话自动转换成长期事实。模型候选照常经过证据、身份、schema、权威、冲突、去重、提交与回复真相守卫；无迁移、无第二个写入者。
4. 分类只接受完整闭集标签 `remember/correct/forget/dispute`；`none`、解释、JSON、多个标签、非法格式、模型失败均不给写入意图。复现发现旧解析器用子串匹配，会把 `do not remember` 判成操作；先补负控，再改为完整标签判定。未声称模型的语义判断永远正确。
5. 每次意图/内容语义调用使用现有 provider 的 AbortSignal，期限 15 秒，失败不猜、不伪报记住。规则未命中的普通聊天会增加一次私有意图调用；需内容兜底时再增加一次调用。模型请求增加的延迟属于本功能成本。

## 验证和激活条件

- 单元门守完整闭集、失败关闭、旧规则优先、用户来源闸；既有 Memory 不变量不变。
- 共用 `main.ts` 的隔离整链分别验证 off/on、CLI/桥/QQ 入口、真实记忆写入、普通自述/引用/疑问的零写入、失败后新请求恢复。语义写入正控必须出现实际模型兜底调用及持久化行，不能仅凭回复“记住了”。
- 使用 `.env.test` 的测试端点执行有限真实模型检查；只写全新隔离库，保留失败档。测试不消费正式账号的 QQ，不向 QQ 发送合成消息。
- `pnpm typecheck`、相关记忆门及完整 `pnpm m4.5:ci` 通过后激活 `.env`，正常排空关闭并重启已有 QQ 入口。保存配置、进程就绪和账号连接读回；自然聊天首用与实际收益单独记录，不凭开关宣称全链行为通过。

现有内容问句守卫和规则取值边界仍保留；不承诺所有礼貌问句、引用、复杂多事实及任意记忆槽位都能正确处理。M4/M4.1 的历史 evidence 和代码缺省 off 保留，本批是独立的 post-Lv2 追加能力。
