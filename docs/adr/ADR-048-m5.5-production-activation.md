# ADR-048 —— M5.5 生产激活（真实聊天启用联网）

- 状态：**ACCEPTED / EXECUTED**（2026-09-20，用户显式批准）
- 关系：**只做状态修订**。本 ADR **没有**改 ADR-045 / ADR-046 / ADR-047 的正文一个字节 ——
  它们的边界（`D-1`…`D-18`）、历史 provider 裁定（`D-19` Brave / `D-20`…`D-30` Tavily）与
  当前 provider 裁定（`D-31` 本地 SearXNG）全部继续有效。
  被修订的**唯一**一项是 ADR-047 里那个数据点：
  `production_activation: NOT_APPROVED` → **`ACTIVATED`**。
- 先例：ADR-044（M5.1.1 Phase 4 关闭）——同样是"只做状态修订、不重写设计"的载体。

## 1. 授权

用户在 M5.5 的 WP10 收口后**显式**给出三件事：打标签 · 合并 `main` · **生产激活**。
计划书 §12「激活 STOP」要求先展示六项（provider 与出站形状 / 两条真实回复 / 来源一致性 /
数据库未写入证明 / 全门结果 / 已知局限）再激活 —— 六项在 WP9/WP10 两轮里已逐条落盘
（`artifacts/m5.5/smoke/smoke-result.json` · `gate-results.json` · 四份发布文档），
本 ADR 是那次确认的裁定载体。

## 2. 改了什么（一处，可枚举）

```text
文件：.env（gitignored，用户自有；本仓库的开关都写在这里）
追加：
  # M5.5 生产激活（用户 2026-09-20 显式批准）：真实聊天里出现显式搜索词时，允许一次本地 SearXNG 查询
  CHARACTER_WEB_SEARCH_ENABLED=true
```

**没有**改：`.env.test`（测试仍需确定性；Live Smoke 是在**子进程**里临时置 `1` 的）、
任何仓库内文件、本机 SearXNG 的任何配置、任何 provider 参数。

验证（真实 `.env`，不碰数据库、不出站）：

```text
webSearchEnabled = true
webSearchEvidenceTokens = 800
kernel flags: ON=[…, web-search]  OFF=[telemetry, memory-background(NOT-WIRED), memory-llm-extractor]
```

## 3. 生效范围（爆炸半径，逐条）

| 维度 | 激活前 | 激活后 |
|---|---|---|
| `web:search` 权限 | 不授予 | **授予** |
| 搜索适配器 / provider 实例 | 构造上不存在 | **构造出来**（`searxng-local`，配置固定在 `search-config.ts`） |
| 出站可能 | **零** | 只有当**用户原话里出现显式搜索词形**时才发生 **1 次** `GET /search` |
| 出站内容 | — | `q` + 冻结的五个参数；**无**认证、**无** body、只有 `accept`（`D-31`） |
| `q` 的去向 | — | ⚠️ 被本机 SearXNG **转发给** `duckduckgo / wikipedia / wikidata`（"本地"≠"不出站"） |
| 证据额度 | 0（不注入） | `CHARACTER_WEB_SEARCH_EVIDENCE_TOKENS`，默认 **800** token（有界 0..2000） |
| `memory_records` | 不受影响 | **仍然不受影响**（`D-7`：外部证据永不自动进长期记忆） |
| 回复 | — | 成功 ⇒ 正文剥离自造 `[E<n>]` + 追加**程序生成**的来源附录；其余四态由程序确定性映射 |

## 4. 本 ADR **不**主张什么

```text
· 不主张"她说的都对"或"来源可靠"—— 只主张"来源集合与执行证据一致"（D-10 逐字）
· 不做逐句事实蕴含验证（v1 范围外，独立里程碑）
· 不主张"每一次都能查到"—— 实测：三个引擎冷启动常常超过 5000ms 硬超时，
  系统会**如实降级**（`L-M55-12`），用户会得到"没查到"
· 不主张来源内容安全 —— 网页文本一律按**数据**注入（`D-8`/负控），但它是不可信外部文本
· 不改变 M4.5 的默认能力集（仍是 3 个；`web.search` 是**追加登记**，`D-11`）
· 不改变 M5/M5.1/M5.1.1 的任何既有语义与历史证据
```

## 5. 回滚

**一步**：把 `.env` 的那一行改成 `false`（或删掉）并重启进程 ⇒ 立刻回到
"不授予权限 + 不构造适配器 + 额度 0"的**构造上无法出网**状态（`D-12` 的两处消费是同一个 flag）。
回滚不需要动任何仓库文件、迁移或数据。

## 6. 保留的 STOP 条件（激活之后仍然成立）

```text
· 禁止把搜索做成"模型自行决定要不要联网"（D-6）
· 禁止把搜索结果自动写进长期记忆（D-7）
· 禁止把摘要正文放进 trace / 账本 / 开发者面（D-8）
· 禁止为了联网而扩 telemetry 白名单、新增端点或改 DTO 表（D-15 / D-18②）
· 出站只允许那六个参数；出现"记忆/人设/userId/traceId/凭证"之一的任何改动都必须回到裁定
```
