## 1. 问题（**先量出来的**）

`D-5` 原本的方向是"**有限提高词面权重**"（`{1, 1.25, 1.5, 2}`）。实测（对抗语料 `@3`，**二值**词面）：
```text
w=1      A1 ❌ A2 ❌ A3 ✅ A4 ✅ A5 ✅
w=1.25   A1 ❌ A2 ✅ A3 ✅ A4 ✅ A5 ❌
w=1.5    A1 ✅ A2 ✅ A3 ✅ A4 ✅ A5 ❌
w=2      A1 ✅ A2 ✅ A3 ✅ A4 ✅ A5 ❌
⇒ **没有任何值同时满足**：A1/A2 要求约 w > 1.47，A5 要求约 w < 1.125（计入 margin 项后的校正值）
```
**根因**：`lexical` 是**二值** ⇒ "精确命中"与"偶然弱重叠"在分数上**完全一样** ⇒
同一个权重无法**只**抬高前者。⇒ 不是"该调到几"，而是**通道缺少强度信息**。

---

## 2. 决策

**词面通道产出 0..1 的强度**（不再二值），`weights.lexical` 的扫描与冻结**照旧**（取最小达标值）。

```text
0    无词面重叠（改述）
0.2  偶然弱重叠（只碰巧共享一个常见词）—— ★ 要区分出来的正是这一类
1.0  精确命中（查询实词基本被覆盖）
```

### 2.1 为什么这能解开（**算术，已由 `@4` 读数证实**）
```text
A1（下界）：目标 lexical 1.0 / sem 0.01 vs 诱饵 0 / sem 0.99 ⇒ 目标胜 ⟺ w > 0.98
A5（上界）：改述 0 / sem 0.85 vs 噪声 **0.2** / sem 0.10 ⇒ 改述胜 ⟺ w < 3.75
⇒ **有交集**；`@4` 实测：**最小达标值 = 1.5**，且 **A5 在 1.25 起就通过**
  （对照：二值下 A5 **每个权重都失败** ⇒ (乙) 保住了改述召回 ✓）
```
