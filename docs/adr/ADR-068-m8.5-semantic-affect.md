## 1. 背景与占位对应（M85-D01）

M8 交付了完整的情绪机械闭环（来源资格 → 词形评估 → Validator → AFFECT_* 事件 → 投影 → 衰减 → 上下文注入），但其输入理解是 `affect-rules@1` 的固定词形匹配：换个措辞的感谢、引用他人的攻击、反讽、修复与撤回，词形路径要么漏判要么误判。

ADR-066 的 **M8-D03** 原文（§决策表）：

> 确定性规则 v1（`affect-evaluator@1` + `affect-rules@1`）；LLM 仅在 processor 合同预留（**未来 M8.1 走 slow path，输出仍是 proposal，过同一 Validator**）

**本 ADR 建立的对应**：用户命名的 **M8.5** 就是该占位的落地实现，逐条兑现三项预留——

| M8-D03 预留 | M8.5 落地 |
|---|---|
| 走 slow path | 慢路径 worker（completeTurn 后非阻塞；本轮回复用编译时已提交状态，M85-D02） |
| 输出仍是 proposal | 模型只产结构化分类提案（判定闭集 + ≤3 候选 + span），数值由程序查固定增量表（M85-D05） |
| 过同一 Validator | 同一放行口追加 `affect-semantic-policy@1` allowlist；精确 delta 校验；单次影响槽位 |

超出占位的新增（均为本 ADR 的裁定范围）：三模式单写入者（M85-D03/D04）、跨版本终结闸（M85-D20）、reducer@2 时间语义（M85-D19）、零 DDL 承载（M85-D21，WP0 已证明）。**不修改 ADR-066 原文。**

## 2. 冻结决策（M85-D01…D22）

完整表述以执行计划 §14.1 为准（22 条）；此处登记裁定要点：

| 编号 | 裁定要点 |
|---|---|
| D01 | M8.5 = M8 输入理解的语义升级；不建第二情绪系统、不改状态动力学（§1 对应表） |
| D02 | 慢路径首版；不承诺同轮/下轮生效；"有界等待同轮"须先修订架构契约才可再议 |
| D03 | 单写入者三模式 `rules`/`shadow`/`semantic`；TOUCH/ORIGIN 永远走现行结构路径 |
| D04 | 不搞混合命中；运行时失败不自动回落词形；回滚 = 具名模式切换 |
| D05 | 语义层非权威：程序选主导类别、查固定增量；Validator 查精确 delta；接受 ≠ 证明意图 |
| D06 | 判定闭集 IMPACT/NEUTRAL/UNCERTAIN/OUT_OF_SCOPE；FAILED 与 INELIGIBLE 分列 |
| D07 | 七家族与数值不动；独立策略版本 `affect-semantic-policy@1` |
| D08 | 立场先行；M8 全序取主导；一次用户事件至多一条 IMPACT |
| D09 | 角色身份只定"谁是你"与范围；当前 Affect 值不作分类输入（防自激） |
| D10 | 有界上下文：当前 + 前 6 条 / 30 分钟 / 3,000 token 预算；tool/summary/recall/M7 不进 |
| D11 | 出站隐私闭集；回执只存引用/版本/闭集/偏移/指纹 |
| D12 | span = 原始输入 UTF-16 半开区间；不跨 surrogate、不经 normalization；权威字段程序填 |
| D13 | 不二次调用修 JSON；一致性校验；confidence 不作接受门 |
| D14 | 两次校验：出站前资格/模式/预算；提交前有效性/epoch/槽位/过期/顺序 |
| D15 | 每 Character 串行队列、并发 1、升序；模型调用不持事务；非自主任务能力 |
| D16 | 时间/重试/过期值 WP0 实测、WP1 冻结（→ 契约冻结 §7）；改值留版本记录 |
| D17 | 任务状态机与终态集（→ 契约冻结 §7） |
| D18 | 三水位分离；完成水位永不越过无持久终态的合格 source |
| D19 | 语义 IMPACT 锚定 `sourceAt`、不推进交互锚；reducer@2 + 受控重建 A==B |
| D20 | 跨版本稳定终结闸 `affect-semantic-finalized:<sourceEventId>`；已终结来源永不重评 |
| D21 | 零 DDL：现有通用表承载（WP0 承载实验 **PASS 14/14** 已证明） |
| D22 | 独立人审是语义生产激活的硬前置；不代填、不因实施授权自动生效 |

**关键冻结值**（全表见[契约冻结](../m8.5/M8.5-Contract-Freeze.md)）：单次超时 **20,000 ms**（探针 max 11.6 s 实测否决 10 s 初值）· 输出 `max_tokens` **3,000**（推理占 completion 91%，600 预算不可行）· 尝试 ≤2（仅传输类可重试）· 时龄 120 s · 批量 32 · 并发 1 · 回执拆分 = 闸行（紧凑闭集编码）+ trace 明细（`character_jobs` 无 payload 列，WP0 实测修正计划 §11.2 表述）。

## 4. 后果

1. **实施授权范围**：按计划 §15.1 分段 A–E 执行（WP2–WP12），全程**无生产影响**——代码缺省 `rules` 逐字不变；验收全部在隔离库 / 生产副本上。
2. **机械保证不变**：M8 权威链（Validator 唯一放行口、事件账本、投影可重放、|Δ|≤0.25、衰减数学）原样保留；M8.5 只换 IMPACT 的**输入理解**。
3. **新增出站**：语义评估调用（测试与生产同配置面 `OPENAI_SMALL_MODEL`）；上下文出站受 §6.1 资格矩阵与 §6.2 预算约束——**不是零出站**。
4. **新增运行时组件**：受管理 worker（对话驱动、非自主任务）；shutdown 交给既有唯一关库链。
5. **数据模型**：零 DDL（WP0 证明）；终结闸行数与合格 source 同量级。
6. **语义正确性不在本 ADR 保证范围**：机械层只保证资格/格式/版本/数值界/单写入者/单次影响/事务/重放；语义层由 WP2 语料 + WP10 盲测 + WP13 影子对照 + §20 人审证明（M85-D05/D22）。

## 5. 风险登记（摘要；全表见计划 §26）

模型误判（含状态操纵/提示注入——§13.2 必测）、延迟与限流竞争（共享模型服务）、推理 token 成本（91% 实测）、shadow 对照的语料代表性、模式切换的 cutover 边界、`L-M8-13`（M7 潜伏缺陷）不得被本阶段顺手修。

## 6. 激活边界（本文不授予的东西）

本 ADR 的 `DESIGN FROZEN` 授权**实施与验收**，不授权生产激活。进入 WP13（分段 F）的硬前置：

1. §16–21 验收契约全 PASS（离线门 / 盲测 / 影子 / 真实链路 / 长轨迹）；
2. §20 独立人审 PASS（判定权在人，材料不标来源）；
3. 用户显式批准（M85-D22）。

激活载体 = 独立的状态修订 ADR（与 ADR-067 同形）：`.env` 设 `CHARACTER_AFFECT_SEMANTIC_MODE=semantic`，**代码缺省仍 `rules`**；回滚 = 改回 `rules`。

- **变更**：`AFFECT_SEMANTIC_INSTRUCTION` 的【输出】段追加一行——

  格式面**。
- **重验**（修订纪律）：离线门重跑（m8.5:test S21 / wp4 S2 版本锁同步 @2；语料回放门

### R-5（2026-09-26，WP10）：`AFFECT_SEMANTIC_MAX_TOKENS` 3,000 → 5,000 —— 传输预算适配（**用户裁定**）

- **变更**：Contract-Freeze §6 的输出 `max_tokens` 3,000 → 5,000（`src/kernel/contracts/
  affect-semantic.ts`；锁同步：m8.5-test S2 / wp3-contracts N2；wp5 P10 引用常量自适应）。
- **动因与裁定**：@5 盲测 10/11 过，唯一未达 = 失败终态率 0.0283（3/106 > ≤0.02）；
  成因纯传输层——deepseek-v4.1-flash（推理模型）3/318 次把 3,000 token completion
  预算全烧在 reasoning 上（content 空、finish_reason='length' ⇒ truncated 确定性终态）
  + 1 次 span 计数滑步；全部失败关闭、零语义成分。Contract-Freeze §6 该行自带
  "盲测期截断率 > 2% ⇒ 重新裁定"条款——按条款提交用户裁定，用户选**上调并重跑**。
- **不是调参凑数（M85-D16 边界论证）**：该值的历史就是推理预算适配（2,000 →
