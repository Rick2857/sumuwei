## 3. 为什么 M9.1 的激活**没有**任何真库操作（与 M9 的 ADR-071 §2/§4 不同）

| 面 | 是否需要激活期对真库执行动作 | 理由 |
|---|---|---|
| **F-4 重述复活** | **否** | 只在**未来**发生一次重述时发射标记；无回填、无播种、无投影重建。历史事件（无标记）在新代码下**逐字节原解释**（D07）；`MEMORY_REDUCER_VERSION` **不变**（D06）⇒ 无 fail-close、无 rebuild 必要 |
| **F-1 装配层遮蔽** | **否** | **读侧**逐轮计算（撤销集从既有表 + 事件面推导，`withdrawnSetCore` 单点）；**无**预计算表 / 缓存表 / 新表新列（D16） |
| **F-5 / WP8 身份推导** | **否** | 只改**形成时**的身份分量。既存信念若要重新形成，只会在**复活**（`revision>1`）时发生，而复活在 M9.1 之前**从未成功过**（F-4 的确定性 id 撞线）⇒ **没有既存信念需要重新推导身份** |

⇒ 激活 = **纯配置变更**。因此本轮**没有**执行「合法启动建档 / SELECT-only 真库读回」，
**真实库在本次激活中未被打开**（参见 §4 的读回性质）。

## 5. FIRST-USE NOT OBSERVED

**CONFIG ENABLED / NO DB OPERATION / FIRST-USE NOT OBSERVED**：
开关已开且配置层读回为正（§4），但**真实对话轮尚未发生**——
轮级观察面（`withdrawn_masking` trace 步骤、`belief_context`、复活形 `MEMORY_CREATED` 的
`restatement` 标记）待用户下一次真实聊天。**不凭配置宣布运行验证通过**。

首个真实轮的观察项（照候选 §4）：

1. 有遗忘史会话里 `withdrawn_masking` trace 步骤出现与占位计数；
2. `belief_context` 是否 `included`（M9 激活时同为 `FIRST-USE NOT OBSERVED`）；
3. 若发生「忘掉/更正后重述」，事件应带 `restatement` 且 `valid_from` = 复活时刻、可召回；
4. 双流水位追赶至账本尾、`failed=0`；
5. 异常 ⇒ 回滚（§6）+ 按 INC-01 走 INCIDENT HOLD（**不**自动修复）。

## 6. 回滚

**回滚 = 删掉 §2 两行（或置 false）**。遮蔽与发射即停；`MEMORY_*` / `BELIEF_*` 事件与投影**保留**；
schema 无新增 ⇒ 无迁移回滚问题。

⚠️ **回滚不是天然安全**（ADR-072 D07）：**若已发生并提交过复活形事件**（带 `restatement` 标记），
删开关后**投影仍保留复活**（append-only：开了再关，已复活的记录保持复活），
但**回滚到旧代码**后 `rebuild` 会**丢复活**（旧 `applyCreated` 不读该字段）。
⇒ 回滚窗口内**不得**把「切回旧提交 + 重建投影」当作无副作用操作；
未发生复活前回滚则完全无副作用。
