# ADR-115：故事接入日常聊天

状态：ACCEPTED / EXECUTED。日期：2026-10-07。

用户授权：「先把缺口补上」，故事成为日常启动的一部分，「聊到了就推进没聊到没事」，不再要求单独调用开局入口。

本裁定取代 ADR-094 D02.2① / ADR-107 R-2a 对本次日常模式的手动开局要求；历史设计与读数保留。

1. 日常启动装配故事服务。无既有经历时只预览入口；首次相关对话才通过既有提交口开局。无关轮零世界写入、零世界上下文。
2. 模型在一次有界决策中判断本轮是否相关及用户是否作出当前合法选择。相关但未选择只呈现场景；含糊、建议、假设、否定不作为用户选择。引用必须来自本轮原话；语义误判风险 L-S8-31 保留。
3. 开局标为 system；选择锚定真实用户事件和真实 conversationId。重启从账本恢复，不重复开局；已结束故事不自动重开。
4. 当前节点、已经提交且角色可见的事件和待选选项由内容资产渲染，经现有 world-observation section 进入主回复。候选明确标为未发生，模拟结果不升级为现实事实。无关轮不注入这个 section。
   日常模式另带不可裁的 story-turn-scope 指令：本轮相关/无关/解析不可用来自程序结果。普通聊天不主动拉回故事，模拟中的日期和约定不升级为现实安排。它不含模拟事实来源，不混入用户原话。
5. 到达结果节点后由既有世界判定器提交确定性结局，不交给模型编造。认知消费仍走原有放行口和独立水位；轮尾执行。
6. 新模式代码缺省关闭。用户本轮请求授权在检查通过后启用当前工作区的日常模式及选择解析；不新增 DDL，不改人设和历史证据，不运行生产实验对话。

认知完整性审查：授权来自本轮用户；开局、选择、结局全部走 commitStoryTurn；system 不冒充用户选择；会话与锚由服务端给；解析失败/无关零写入；来源保留 storyId/version/runId/eventId。启动待命不写长期认知。开局、选择、结局是分阶段的既有提交，后续阶段拒收不撤销先前合法提交，按账本事实恢复。

验证：相关/无关/无选择/拒收/失败恢复/跨重启/确定性结局/不自动重开；真实 TurnGateway 中世界 section 与 current-input 分离；真实 main.ts 离线整链；有限真实模型语义检查；typecheck、相关门和完整 CI。结果追加到交付报告。

执行读回：`.env` 启用 `CHARACTER_STORY_CHOICE_DECISION_ENABLED=true` 和 `CHARACTER_STORY_DAILY_ENABLED=true`；既有 `CHARACTER_STORY_COGNITION_ENABLED=true` 保留，代码缺省三项仍 false。默认故事决策期限 8000ms，真实隔离短链已复验。停服授权来自用户本轮追加答复「暂时停止 QQ，检查后重启」，关库记录 cleanClose=true；未发送生产实验消息。验证与剩余边界见 [交付记录](../post-lv2/S8-Daily-Conversation-Report-2026-10-07.md)。回滚日常接入：将新增两项设 false；既有账本和认知消费记录保留。
