# M9.5 → M10/M11 交接（计划 §4.4 的**稳定边界**）

> 日期：2026-09-28 · 机器判据：`pnpm m9.5:compat:verify`（**5/5**）· 计划 §4.4（7 条，逐字对齐）
> ⚠️ 本文件是 M10（Goal）/ M11（Reflection）开工时要读的**唯一**边界说明。

---

## 1. 可用的能力（M9.5 实际交付的）

```text
① **检索请求带版本**：`RecallRequest.retrievalPolicyVersion`（`lexical-recency@1` / `hybrid-relevance@1`）
   与 `semanticMode`（`off` / `shadow` / `on`）—— 未知值**被拒**，不是静默回落。
② **引用可追溯**：`RecallReference = { memoryId, sourceRevision, evidenceIds }`
   —— **只有 ID + 版本 + 证据 id**，**没有**"可直接当新事实"的摘要文本。
③ **资格与排序分离**：资格层（`memoryIntegrityProblems` / 根证据）→ 通道合并 → 排序 → 截断 → 选择，
   逐层计数守恒由 `m9.5:context@1`（11 条不变式）守着。
④ **语义分数是真分数**：`available` ⟺ **真的拿到分数**；否则**具名降级**
   （`not_indexed` / `model_missing` / `dimension_mismatch` / `timeout` / `generation_mismatch` / `missing_score`）。
⑤ **两种模式可观察**：`shadow` 会算并记录新旧顺序对照，**但实际回复只用旧路径**。
```

## 2. 读取契约（**逐条**对应计划 §4.4）

| §4.4 | 契约 | 机器判据 |
|---|---|---|
| ① 请求带 character/user/目的/时间/预算/**调用版本** | `RecallRequest` 已含 `characterId` / `user` / `intent` / `timeScope` / 预算 / **`retrievalPolicyVersion`** | `m9.5:test@1`（策略/模式版本化 + 未知值被拒） |
| ② 引用可追溯，**不返回可当新事实的摘要文本** | `referencesFromOutcome()` 产出 `RecallReference[]`；`RecallReference` **没有**自由文本字段 | `m9.5:compat@1` |
| ③ **"没找到"不是反证 · "相似"不是蕴含 · "多次取回"不是独立证据** | 语义分数只进**排序**，**不**进事实采信；通道登记 `semantic.produced = false`（未激活前） | `m9.5:retrieval@1`（D26：禁绝对阈值）· `m9.5:semantic@1`（R3 伪启用防线） |
| ④ M10 读到偏好**可作规划输入**，**不等于**授权执行或新承诺 | `goalFixtureConsume()` 返回 `executionAuthorizations: readonly never[]` 与 `newCommitments: readonly never[]` | `m9.5:compat@1` |
| ⑤ M11 形成**独立待审**反思提案，**不得**直接把索引文本写回长期状态 | `reflectionFixtureConsume()` 的 `status` **只能是** `pending_review`，且 `stateWrites: readonly never[]` | `m9.5:compat@1` |
| ⑥ 后续异步工作**使用前必须再次回查有效性**，不得长期持有一次检索的授权快照 | `recheckReferences(refs, lookup)` —— 每次使用前重查 `currentRevision` / `stillValid` | `m9.5:compat@1` |
| ⑦ **两个纯 fixture consumer**；**不创建** Goal/Reflection 的空生产服务 | `goalFixtureConsume` / `reflectionFixtureConsume` 都是**纯函数**；仓库里**没有** Goal/Reflection 生产服务 | `m9.5:compat@1` |

## 3. 待办（M10/M11 侧）

```text
· M10：把"偏好"当**规划输入**用；**不得**把检索到的偏好读成"用户已授权执行"。
· M11：反思提案**只**产出 `pending_review`；写回长期状态**必须**走 M4 的提案管线（不得绕）。
· 两侧都必须：**每次使用引用前**调 `recheckReferences`（§4.4⑥），不得缓存"当时有效"的快照。
```

## 4. **不能外推**之处（诚实边界）

```text
· 语义召回**未生产激活**：`.env` 未设 `CHARACTER_MEMORY_SEMANTIC_ENABLED`；通道登记 `produced = false`
  ⇒ 当前真实对话里**不会**走语义通道（缺省 `off`）。
· 词面权重**冻结在等权**（`{1,1,0.5}`）：有限校准 = **NOT MET**（自然场景等权已满分 ⇒ 无改善空间）；
  ⚠️ **对抗场景**下等权**会输**（诱饵语义 0.99 / 目标 0.01 ⇒ 目标 rank 2）—— 见 `L-M95-18`。
· 真模型档**只跑到小批预检**且 **NOT MET**（1 条关键错误：`neverSaved` 被断言成"记得"）⇒
  **不得**把本里程碑的语义能力当作"已验证可用"；见 `M9.5-FMB-01`（立案 OPEN）。
· 换模型（A3）**没有**买到顶层精度（保留 E5）；**bge-m3 那一档未测**。
· `A4`（reranker）/ `A5`（ANN）**未做**。
```
