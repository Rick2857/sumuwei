## 2. 链路（一次检索实际走的路）

```text
① 装配：`src/main.ts` 的 `buildRecallTurnPort()` —— **开关打开时**才构造探针
       （开关 `CHARACTER_MEMORY_SEMANTIC_ENABLED` 缺省 **false**；模式缺省 `shadow`、非法值 ⇒ `off`）
② 资格层：`memoryIntegrityProblems` + 根证据读数 ⇒ 不通过者**出局**（不是"降权"）
③ 通道：词面（`listBySubject`）与语义（探针 `score()`）各自给分；
       `semantic` 通道登记 `produced = false`（**未激活前如实**）
④ 语义分数：`semanticSignalOf()` —— `available` **必须**有真分数，否则**具名降级**（R3）
⑤ 合并：`mergeChannelHits()`（按 Memory ID 合并，两条通道**都记录**）
⑥ 排序：`orderCandidates({ policyVersion })`
       · `lexical-recency@1` = **新近度降序 + id 升序**（与旧比较器**逐字一致**）
       · `hybrid-relevance@1` = 相关性降序 → 新近度 → id
       相关性 = `lexical·w_l + semantic·w_s + margin·w_m`；**冻结值 `{1, 1, 0.5}`**（用户裁定甲）
⑦ 截断：`truncateCandidates()`（自检"丢掉的最旧 vs 保留的最新"）
⑧ 记账：`checkRecallAccounting()` 11 条不变式（`considered` = 各层去向之和）
⑨ 交接：`referencesFromOutcome()` → `RecallReference[]`（**只有 ID/版本/证据 id**）
```

## 3. 派生索引（D31：**不进 kernel 迁移链**）

```text
· `SEMANTIC_INDEX_SCHEMA_VERSION = 1`；DDL **单一来源**（`memory_semantic_meta` / `_generations` /
  `_index` / `_scope` / `_failures`）；升级表当前为**空**（版本 1 无 1→2 路径）。
· `ensureSemanticIndexSchema()`：幂等（noop 发 0 条语句）· **拒绝更新版本**（fail-closed）·
  中途失败**回滚**（不留半成）。
· 维度承诺 **384**；换维度 = **新版本 + `alter column`**（不许就地改）—— 这正是 A3 只能在**库外**做的原因。
· 写入前 `validateSemanticVector()`（D28）：维度 / NaN / Inf / 零模 / 未归一化 各自具名拒绝。
```

## 4. 隐私与出站边界

```text
· 编码子进程**先** `installNoEgressGuard()` 再 import 任何东西 ⇒ `allowRemoteModels = false`；
  违规抛 `m95_no_egress_violation`，日志**只**记 `protocol//host/…`（不记正文）。
· `m9.5:privacy@1`：无私人文本出站（结构性守卫**两向**）· 诊断不泄漏（哨兵）· 查询**零写**。
```

## 5. 模式（`off` / `shadow` / `on`）

```text
· `off`：**零**探针调用（`m9.5:modes@1` 断言调用数 = 0）。
· `shadow`：**真的算**语义分数并记录新旧顺序对照，**但实际输出只用旧路径** ⇒ 输出与 `off` **逐位相同**。
· `on`：语义参与排序 ⇒ 顺序改变（目标从"被丢掉"变成"入池并靠前"）。
· 探针失败时**一律降级**到旧路径，且**不发明**对照（`shadow` 下不编造"新旧不同"）。
```
