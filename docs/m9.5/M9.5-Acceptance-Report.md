## 3. 这一轮真正买到的东西（三条，都有读数）

```text
① **层④缺口在真链路上被修好**（WP0 定位 → WP6 接线 → WP9 端到端复核）
   同一句话、同一批记忆（目标最旧但唯一相关）：
     旧路径：召回选中 **0** 条 ⇒ 编译后的 prompt 里**没有**它（7068 B）
     `on`  ：召回选中 **1** 条 ⇒ **进了** prompt（7551 B）
   500 轮规模上：`on` 有 **451/500** 轮与旧路径不同，末轮选中 0 → 1。

② **"取消"从"看起来能取消"变成"结构性可回收"**（L-M95-01 的 ADDRESSED）
   取消 = SIGKILL 子进程 + 观察到退出事件 + 杀后零输出；机器利用率 97.7% → 3.0%。

③ **"语义启用"不可伪造**（D25④ / R3）
   `available` 只由"本次是否真拿到分数"决定（真分数与数据库余弦偏差 **0.00e+0**），
   而 `shadow` 在 **500/500** 轮里与旧路径选择**逐位相同**（却真的算了 500 次分）。
   ⇒ "算但不影响输出"与"伪启用"这两件事第一次变得**可分辨**。
```
