## 2. 为什么**不**宣布 `M9.5 = PASS`

```text
计划的 WP10 出口是「质量 / 真实链 / 人审**三项分列**」。今天：
  · **人审已有裁定**（2026-09-29 **声明式**：材料四轮修订后用户审毕、与答案核对**无异议**）——
    载体 `artifacts/m9.5/local/blind-review-record.md`；⚠️ 判定写在**纸上**、**未**数字化 ⇒
    记**声明式裁定**（M8 先例），**不**主张"独立盲审"；机器可核的那一项（量具 30/30 符合期望）单列
  · **有真模型读数**（32 条 · 8/类 · 修后**连续两轮 MET**）—— 见 §1 的 live 行
  · **校准链已完成三步**，且参数**已冻结**（用户裁定**甲**：维持等权；`calibrated: true`）
    （等权下"语义领先但无词面"的诱饵**可以压过**字面精确命中）⇒ 是否给字面命中保护**是你待裁定的那一件事**
⇒ 工程面全绿**不能**替它们说话。把"硬门 PASS"读成"她记得对了"，
   正是本计划 §22 与 M6/M8 都点名禁止的那种合成。
```

**可以判的**：WP0–WP9 的**工程结论**（机制、边界、可查、可复现、失败关闭）+ 校准链的**方向性读数**
（A2 相对 A0 的改善在 dev 与 val **都**成立；⚠️ **幅度不可移植**：dev 改述首位 8/18 vs val 2/16）。
**不可以判的**：召回**质量**、真实模型下的行为、是否可投入生产。
