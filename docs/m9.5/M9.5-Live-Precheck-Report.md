## 9. 第三轮 + **门槛分辨率问题**（2026-09-29，Round 105）

```text
R1: (a) 95.8% ✓ · hard 100% ✓ · unknown 83.3% ✗ · (c) 4.2% ✗ · (d) 1 ✗
R2: (a) 91.7% ✓ · hard 83.3% ✗ · unknown 83.3% ✗ · (c) 8.3% ✗ · (d) 1 ✗
R3: (a) 91.7% ✓ · hard **66.7%** ✗ · unknown 100% ✓ · (c) 8.3% ✗ · (d) **0** ✓
```

**`ambiguousSubject-0002` 未复现**（R3 她只要求澄清、没有断言）⇒ 复现次数 **1/2** ⇒ **不作稳定结论**。

### ⚠️ 本轮发现的**判据分辨率问题**（与 `L-M95-26` 的"分母"问题同族）

```text
每类只有 **6** 条 ⇒ 一条 = **16.7%**；而门槛是 **≥85%** ⇒ **5/6 = 83.3% < 85%**
⇒ **"每类 ≥ 85%" 在 n=6 时等价于"该类一条都不能错"**。
⇒ 门槛的**分辨率（16.7%）大于它与阈值之间的余量（1.7%）** ⇒ 三轮里 hard 从 100% 掉到 66.7%，
   **每次都是"某一条个案"在决定整类是否达标** —— 那不是"质量波动"，是**判据的分辨率不足**。
⇒ 要"85%"真正可判，需 `1/n ≤ 15%` ⇒ **n ≥ 7**（n=7 时 6/7 = 85.7% ≥ 85%，允许一条失败）。
   **这是用户的口径裁定**，工程不擅自改。
```

### 建议（待用户定）

```text
(甲) 保持每类 6 条，但把判读口径改为"**每类一条都不能错**"（= 承认 n=6 下的实际门槛）；
(乙) 提到**每类 7–8 条**（24 → 28/32 条），让 85% 允许一条失败；
(丙) 不改样本，改为**多轮聚合**（例如 3 轮 × 24 条 = 72 条/类·18），用总分母判 —— 需要先实现 `--runs` 循环。
```
