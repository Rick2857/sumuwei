## 2. F-4 机制与隔离复现（场景 A/B/C）

```text
确定性 id：makeMemoryId(characterId, slot) ，slot 含内容指纹
  ⇒ 同内容重述 ⇒ 同 memoryId（读数 A-1：same=true）
```

### 2.3 对照与延伸

- **R01 对照（场景 B）**：ACTIVE 同内容重复 ⇒ 去重层拦截 `already_applied`、单条 CREATE、状态 active——**既有 D2 语义正确，修复不得动它**。
- **R03 基线（场景 C）**：`记住 v1(不吃香菜) → 更正 v2(能吃香菜) → 逐字重述 v1`：
  - 冲突面：`analyzeConflict` 判无时间标记矛盾 ⇒ `MARK_DISPUTED`（v2 被标争议；v1 保持 superseded）——**D-55c 正确生效，无未经授权覆盖**；
  - 缺口面：重述值**未被记录**（v1 无新 CREATE；槽内零 active ⇒ 「不吃香菜」不可召回），而 `translate` 给 `written` ⇒ 假成功口吻；
  - 全库终态：`[like:disputed | dislike:superseded→like]`。
  - **结论**：R03 的「原冲突政策生效」半边现状已满足；「回复与实际程序结果一致」半边与 F-4 同源（`runMutation`/`translate` 不区分「用户要的动作」与「实际执行的动作」）。WP1 须把 dispute 路径的如实表达纳入契约。
- **幂等面（工具开发中实测）**：同一触发事件的重复执行被幂等键拦截（`already_applied`）——R05 的既有机制在位；复现量具因此改为**单次执行经生产 turn 端口**（第一版直调 service 后又走端口，第二次执行撞幂等键污染读数——已修正并记录）。

**判定点**（计划书 §4.3 / M9.5 §10.2 对齐）：最终判定必须发生在 **ContextCompiler 接受最终证据集合之前**——即 Recent 行进入 `compileInput.recentEvents` 之前（装配层），不是召回后、不是 trace 里。

**关键设计事实**（WP1 ADR 输入）：

1. `applyRetracted` 只写 `status` + `updatedAt`——**撤回原因不在记录上**，只在 `MEMORY_RETRACTED` 事件 payload（`reason: 'explicit_forget' | 'explicit_correction' | 'audit'`）。遮蔽端口须读事件面（或以记录+事件联读）区分「明确遗忘」与「审计撤回」。
2. retracted 记录**保留 sourceRefs**（`...state` 展开）——被撤来源集合可从记录面读取。
3. `canonicalKeyOf` = owner+subject+type+predicate+qualifier（**不含 value**）——「同值不同人/主体」天然分槽（P06 的结构基础在位）。
4. rollup 资格闸以「事件 → 记忆根 → 状态」关联（`memory_evidence_links`）判定失效——Recent 遮蔽可复用同一关联语义（被撤记录的 sourceRefs = 被撤事件集合）。

## 7. WP1 待决项（移交清单）

1. F-4 标记字段的具体形状（`restatement?: { previousRevision; previousStatus }`）与 `validatePayload` 放行；`MEMORY_REDUCER_VERSION` **不升版**的论证（升版会 fail-close 全部存量记录）。

3. dispute 路径回复真话（C 发现）：`MARK_DISPUTED` 结局的如实翻译（「已标记存疑，没有直接改」），不得沿用「记住了」。
4. F-1 遮蔽范围裁定：`explicit_forget` ⇒ 记录 sourceRefs ∪ 同槽 superseded 链 sourceRefs；`explicit_correction`/`audit` ⇒ 仅记录自身 sourceRefs（普通更正历史沿原政策可查，P07）；assistant 行按 `replyToEventId ∈ 被撤集合` 关联（P03）。
5. F-1 失败关闭形态：撤销证据读失败 ⇒ 本轮不供给 Recent（如实降级 + trace），不得伪装「用户从未说过」；正控防全量禁用退化。
6. 开关命名与消费点（`CHARACTER_MEMORY_RESTATEMENT_ENABLED` / `CHARACTER_WITHDRAWN_CONTEXT_MASKING_ENABLED`，缺省 false，必须有真实消费者——D3 教训）。
7. 回退论证：旧代码读新标记事件 = no-op（rebuild 会丢复活）⇒ 回滚候选必须写明「回滚后需重建投影或接受复活丢失」，不能把切回旧提交当天然安全。
