## 4. 实现期教训（已固化在脚本注释）

1. **R12 的信念形成必须走「记忆依赖路径」**：首版用独立会话线索形成 inferred 信念——它**不依赖记忆**，
   遗忘记忆后幸存（正确行为，但**不是**长门 LL-C3 的形状）。改由记忆调和流形成 reported 依赖信念后 LL-C3/C4 翻绿。
2. **召回段 sourceRef 格式带 `memory:` 前缀**：断言 `memoryInModel.includes(mid)` **永假**；
   正确是 `memory:{id}`（调试读数定位，非系统缺陷）。
3. **探针查询词面要与槽位 haystack 重叠**：检索通道是词面重叠匹配——「你记得我怎么想的」不命中
   是检索**既有行为**，不是本场景判据面。
4. **`digestTree` 比较必须比 `.treeSha256`**（对象引用比较恒假——量具自身的坑，已修）。
5. **网关 `conversationSequence` 闭包读 `syncSeq` 维护的序号**，不能换成无条件抛的守卫。
6. **R03 的 oracle 是 dispute 不是 overwrite**（`disputed:brief superseded:detailed`）——契约语义，
   不是防御性断言（`7bc7c1f` 修正）。
