## 3. 实现期教训（已被 WP3/WP4 消费）

1. **量具与生产同语义**：`computeWithdrawnSet` **委托生产端口**，不另写一份集合逻辑——否则「量具绿」与「生产行为」无法互相证明（D16 单一事实源）。
2. **计数型检测器必须自检 `measured_count > 0`**（`F4-M1` / `WS-P1`）：`0 检查 / 0 不一致` 与「全部一致」在输出上不可区分（AGENTS §6.8）。
3. **「缺口具名」是失败关闭的一部分**：`reason_missing` / `orphan_no_sources` / `chain_truncated` —— **不伪装零结果**（D19 同族）。
