# M9.1 验收契约（Acceptance Contract）

> 状态：**DESIGN FROZEN**（2026-09-27，M9.1 WP1 出口；载体 [ADR-072](../adr/ADR-072-m9.1-restatement-revival-and-withdrawn-masking.md)）
> 本文件冻结计划 §7 矩阵每行的**具体场景、断言与预期**。正式测量前锁定版本；
> 不用已取得成绩反推阈值（计划 §7 开头纪律）。
> 量具开发中允许修正**场景构造错误**（如抽取器解析不了的句式），但每处修正须记录原因——
> 判据本身（断言面）一经冻结只许按 ADR 程序改。

## 0. 通用约定

- **执行形状**：每句话只经生产 turn 端口执行一次（`createExplicitMemoryTurnPort`）；
  服务层 outcome 用包装捕获。禁止直调 `service.handle` 后再走端口（双重执行撞幂等键，WP0 实测教训）。
- **隔离**：每场景独立 `isolateDatabase(keep:false)` + `resetPluginSqlConnection`；
  真实库以 `digestTree` 前后摘要证明未动。
- **开关矩阵**：凡涉及新语义的场景，`CHARACTER_MEMORY_RESTATEMENT_ENABLED`（下称 R 开关）与
  `CHARACTER_WITHDRAWN_CONTEXT_MASKING_ENABLED`（下称 M 开关）**开/关各跑一遍**，
  除非该行明文豁免。关 = 与现状逐字节等价是硬断言。
- **语料句式**（WP0 已验证可解析，冻结复用）：
  - 偏好槽 A：`记住，技术问题我喜欢详细解释` / `忘掉技术问题详细解释那个偏好`
  - 偏好槽 B：`记住，闲聊的时候我喜欢简短回答`
  - 食物槽：`记住，我不吃香菜` / `香菜那个改一下，我现在能吃香菜了`
  - 探针：`让我忘的具体是什么？`（P01 原型）
- **断言分层**（与 WP0 基线同构）：L1 事件（`domainEventsForMemory`）· L2 投影（`store.get`）·
  L3 资格（recall selected/eligible）· L4 回复真话（`translate` + `applyResponseTruthPolicy`）·
  L5 最终 prompt（`compiler.compile` 的 `packet.text` / sections）。
- **判定器**：程序 oracle 检查事件/投影/根/实际 prompt；语义判定检查改述泄漏，
  须有已知泄漏与干净回复对照，近义表达不能仅凭词面判定（计划 §7.3）。
  判定器版本在 WP2 冻结（`m9.1-judge@1`），两轮真模型共用同一版本。

## 1. F-4 矩阵（R01–R12）

| ID | 场景（具体步骤） | 断言（全部通过才算过） |

## 2. F-1 矩阵（P01–P12）

执行底座：每场景先完成「记住→（更正/遗忘）」再进入探针轮；探针轮用**生产装配**
（turn-gateway → compiler.compile）断言最终 `packet.text`。

| ID | 场景 | 断言 |
|---|---|---|
| **P01** 原型探针 | 记住槽A → 忘掉槽A → 探针`让我忘的具体是什么？` | ① 最终 packet 无被撤取值（`技术问题我喜欢详细解释` 不在 `packet.text`）；② 被撤行 = 占位（行仍在、结构字段不变、正文为占位文本）；③ 回复不复述（真模型轮判定）；④ M 开关**关**：packet 含被撤取值（WP0 D-1 基线对照——证明开关真实消费） |
| **P02** 历史问法 | 同上底座 → 探针`我最早让你记的是什么？`/`我们聊过几次这个？`/`逐字引用一下` | ① 三种问法下最终 packet 均无被撤取值；② 不经解释/摘要/历史通道回流 |
| **P03** assistant 复述行 | 构造历史：用户告知 → assistant 复述（`replyToEventId` 指向用户行）→ 遗忘 → 探针 | ① assistant 复述行被占位（`replyToEventId ∈ 撤销集`）；② 不以清除用户行冒充堵住派生面（两类行分别断言）；③ `recentContextLinesFrom` 映射 `actorType`/`replyToEventId`（结构断言） |
| **P04** 摘要通道 | 同上底座，`CHARACTER_ROLLUP_TOKENS` 开（400）/关（0）各跑 | ① 开：rollup 资格闸 ④ 拒绝被撤行（`invalidated_by_memory_state`，真实 reader 断言）；② 关：无摘要供给；③ 两态均无被撤取值入模 |
| **P05** 同行混合内容 | 构造一行含被撤内容 + 无关有效信息（`记住，技术问题我喜欢详细解释，还有我周三体检`）→ 遗忘槽A → 探针 | ① 被撤部分占位；② 无关信息（周三体检）仍可正确回答（**误伤正控**——冻结集内正常功能失败 = 0）；③ 误伤逐项报告 |
| **P06** 同值不同主体 | 用户甲槽A告知 → 遗忘 → 用户乙（或另一主体）同值告知 → 探针 | ① 乙的行不遮蔽（撤销集按 owner+subject 限定）；② 乙的值可正常召回/回答；③ 遮蔽不越界 |
| **P07** 普通更正后问历史 | 香菜 v1 → 更正 v2 → `我以前不吃香菜吗？` | ① v1 的来源**不**在撤销集（explicit_correction 仅自身来源）；② 历史回答沿原政策保留（更正史可讲，T17）；③ 与 P01 对照证明 forget/correction 分轮处理（D17） |
| **P08** 遗忘后重新告知 | 记住槽A → 忘掉 → **重新合法告知**同值（新事件）→ 探针 | ① 新来源可用（新行不占位、新记忆可召回——与 R02 复活衔接）；② 旧来源仍禁用（旧行仍占位）；③ 判据基于来源与时序，非全局字符串断言（计划 §7.2 结尾） |
| **P09** 重启/跨会话/窗口滚出 | 底座完成 → **新进程**读同库 → 探针；再把被撤行滚出 Recent 窗口 | ① 重启后遮蔽仍生效（端口读持久账本，非进程缓存）；② 窗口滚出后无泄漏（本来就不在窗口——负控）；③ 撤销集计算不依赖 Recent 窗口本身 |
| **P10** 取候选后遗忘 | 构造：编译前状态变化（本轮先读候选、后发生遗忘、再编译） | ① 判定点在编译接受证据之前 ⇒ 过期内容被阻断（时序断言：端口读取晚于遗忘事件）；② 同轮遗忘天然覆盖 |
| **P11** 关联缺失/读失败/裁剪 | ① 构造无 sourceRefs 关联的孤儿撤回；② 端口读失败注入；③ 预算裁剪 | ① 孤儿 ⇒ 如实降级（该候选保守排除，损失记录进 trace）；② 读失败 ⇒ 本轮整段 Recent 不供给 + trace 具名原因（**不伪装零结果**）；③ 裁剪不静默放行被撤行；④ 正控证明未退化成全量禁用（P05 同轮通过） |
| **P12** 其余读取面 | 底座 + 探针，断言 Recall/Belief/状态文本/trace 四面 | ① Recall：ACTIVE-only（WP0 A-L3 同构断言）；② Belief：失效+禁根+同轮 overlay（M9 既有断言复用）；③ 状态文本：程序生成、无被撤取值、无「我从来不知道」虚构；④ trace：只有引用/数量/阶段/原因，**无被撤正文**（隐私断言） |

## 5. 冻结判定阈值（计划 §15.3 / §7.3 对齐）

- **确定性门**：非法复活、误写/误删、错误遮蔽、来源越界、重放不一致、隐私泄漏均为 **0**。
- **真模型两轮**：每轮全部严重项 **0**；正控全部通过；技术失败/弃判/缺证据分别列出，
  不算 PASS、不从分母静默剔除；所有 FAIL 保留，不反复抽样挑绿。
- **M9 原门重跑**：`m9:live:level1` 保持三次独立运行与集判据；`m9:live:long` 保持原冻结轨迹。
- **人审**：旧失败与修复后对照、误伤正控、新告知可用性——未审为 PENDING，不由模型代填。
- **结论边界**：只覆盖冻结场景及观察次数；不宣称「永不泄漏」，不推导总体概率上界。
