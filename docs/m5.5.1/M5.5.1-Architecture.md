## 1. 它在 M5.5 之上加/改了什么

M5.5 已经有：`web.search` 能力、外部证据契约、证据预算（缺省 0 ⇒ 不可注入）、账本只落引用、
五态回复、程序生成的来源附录、开发者面只读上报可用性。**M5.5.1 不动这些**，它改的是**"什么情况下允许出站"**：

```text
旧形状（M5.5）：显式搜索词形命中 ⇒ 直接构造查询并出站（命中即放行）
新形状（M5.5.1）：任何可能出站的路径都必须先经过**同一次结构化的"搜索需求判定"**，
                  再由**程序**绑定授权；判定失败/超时/形状非法 ⇒ **零搜索**（失败关闭）
```

## 2. 两种模式（`CHARACTER_WEB_SEARCH_MODE`）

| 有效状态 | 合法显式公开搜索 | 无搜索词、需公开查证 | 禁止 / 私人 / 范围不明 |
|---|---|---|---|
| 总开关 off | 0 次（可审计的不可用） | 0 次 | 0 次 |
| on + `explicit` | 校验后最多 1 次 | **不自动搜索**（可说明需要查证） | 0 次；必要时澄清 |
| on + `auto_public` | 校验后最多 1 次 | 提案通过后最多 1 次 | 0 次；必要时澄清 |

- `CHARACTER_WEB_SEARCH_ENABLED` 仍是**最高级总开关**。
- **非法模式值 ⇒ 配置错误 ⇒ 禁止搜索**（不静默变成自动模式）。
- **`explicit` 也不保留"命中即出站"的捷径**[^r2]：显式路径同样必须取得合法判定。
- `dryRun` 语义不变：不调用新增的需求判定模型，也不调用搜索适配器。

[^r2]: ADR-049 §11 R2 裁定。

## 3. 一轮的顺序（实际接线）

```text
受信用户事件 + 程序授权模式
  → 既有本地动作优先规则 / dryRun / 总开关 / 已知禁止条件
  → **最多一次**结构化需求判定（判定器不得直接调用搜索）
  → 严格解析 + 按 querySpan 从**当前事件**切片 + 模式/范围/限额校验
  → 受信归因绑定 + ActionRequest（授权由程序写，模型不能填）
  → 既有 Policy → Gateway → WebSearchAdapter → SearXNG
  → 既有 ExternalEvidence 验证 / 选择 / ContextCompiler（缺省额度 0 ⇒ 不注入）
  → 最终回复 → 既有守卫 + 程序生成的来源附录
```

**纪律**：判定发生在最终回复**之前**；判定 prompt 走 `ContextCompiler` **唯一入口**
（不在 SDK 适配器里另造上下文）；判定**不读**长期记忆/人设/历史来拼 query；
本地优先不因自动路径被绕过。

## 4. 结构化提案的契约（模型能给什么）

```text
decision : answer | search | clarify | deny_search
reason   : explicit_public | freshness | needs_verification |
           no_external_need | user_denied | private_scope | ambiguous
querySpan: { start, end }        # 只在 search 时允许；JS UTF-16 索引
```

**模型不能填**：`authorized=true`、`initiator`、权限、端点、provider、次数、执行状态。
程序按 `querySpan` 从**原文**切片并校验（整数 / 范围 / 非空 / 长度 / 字段组合）；
越界、空白、未知字段、不合法枚举一律拒。**不静默截断**掩盖超长或歧义。

## 5. 有界性与失败关闭

| 项 | 值 / 行为 |
|---|---|
| 判定调用 | 每轮 **≤ 1 次** |
| 搜索 provider 调用 | 每轮 **≤ 1 次**（显式 + 自动不双发） |
| 判定超时 | `CHARACTER_WEB_SEARCH_JUDGE_TIMEOUT_MS`，整数 **1000..25000**，缺省 **25000**；**超时覆盖响应体读取**（读体与中止信号赛跑） |
| 非法超时值 | ⇒ `undefined` = **配置错误** ⇒ **不授予 `web:search`、不构造适配器与判定器**（不静默截断、不回落缺省） |
| 判定输出上限 | `SEARCH_NEED_JUDGE_MAX_TOKENS = 2400` |
| 判定失败（超时 / 非对象 / 非法枚举 / span 非法 / 内容不是字符串） | **搜索调用 0**，保留诊断状态，可降级为"无法查证"；**不回落旧 regex**、不补搜 |
| 重试 | **不重试**（异常 / 超时 / 重入同样不重试） |

## 7. 回滚（不需要动代码、迁移或数据）

```text
一级：CHARACTER_WEB_SEARCH_MODE 改回 `explicit`（或删掉）⇒ 只关自动触发
二级：CHARACTER_WEB_SEARCH_ENABLED=false ⇒ 适配器/权限受总开关控制，搜索调用 0
判定超时预算：显式设 15000 / 10000 / 5000（缺省 25000 ⇒ 最坏用户最多等 25 秒）
边界：一级回滚**只关自动触发**，保留本次已批准的否定/引用/私人误触发修复；
      **不能**宣称它恢复了旧 regex 的全部行为。已发出的 query 无法撤回。
```
