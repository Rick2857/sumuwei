## 3. §1 探针重跑（只读，不碰库、不调模型、不出站）

计划 §1.2 的八行**8/8 逐字复现**（capability 与 query 都一致）。完整表见 `baseline.json`。

**其中一行必须升级处置**（已登记为 `L-M55-16`，P0）：

```text
触发出网  web_search_zh_explicit  query="不要 索，只根据你已有的知识回答"
          ⟵ 不要联网搜索，只根据你已有的知识回答
```

**用户显式说"不要联网"时，系统仍然发一次真实搜索**，并把 `不要 索，只根据你已有的知识回答`
交给本机 SearXNG → 转发给 `duckduckgo / wikipedia / wikidata`。

两条根因（都能精确指到行）：

1. [`intent.ts:47-59`](../../src/kernel/action/external-evidence-intent.ts#L47-L59) —— **完全没有否定处理**：
   规则只匹配词形，`不要 / 别 / 不用 / 无需` 不在任何判据里。
2. [`intent.ts:50`](../../src/kernel/action/external-evidence-intent.ts#L50) —— 显式规则里写的是 `联网搜`（**没有**「索」），
   于是 `联网搜索` 匹配到 `联网搜` 后整段剥离，**留下孤儿「索」**。这是**纯字符串处理缺陷**，
   不是"语义不够聪明"；`上网搜索` / `网上搜索` / `搜索一下` 有同类风险，WP1 要一并查。

**用户的处置**（2026-09-20，已记录）：**M5.5.1 落地前保持激活开着** ——
也就是说这个窗口内"说了不要联网仍会出网"是**已知且被接受**的风险，由 M5.5.1 关闭。

## 附录 A（WP2b 补记 · 2026-09-20）：**§4 那个树摘要复现不出来**（量具方法缺陷，如实登记）

WP2b 收尾按 §4 的要求重采真实库读数时，发现：

| 读数 | 值 | 来源 | 今天能否复现 |
|---|---|---|---|
| M5.5 WP9 Live Smoke 的 `sourceDigestBefore/After` | `6ed679388e56f153183fb9308aaecabbbf17864f4980b9d1c24e1ae02ce1d56e` | `artifacts/m5.5/smoke/smoke-result.json`（由 `scripts/verify-m5.5-smoke-live.ts` 的 `treeDigest()` 生成，**方法在仓库里**） | ✅ **逐字复现**（今天重采得到同一个值） |
| 本文件 §4 / M5.5-Acceptance-Report §（WP10 前后对照） | `6dd8ac37…a5cc` | 手工/一次性读数 | ❌ **复现不出来** |

复现实验（对**同一批 1206 个文件**穷举 11 种常见行格式：`rel:size:hash` 用 `|` / `\n` / CRLF / 空串连接、
全排序、Windows 反斜杠路径、绝对路径、`sha256sum` 风格、`rel:hash`、`rel|size|hash`）
**没有一种**得到 `6dd8ac37…`；而 smoke 的 `treeDigest` 一次就得到 `6ed67938…`。

**结论（两部分，不要混）：**

1. **真实库没有被写过 —— 这条主张仍然成立，而且现在有更强的证据**：文件数 **1206**（与基线相同）；
   本轮复算得到 `6ed67938…`，与 **WP9 smoke 当时记录的读数逐字相同**；整棵树里**最新**的写入时间是
   **2026-09-20 08:38:14**，而本轮的门跑在 **18:26 之后**；各门自己打印的也是
   `真实库 …（本次不会被写入）`。
2. **§4 那一行"逐字相同"的证明力要下调**：`6dd8ac37…` 这个数**没有可复现的生成方法**
   （旁边写的"相对路径 + 字节数 + 每文件 sha256"按仓库里那份实现算出来是 `6ed67938…`）。
   按 §6.8 的纪律（"数字对 ≠ 数字描述的是你以为的那个东西"），它属于**方法不可复现的读数**，
   不能在后续 WP 里继续当成比对基准。⚠️ `artifacts/m5.5.1/baseline.json` 与
   `docs/m5.5/M5.5-Acceptance-Report.md` 里的该值**保持原样**（历史读数不改写）。

**自 WP2b 起的统一方法**（唯一基准，仓库内可复现）：

```text
方法：scripts/verify-m5.5-smoke-live.ts 的 treeDigest()（相对路径 + 字节数 + 每文件 sha256 →
      逐目录排序遍历 → rows.join('|') → sha256）
对象：data/pglite

```
