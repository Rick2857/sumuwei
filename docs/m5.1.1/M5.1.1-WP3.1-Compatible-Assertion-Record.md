## 变更明细（**用例名未改；测试条数不变：42 → 42**）

```text
文件：scripts/kernel-tests-m5.1.1.ts

(a) 夹具：LEDGER 的 id 由 'event-ledger' 改为 'kernel'
    原因：K-23 / R-20 冻结了 canonical ledger recorder = SYSTEM/kernel；
          旧夹具的 id 会让"回填行的 recordedBy"落在**非 canonical** 上。
    影响：任何用 LEDGER 当 recordedBy 的**回填行**用例的期望都随之更新。

(b) 正控（同一个用例的第 ③ 段）：回填行的 recordedBy
    旧：unknown('LEGACY_UNRECORDED')
    新：known(LEDGER) 即 Known(SYSTEM/kernel)
    原因：`Absent`/`Unknown` 的 recordedBy 现在是**违规**（迁移完整性失败），不再是合法形状。
    ⚠️ 这是**判据变紧**，不是放宽：旧形状（Unknown）现在会红。

(c) 新增第 ⑥ 段（负控组，5 个形态 + 1 个正控）：
    USER/kernel · CHARACTER/kernel · TOOL/kernel · SERVICE/kernel · SYSTEM/not-the-kernel
      ⇒ 都必须报 `migrated_legacy_recorder_not_canonical`（"recordedBy MUST NOT be caller supplied"）
    canonical（SYSTEM/kernel）⇒ 必须**静默**

判据强度对比
──────────────────────────────────────────────────────────────
旧：回填行的 recordedBy **完全没有被约束**（WP3 时留 Absent 也算合法）
新：必须**恰好**是 Known(SYSTEM/kernel)；缺失、别的 kind、别的 id **都红**
    ⇒ 能抓到旧判据抓不到的：调用方自报 recorder / recorder 缺失 / recorder 被 mutation
```
