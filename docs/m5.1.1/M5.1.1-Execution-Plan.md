# WP3 — Legacy Backfill

## Objective

实现历史 attribution 的确定性迁移。

## Principle

```text
Never infer what history did not record.
```

## Implement

按：

```text
event-family × slot
```

执行 D/P/U/N 规则。

不得：

```text
actor_type=user
→ actor=USER
```

不得：

```text
actor_type=user
→ contentOriginator=USER
```

无法确定：

```text
Unknown(LEGACY_UNRECORDED)
```

不适用：

```text
Absent
```

Legacy Axis B：

```text
source_kind
= legacy classifier output

source_authority
= UNCONFIRMED_ORIGIN

epistemic_source
= UNCONFIRMED_ORIGIN

attribution_origin
= MIGRATED_LEGACY
```

## Tests

必须对每个：

```text
event family × slot
```

精确计数。

至少验证：

```text
MIGRATED_LEGACY concrete contentOriginator count = 0
UNKNOWN* PrincipalKind count = 0
invalid kind/id/reason tuple count = 0
legacy USER_EXPLICIT fabrication count = 0
```

加入历史洗白 mutation：

```text
LEGACY_UNRECORDED
→ Known(USER)
```

检测器必须 FAIL。

## Production-copy

只允许：

```text

```

流程：

```text

→ copy
→ migration preview
→ apply on copy
→ count verification
→ replay verification
```

不得 destructive live production。
