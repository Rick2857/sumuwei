## 唯一一条 changed assertion

```text
文件      ：scripts/kernel-tests-m5.1.1.ts
用例      ：「回填行（MIGRATED_LEGACY）由回填规则管，但**不得伪造 contentOriginator**」
           （**用例名未改**；测试**条数未变**：42 → 42）
旧期望    ：codesOf(...).includes('migrated_legacy_fabricated_content_originator')
新期望    ：① user_message（contentOriginator = **U**）被填 Known(SERVICE)
             ⇒ codesOf(...).includes('migrated_legacy_u_slot_fabricated')
           ② tool_event（contentOriginator = **D**）被填 Known(USER / CHARACTER)
             ⇒ codesOf(...).includes('migrated_legacy_fabricated_content_originator')（值级，保留）
           ③ 正控：Unknown(LEGACY_UNRECORDED) 的形状仍然必须**安静**
           ④ **新增**正控：确定性工具行 Known(TOOL/weather) 必须**合法**
           ⑤ **新增**负控：N 槽位（tool_event.executor）被填值 ⇒ `migrated_legacy_n_slot_not_absent`
原因      ：K-20 —— 旧 blanket 规则（"任何具体 contentOriginator 即伪造"）与
           冻结的 D/P/U/N 矩阵、K-3 FINAL 冲突。用户 2026-09-18 裁定替换为分类感知判据。
影响面    ：**仅**这一条用例的"期望理由码"；它仍然**失败关闭**（伪造照样被抓住）。
```

**为什么这不算"放宽旧判据"**：

```text
旧判据能抓到的         新判据能抓到
─────────────────     ─────────────────────────────────────────────
回填行任何 Known(originator)  →  U 槽位 Known（含旧的 SERVICE 例）
                                 D 槽位 Known 与确定性证据不一致（**新**）
                                 contentOriginator = Known(USER/CHARACTER)（保留）
                        新增能抓到而**旧判据抓不到**的：
                                 N 槽位被填值（旧判据完全没查）
                                 P 槽位无独立行级证据却记 Known（旧判据没查）
唯一"不再报"的情形：D 槽位记录**与确定性证据一致**的 Known
                    —— 那本来就是**正确结果**（K-3 FINAL：tool_event.contentOriginator = D）
```

## 为什么**不**重发 WP1 的证据

`artifacts/m5.1.1/wp1-contracts.json` 是 **WP1 的历史权威证据**（F4：历史 evidence 永久冻结）。
本 WP 核对过它**没有快照**这条规则的内部形状（`fabricat` 命中 0 次；`MIGRATED_LEGACY` 仅出现在
`vocabulary.attributionOrigins`），且**契约测试条数仍是 42** ⇒ 该 artifact 的
`passed / failed / vocabulary / necessityMatrix / axisB` 逐项仍然成立。
⇒ 按 F4，**不重写**历史证据，只在本文件里单独记录这次断言变更。

（另：按 K-19 的写入门，重发 WP1 的证据需要 `M511_AUTHORITATIVE_EVIDENCE=1` 且**四路测量输入齐全**
——其中一路是 M4 CI 回归，那是 WP10 的项，不在本 WP 的授权范围内。这一点如实登记。）
