## 2. 门覆盖完整性（Gate Coverage Completeness）

判据：`discoverAttributionVerifiers()` 扫 `scripts/*.ts` 的**归因断言针表**（10 个标识），
与注册表逐条比对。**针表与注册表都不是人写的清单**：完整性由扫描得出。

```text
扫到的 attribution verifier      = 22
注册表里的 verifier              = 26（其中 20 条声明应当被扫到）
missingGate                      = 0
staleGate                        = 0
unclassifiedVerifier             = 0
```

**自污染（踩到并修掉，K-17 §1b 的同型问题）**：第一版 harness 把针表**字面量抄进了自己**，
而注册表本身就声明了针表 ⇒ 这两个文件被判成"未分类 verifier"（22 里多出 2）。
处理办法**不是放宽针表**：
- 两个量具文件逐条登记进 `NON_VERIFIER_SCRIPTS`（写明理由）；
- harness 改成**从 K-17 源码里读它的针表**，而不是复制字面量；
- 负控仍然必响 ⇒ 证明这次排除没有把判据变哑（见下）。

**三段式负控 / 恢复**（全部在临时目录或纯数据上做，不改仓库）：

```text
① 注入一个未登记的合成 verifier            ⇒ unclassifiedVerifier 必响   ✅
② 注册表里塞一条不存在的 verifier          ⇒ missingGate + staleGate 必响 ✅
③ 摘掉 wp4 的 pnpm 入口                    ⇒ staleGate 必响               ✅
恢复：真实仓库 + 真实注册表                ⇒ 重新安静（0 / 0 / 0）        ✅
```

## 8. 仪器观察（登记但**不**立案 —— 都不产生假绿）

1. **`m5.1.1:wp7:preflight` 现在报红**：它的允许面基线是 **WP7 的起点**，而 **K-29** 在 WP7 之后
   受权改了 `src/kernel/contracts/attribution.ts` 与 `conversation-event.ts`。
   它被分类为 `historical-scope-guard`（**不是**当前 correctness claim），因此不计入"门必须 exit 0"。
   它**红得对**（fail-closed），但作为"当前门"没有意义 ⇒ 建议：要么把 K-29 的两个文件加进它的允许面
   并重跑，要么退役它。**没有**登记 K：它只会误报红，不会误报绿。
2. **K-17 的 `verdict` 字段不覆盖全部六条 check**：它只由 dangerous / unclassified / measurementInvalid
   三个条件决定，**不含"陈旧条目"那条**。实测踩到过一次：误把两个不命中针表的文件加进分类表 ⇒
   `passed 14 / failed 1` 而 `verdict = PASS`。⇒ **读数纪律：判 PASS 必须看 exit code + passed/failed，
   不能只看 `verdict`。** 本 harness 的 §3 用 `failed > 0` 判红，因此那次被正确判红。
3. **我自己的一处量具 bug（已修，留证）**：`git status --porcelain` 的第一列是**空格**
   （`" M path"`），而对整段输出 `.trim()` 会把**第一行**的空格吃掉 ⇒ 那一行会被 `/^ M\s/` 漏掉。
   后果：`artifacts/m5.1.1/k29-necessity-enforcement.json` 的证据**永远不被还原**（它恰好是字母序第一行），
   以及"运行前状态快照"偶发漏掉第一个文件。修法：解析 porcelain 用**不 trim** 的 `gitRaw()`；
   并把它写进注释（`parse porcelain never trim`）。这条与本项目 §6.9 是同一族：
   **读数看起来正常，量到的却不是你以为的那一行。**
   同一轮还修掉一个更危险的版本：还原面一度是"运行后新出现的、未声明的改动" ⇒ **会误还原作者自己的文档改动**。
   现在还原面恒等于"**注册表声明过的**写入面 ∩ 当前与 HEAD 不同"，未声明路径**只报告、绝不还原**。
