## 0. 这份记录要回答的问题

R-48 把 `E4/S3` 的载体从"**conversation ingress 必须有 `system_event` 生产者**"改成
"**domain-appropriate authoritative event ledger 上必须有真实的 SYSTEM-origin production event**"。
这是一次**验收载体变更**，R-48 §C1-0 明令："不能伪装成单纯调整测试代码"。

因此本文件逐项记录：

```text
OLD E4            ·  NEW E4            ·  WHY（为什么旧判据在当时是对的、现在不再是唯一载体）
PRESERVED（必须保住的安全性质）  ·  旧读数如何被保留而不是删除
逐组：OLD / NEW / 是否放宽 / 历史证据是否被重写 / 证明
```

**一条总原则**：

> 这是 **acceptance-carrier change ruled by R-48**（由用户裁定授权的验收载体变更），
> **不是** "test relaxation"（不是为了变绿而放宽判据）。
> 判据的**形状**（Known 正控 + 诚实 Unknown + 无证据伪造必拒 + L1/L2 + 真实生产路径）**一字未改**；
> 变的只是**哪个权威账本**承载它。若没有 R-48，`C1-G11` 那一改**会**是放宽。
