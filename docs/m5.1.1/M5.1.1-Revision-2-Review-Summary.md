## 3. B1–B7 Resolution

| Blocker | 处理 | 落点 |
|---|---|---|
| **B1** `actor_type` 不得直接迁移为 `actor` | `actor_type`/`actor_id` 定位为 **legacy compatibility projection**（语义不变、不得成为事实源）；**删除** `actor_type→actor` 通用回填；`conversation_events.actor` 默认 `Unknown(LEGACY_UNRECORDED)`；`character_action_events` 改为**逐 event family/type** 判定 | ADR D8；Migration-Strategy §3.2/§3.3；Compatibility-Matrix §3.1/§4 |
| **B2** `sourceAuthor` 语义过窄 | 全库更名 **`contentOriginator`**（语义来源，非键盘操作者）；保留强制对照行；补齐三个标准示例 | ADR D6；Compatibility-Matrix §2.1 |
| **B3** 缺少构造/证明边界 | **新增 §3 Attribution Construction & Attestation Boundary**：构造者表 + 核心不变量 + 输入 DTO / authority-bearing envelope 分离 | ADR §3；Test-and-Gate-Plan **G-AT-4** |
| **B4** `UNKNOWN` 混入 `PrincipalKind` | `PrincipalKind` 收敛为 **6 值**；未知改为 `AttributionValue` 的 `Unknown<UnknownReason>`；`UnknownReason = LEGACY_UNRECORDED \| RUNTIME_UNRESOLVED`；三态编码 `<slot>_kind/_id/_unknown_reason` | ADR D5；Proposed-Schema §0 |
| **B5** `AuthorityKind` 含 `DEVELOPER_SURFACE` | 删除 `DEVELOPER_SURFACE` 与 `UNKNOWN_LEGACY`；新 `AuthorityKind = POLICY\|CAPABILITY\|SYSTEM_RULE\|USER_CONSENT\|BREAK_GLASS`；Developer Control 示例重写 | Proposed-Schema §2.1；Compatibility-Matrix §2.2 |
| **B5.1** `ACTION_REQUESTED` 要求 authority | 改为 `ACTION_REQUESTED → ABSENT`；`ACTION_AUTHORIZED` / 副作用执行 → `REQUIRED`。**已核实 `ACTION_AUTHORIZED` 已存在 ⇒ 不新增生产事件** | ADR D7；Proposed-Schema §3 |
| **B6** Gate 用值相等作判据 | 改为"无证据推导"与"字段值与权威证据冲突"；**删除** `executor==actor` 与 `initiator==subject` 两条禁令；新增**合法相等必须通过**的反假阳性对照 | ADR D10；Test-and-Gate-Plan §1.2/§2.1 |
| **B7** Memory 重新资格化混入 ADR-042 | 移出至 **ADR-043**（本轮只 DRAFT）；新增阶段门：Phase 1–3 由 ADR-042，**Phase 4 BLOCKED BY ADR-043** | ADR §8；ADR-043 草案；Migration-Strategy §2.1 |

**另加**（请求 §10 的独立要求）：**Axis B 必须真正持久化** ——
`source_kind` / `source_authority` / `epistemic_source` 落库，
原则 WRITE=record what was established / READ=read what was recorded /
NEVER=reconstruct from `actor_type`；旧行取 `UNCONFIRMED_ORIGIN`，禁止伪造 `USER_EXPLICIT`。
→ ADR §4；Proposed-Schema §5.3。

**全部 7 个 Blocker 处置完毕，无遗留。**
