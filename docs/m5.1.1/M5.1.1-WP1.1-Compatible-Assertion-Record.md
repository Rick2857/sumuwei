### 6.2 为什么"净新增 19 / 22"必须被量出来

v7 对 `conversation_events` 写了 22 条 `add column if not exists`，但
`source_kind` / `source_authority` / `epistemic_source` 在**迁移 0003** 就已存在，
因此这张表**净新增 19 列**（20 → 39）；`character_action_events` 此前没有这三列，
**净新增 22 列**（12 → 34）。

`pnpm m5.1.1:migration:verify` 现在**逐表量**这个差值并把期望写死
（`+19` / `+22`）——否则"22 列"很容易被读成"两张表各加了 22 列"，
而那是一句正好差 3 列的事实陈述。
