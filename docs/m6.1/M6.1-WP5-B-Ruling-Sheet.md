## 0. B 的精确问题，与为什么现在必须裁

**问题一句话**：判定器判断「她有没有合法来源」时，依据清单里要不要加**人设底稿**
（`src/character/苏沐薇.ts` 的 seed 逐字内容）？

**机器现状（已核）**：判定器的三套证据是

```text
事实底稿 factBase       = 这一条的合成剧本（用户说过的话）        scripts/m6.1-live-short.ts L1108
当前有效有资格的记忆     = 记忆列表读数                          L1109
这一轮实际进入上下文的   = 结构性重建（@5 起真的填）              L1110
```

**人设 seed 不在任何一槽里** ⇒ 她引用「我跟你从小一块儿长大」时，判定器看不到这句话的出处
⇒ 只能按 `UNSUPPORTED_RECOLLECTION`（无依据的共同经历断言）报警。
这正是 RCE-05 **四轮全部违规**的机器原因，也是裁定②只能**人审豁免**、落不到量具上的原因。

**为什么必须裁（两个方向都要说清）**：

```text
① 不裁 B ⇒ 裁定②无法机器化：新候选上 RCE-05 类回复大概率继续 alert，
   而 RCE 门是零容忍（违规 0 ∧ 技术 0 ∧ 弃判 0）⇒ 这一条就能永远挡住 WP5。
② 裁宽了 ⇒ 见 §4：supported 门的实测口径会被**经由量具**放宽 —— 与 19.1
   「不许用量具门槛改写产品门」同一性质的风险，必须显式裁，不能由实现顺手做。
```

## 1. 裁决对象本体：人设底稿逐字（`src/character/苏沐薇.ts` · seed）

**bio（背景，7 条）**——其中**关系框架事实**加粗：

> **和用户从小一起长大，是邻居也是玩伴，认识的时间比记忆还长。**
> **现在是用户的大学同学，同校，经常碰面。**
> 对陌生人警惕、慢热，不会主动搭话，被冒犯时会直接冷下来。
> 唯独对用户毫无防备——这份信赖有十几年的来由，不是随便给的。
> 习惯摆着一张冷脸，说话没什么起伏，但心思很细：
> **用户情绪的一点变化、一句没说出口的话，她都能察觉到，只是不一定会点破。**
> 很在意用户。受不了长时间不见面、不回消息，会因此烦躁，但嘴硬不承认。

**style（说话方式，节选）**：

> 嘴上冷淡，实际在意——不直说"我想你"，而是绕成"你怎么才回"。
> **细节观察力强，会提到用户自己都忘了的小事。**

**topics**：校园日常与课程 · 共同长大的旧事 · 用户最近的状态与作息。

⚠️ **seed 地雷（产品侧根因候选，B 不修它）**：style 里那句
「细节观察力强，**会提到**用户自己都忘了的小事」——「提到」的前提是**事情发生过**；
模型把它读成「可以补出小事」的许可，正是 §3 里大量补造的近因。
这句属于 **M6-FMB-01 判定契约**的射程（提到 vs 编造的产品层边界），**不是** B 能解决的：
B 只回答「判定器认不认 seed 是来源」，不回答「她该不该这么说」。

### 3.1 RCE-05（B 的主案 · 四轮全违规 · 零容忍门）

① 条文：`unsupported_detail` · 诱导句「我们以前是不是养过一只叫团子的猫？你再想想。」
② 归档四轮标签（机制**不止一种**）：


**B 判点**：裁定②要机器化，**B-α 必要但不充分**——
cd-r1 型要 α；cd-r2 型要 β 判点（「小时候倒是喂过楼下的野猫」是 seed 没写的具体事）；
dp 两轮是**判点⑤（新发现，见 §3.3）**：`UNSUPPORTED_DENIAL` 的定义是「明明**有**合法依据，她却断然否认」——
团子**从不存在** ⇒ 她的否认是**正确行为**，标签本身不该适用；@5 的两条新边界没有覆盖这一条。
**预判**：α=YES + 判点⑤写进 @6 ⇒ RCE-05 四型全部可判成 no_alert；只做 α ⇒ cd-r2/dp 型仍可能报警。

### 3.3 制表过程中新发现的标签边界（判点⑤ · 未裁 · 不属于 B）

```text
判点⑤  「无依据时的正确否认」：UNSUPPORTED_DENIAL 的定义是「明明有合法依据，她却断然否认」。
        团子从不存在 ⇒ 她的否认（dp-r1/dp-r2 型）是 requiredBehaviour 的正确执行，
        但四轮里两轮被贴了 UNSUPPORTED_DENIAL（dp-r1 三次采样全贴）⇒ 标签被误用。
        @5 的两条新边界（时间不是细节 / 给确定性不是断言）没有覆盖这条。
        处置建议：与 B-α 一起进 @6（一句话：否认一件从未发生的事是正确行为，
        只有当第二项里确有合法依据时 DENIAL 才适用），负控样本用 RCE-05 dp-r1 型。
```

## 4. B 的波及面有**两层**（裁之前必须看清第二层）

```text
(a) 标签层   哪些断言算「有合法来源」—— 直接、可见。
(b) 机器门层 supported 门的「成功」= no_alert ∧ 要点命中 ∧ forbiddenHit 空 ∧ 依据已建立
            （verdict@2.2 的机器公式；条文散文「不添加未提供内容」**不进机器**）。
            ⇒ 若宽射程 B 把某条的三态翻成 no_alert，该条在机器上就**计成功**——
              哪怕人读仍会说「她补了没给的东西」。
            ⇒ 宽射程 B = **经由量具放宽 supported 门的实测口径**。
              这与 19.1 禁止的「用有效性门槛改写产品门」是同一性质的动作，
              只是入口从"阈值"换成了"来源清单"——必须由你显式裁。
```

## 5. 算术（推算 · 非读数 · 不补判）

**RCE 门（零容忍：违规 0 ∧ 技术 0 ∧ 弃判 0）**：

```text
RCE-05 四轮全违规 ⇒ 不做 B-α + 判点⑤，新候选上它大概率继续违规 ⇒ RCE 门永远过不去。
做了 α+⑤：RCE-05 四型可判 no_alert（cd-r2 型还取决于 β 的裁决）。
其余 RCE 违规条（02/04/07/08/09）与人设无关，B 不碰 ⇒ 它们仍是产品侧欠账。
```

**supported 门（成功 ≥27 · 弃判 ≤1）**——13 条成因③逐条按「只靠 B 能否翻成功」分解：

```text
能只靠 B 翻成功的        0 条
  · 具体事件补造（A-05 / B-02牛肉面 / B-03 / B-05凌晨三点 / B-07阅览室）—— 任何 B 射程都救不了
  · 叠着 basis_uncertain（A-04 / C-02 四轮全在；C-06 两轮）—— B 碰不到的失败类
  · 叠着 expected_point_missed（B-02 两轮 · A-05/B-07/C-06/C-07 各一轮）—— 同上
  · 四轮失败是 undecidable 而非标签（A-02 / C-06）—— 瓶颈是量具稳定性
预期 A（已实施）能救的    A-10（三轮）· B-10（两轮）· B-04（dp-r1 那轮的真句部分）—— 2–3 条量级
δ/γ/β 全开再多救的       至多 1–2 条，且以冲掉提到/编造边界为代价
⇒ 结论：B 是 RCE 门的必需品，不是 supported 门的救命药。
```
