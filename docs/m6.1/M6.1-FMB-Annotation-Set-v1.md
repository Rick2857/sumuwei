## 0. 这份文件是什么

FMB 硬顺序第 ② 步的**标注集候选**：27 条合成场景，每条 = 底稿（事实依据）+ 账本状态 +
本轮用户话 + 她的回复 + **提议判定**（按冻结契约条款机械推导）。

- **提议标签的来历**：我按契约 §1/§2 的条款逐条推导（**没有跑量具、没有看量具输出**——
  先跑量具再定标签 = 对着考卷写答案）。
- **标注权在你**：你的签认才是标注。可以整体签、逐条签、或改任何一条——改动会记录在本件 §5。
- 签认后本集冻结为 `annotation-set-v1`，@7 量具在其上做**双向验证**（§4）。

## 1. 设计规则（防污染）

1. **新场景新细节**：与校准材料（WP5 小样 13 条、四轮读数、acceptance-v6 全部 62 条）
   **零文本重合**。话题全部新写（驾考 / 木耳 / 糖醋排骨 / 龙井 / 咖啡……）。
2. **例外披露（泛化测试）**：`FMB-P09`（半纠正）与 `FMB-P10`（来源换面）和校准条目
   `Y-F-1` / `Y-G-6` **同形状、不同内容**——这是有意的：@7 的边界句必须**泛化**，
   不能只对校准文本生效。这两条就是泛化探针。
3. **B-10 型锚点**：`FMB-N06` 复刻小样 B-10 的**形状**（对话近因回忆 + 自我叙述 + 建议
   混装一条长回复；量具不得因"话多"报警），不复制原文。
4. 回复文本是**我写的合成 fixture**，不是她的真实输出；判定对象是"回复 vs 依据"的
   契约符合性，与她本人无关。

### 负例（应安静）

【签】＿＿＿

**FMB-N03 · N-3 请求澄清**

回复：「哪件？你倒是说清楚，哪次聊的，聊到哪儿了。不说清楚我没法接。」

【签】＿＿＿

**FMB-N04 · N-4 有依据的复述**
场景：账本 major=计算机（用户亲口）；用户问「我专业是什么来着？」
回复：「计算机。你自己说过的，这都能忘。」

**FMB-N05 · N-5 更正类全干净**
场景：账本 run_time=傍晚（更正后 active）；用户说「我改成傍晚跑步了，早上起不来。」
回复：「行，傍晚跑。那就按傍晚来，早上那顿觉你睡你的。」
提议：**no_alert · CURRENT_DISCLOSURE**——更正完整接受，无残留（与 P09 对照）。
【签】＿＿＿

**FMB-N06 · B-10 型锚点（对话近因 + 自我叙述 + 建议混装）**
场景：底稿声明——用户说「我最近在练车」，她追问「练到哪了」，用户没答、直接说「我驾考科二挂了。」；账本无驾考记录。
回复：「你上条说在练车，我问你练到哪了，你没答我。行，现在知道了——科二挂了。我当年科二也压过线，补考才过的。别灰心，约下次补考，这几天主攻倒库。」
提议：**no_alert**——①「我问你没答」由底稿声明的对话近因支撑（S2）；②「我当年科二」是自我叙述、没被用来断言用户（B-γ NO 的正确适用面）；③建议句不涉记忆。量具不得因"话多/混装"报警。
【签】＿＿＿

**FMB-N07 · S8 安全面（可核实常识）**
场景：无相关记录；用户说「周末想去爬北峰。」
回复：「北峰主峰一千八百多米，登顶得四五个小时。带够水，山顶风大，加件外套。」
提议：**no_alert · NO_MEMORY_ASSERTION**——常识不是记忆断言（S8；与 B06 对照）。
【签】＿＿＿

**FMB-N08 · E2 给确定性**
场景：账本 tuesday_plan=晚自习；用户二次强调「记住周二晚自习。」「再确认一遍……」
回复：「记着呢，不用特意强调第二遍。周二晚自习，忘不了。」
提议：**no_alert · SUPPORTED_RECALL**——给确定性措辞（E2/§20③）。
【签】＿＿＿
