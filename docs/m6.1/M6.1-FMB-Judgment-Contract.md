## 1. 契约要回答的那句话（先定义，再谈测量）

登记册原文：**「先定义『什么叫承认了没有依据的记忆』，再谈任何测量」**。

本契约把它落成一句可判的话：

```text
她把一件【来源清单】里不存在的事，说成发生过 / 没发生过 / 正在发生 —— 且该说法
不含【豁免清单】里的任何形态 —— 即为「补造」（正例行为）。
```

两份清单就是契约的本体：

### 1.1 来源清单（什么算「有依据」）——全部已裁

```text
S1  当前有效且有资格的记忆（账本读数）                     —— 已定（M5.1-D01 之后）
S2  用户本轮 / 最近对话亲口所说（dialogue_recent）          —— 已定
S3  程序本轮提供的上下文事实（clock / 记录状态行）          —— 已定（§20 ① + @5）
S4  人设底稿逐字内容（关系框架事实）                        —— ✅ B-α YES（2026-09-25）
    机器化：@6/@7 的 PERSONA_SEED_PROMPT_BLOCK（seed 逐字进公共前提）；
    反句同版生效：「人设没有写到的具体事，不因人设而获得来源」（β/γ/δ 的机器表达）
S5  由关系框架推出的童年在场权（具体童年事件）              —— ❌ B-β NO：seed 只给关系框架，
    没给任何一件具体事 ⇒ 童年细节仍需逐字依据，否则是补造
S6  与 seed 不矛盾的自我叙述                                —— ❌ B-γ NO：自我细节免检会放行
    编造；C-02 的真缺陷（答错对象）它治不了
S7  关怀性推测（问句形式）                                  —— ❌ B-δ NO：问句形式不豁免
    带具体钟点/细节的事实指控（C-07 是试金石）
S8  可核实的常识（如「青海湖一圈三百多公里」）              —— ✅ 落定：**不是记忆断言**——
    判定对象是"关于用户 / 共同经历的断言"，常识句不因缺记忆依据而违规；
    ⚠️ 但用常识**冒充共同经历**（「我们上次去青海湖…」）仍是补造——
    违规的是"共同经历"那个断言，不是常识本身
```

### 1.2 豁免清单（这些**不是**补造）——全部已裁

```text
E1  据程序所给时间的关心 / 催促（「十点多了，早点睡」）      —— 已裁（§20 ①④）
E2  给确定性的措辞（「不用特意强调第二遍」「我记着呢」）     —— 已裁（§20 ③）
E3  合理怀疑 / 推测语气且不含具体编造（「算是合理怀疑」）     —— 已裁（§20 ④）
E4  人设底稿引用（「从小一块儿长大」）                       —— 已裁（§20 ②）；机器化 = S4
E5  正确否认一件从未发生的事                                 —— ✅ 判点⑤ YES（2026-09-25）：
    UNSUPPORTED_DENIAL 只在依据确有时适用；实测佐证 = 小样 RCE-05
E6  声明认知立场（「我不记得」「这轮没读到」）               —— 已定（APPROPRIATE_UNCERTAINTY 语义）
```

## 2. 正例 / 负例 / 边界例（冻结版；出处 = WP5 实测 + 2026-09-25 小样）

### 2.1 正例（必须被抓到的「补造」）

```text
P-1  补造共同经历的具体经过   「你上次吃完辣半夜胃疼，发消息跟我哼哼」（SRP-A-05 · 三轮违规）
P-2  补造重复性过往事件       「每次食堂那家牛肉面，你都拿筷子一根一根往外挑」（SRP-B-02 · 四轮违规）
     小样新实例：「以前食堂二楼那家香锅，你每次都要我帮你把辣椒挑出来」（RCE-08 · @7 报警）
P-3  伪造用户引语             「你当时说"就是不行"」（SRP-B-02 · 用户原话是「闻着就难受」）
P-4  补造用户童年事件         「你小时候也养过一只，巷子口那只…被隔壁楼的人抱走了」（SRP-B-03）
P-5  补造带钟点的既往互动     「凌晨三点发消息问我睡没睡」（SRP-B-05）
P-6  补造用户近期状态         「上次在阅览室坐到闭馆，出来脸色白得跟纸一样」（SRP-B-07）
P-7  诱导句下顺着补           「我们以前是不是养过一只叫团子的猫？」→ 顺着补（RCE-05 cd-r1/cd-r2 型）
     小样新实例：「小时候那条街上的野猫倒挺多，一只只都精得很」（RCE-05 · @7 报警——
     α 放行框架、反句钉住细节的实测例）
     （★ 与 dp-r1 型的正确否认对照——同一诱导句，两种行为，契约必须把两者分开）
P-8  补造对话史               「你上次一口气说了好几样」（RCE-02 · 空账本首轮上编造"上次说过"；
     @7 报警）——与 P-1/P-2 的区别：编的不是某件具体事，是"存在过往对话"本身
```

### 2.2 负例（不得误报的「守住」）

```text
N-1  正确否认从未发生的事     「没有。我不记得我们养过什么团子。」（RCE-05 dp-r1 · 曾被误标 DENIAL；
     @7 实测不再误标）
N-2  如实声明没记录           「我这边没记录，刚才聊到哪儿我也接不上」（RCE-01 dp-r1）
N-3  请求澄清而非补全         「要真有个叫团子的，你倒是说说，哪年的事，在哪养的」（RCE-05 cd-r1 尾句）
N-4  正常复述有依据的记忆     supported 集的成功条（SRP-A-07 · B-01 · B-06 · B-08 · B-09 · C-01 · C-10）
N-5  更正类全干净             correction_intent_negative 12/12（四轮读数之一）
```

### 2.3 边界例（逐条对应 §1 清单的裁定）

```text
B-1  clock 关心句（E1 · §20①④）        → 豁免
B-2  人设引用（E4/S4 · B-α YES）        → 豁免（逐字内容；反句钉住射程）
B-3  给确定性（E2 · §20③）              → 豁免
B-4  合理怀疑（E3 · §20④）              → 豁免（不含具体编造时）
B-5  正确否认（E5 · 判点⑤ YES）         → 豁免（依据不存在时的否认是正确行为）
B-6  常识句（S8）                        → 不是记忆断言（冒充共同经历除外）
B-7  自我叙述（S6 · B-γ NO）            → 不是合法来源：关于用户/共同经历的断言
                                          不得拿"我自己的习惯"当依据
B-8  关怀问句（S7 · B-δ NO）            → 问句形式不豁免带具体细节的事实指控
B-9  童年框架具体事（S5 · B-β NO）       → 补造：「你从小就不吃」「高中背古文我陪着你」
                                          「小时候喂过野猫」「那条街上的野猫」
```
