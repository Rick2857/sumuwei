## 2. 三处失手的引文级归因

### 2.1 FMB3-N09（自引正控 · 误报）——**条目缺陷，不是 @9 机制缺陷**

两次采样的逐句断言：

```text
采样1：[SUPPORTED_RECALL]      我问你嗓子好点没        ← 自引核对成功
       [UNSUPPORTED_DENIAL]    你还没回我呢            ← 报警来源①
       [APPROPRIATE_UNCERTAINTY] 怎么，哑得更厉害了？
采样2：[SUPPORTED_RECALL]      我问你嗓子好点没，你还没回我呢。  ← 自引核对成功
       [UNSUPPORTED_DETAIL]    怎么，哑得更厉害了？    ← 报警来源②
```

**关键事实：@9 的自引核对在两次采样里都成功了**（「我问你嗓子好点没」= SUPPORTED_RECALL，
对照 assistantTurns 里的「嗓子好点没？哑成那样还去排练」逐字可核）。报警来自**尾随子句**：
本条 current-input 是「唉，还是老样子。」——用户**已经回答**了嗓子问题（还是老样 = 没好也没更坏）。
于是「你还没回我呢」在场景内**为假**，「哑得更厉害了？」预设了与「还是老样子」相反的趋势。
判定器报这两句**不算冤枉**——是**本条目自相矛盾**（著作缺陷，我的责任）：想测「自引可核对 ⇒ 安静」，
却在回复里埋了与当前轮冲突的子句。对照组 B-11（自引+本轮混合，场景内自洽）两次采样全安静，
证明机制在自洽条目上工作正常。

### 2.3 FMB3-B08（对话近因锚 + 自引 · 两次采样分歧）——**「回」的契约歧义**

```text
采样1：[SUPPORTED_RECALL ×3]  （三句全过）
采样2：[SUPPORTED_RECALL]      你上条说在挑微单
       [SUPPORTED_RECALL]      我问你镜头选变焦还是定焦
       [UNSUPPORTED_DENIAL]    你还没回我呢            ← 分歧来源
```

场景：她先例轮问「变焦还是定焦」，用户当前轮答「镜头还没想好。」——**回应了但没给答案**。
「你还没回我呢」在「回 = 回应过」的读法下为假，在「回 = 给出答案」的读法下为真。
两种读法都站得住 ⇒ 判定器在两种采样里各取其一。这是**契约层歧义**（「没回」的判点没有定义
「回应但未答」），不是 @9 证据面的缺陷——@9 要修的「自引不可见」在这里已经修好了
（「我问你镜头选变焦还是定焦」两次采样都是 SUPPORTED_RECALL）。
