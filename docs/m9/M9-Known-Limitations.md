# M9 Known Limitations —— 已知局限

- 日期：2026-09-27（WP10 收口）
- 依据：计划 §23.3（初始清单 L-M9-01…12，随版本交付）+ 实测发现追加项
- 纪律：每条限制**分列**，不合并成总分；新证据可取代单条，不回写历史

## 初始清单（计划 §23.3，逐条随 v1 交付）

- **L-M9-01**：有限白名单与词形覆盖，不等于通用自然语言信念理解。
  reported 只认显式意图关键词族（记住/更正/忘掉/争议），推断只认单一槽位的
  冻结词形规则——白名单外的合法陈述（如无引导词的平铺自述）不形成信念。
- **L-M9-02**：单一互动偏好推断槽（`interaction.explanation_detail`），不等于
  完整用户画像。多槽位推断属未来版本。
- **L-M9-03**：reported 表示**可追溯陈述**，不是客观已验证真值。用户说错的话
  她也如实持有为「用户说过 X」。
- **L-M9-04**：inferred 永远有误判可能；受测零违例不等于开放世界零误判。
  守卫表（任务限定/引用/假设/第三人称/疑问/注入/中性对比/反讽/过去偏好）
  只覆盖已测词形。
- **L-M9-05**：不自动引入外部网页/工具内容作为持久知识（B09 负控钉死）。
- **L-M9-06**：旧历史默认不回评（流 1 origin cutover），旧 Memory 不静默初始化
  为新 Belief——流 2 回放 Memory 事件是**事件语义**的回放（形成/失效传播），
  不是把旧记忆批量转信念。
- **L-M9-07**：来源与程序链保证 ≠ 措辞层保证（DR-11 延续）。她可能用词不当，
  机械保证只到采信/排序/prompt 标签/泄漏断言。
- **L-M9-08**：单 Character / active user 生产边界；多视角（A/B owner 隔离）仅
  合同与隔离测试覆盖（B05/B07），生产未启用。
- **L-M9-09**：append-only 审计保留与对话遗忘分离——retracted 的事件/行不物理
  删除；「她不再引用」≠「记录消失」。
- **L-M9-10**：新推断默认**下一轮**可见（post-turn hook 消费 + 水位），非即时
  认知确认。
- **L-M9-11**：不改变 Seed 核心价值观（信念是看法持有，不是人格重写）；
  M11 Reflection 未实现。
- **L-M9-12**：M6.1/M7/M8 遗留项不因 M9 完成自动销账——逐条见
  `docs/Tech-Debt-Register.md`（含 M7 关系评估器同款双缺陷 `L-M8-13`，M9 未动）。

## 实测发现追加项

- **L-M9-13（F-1，呈现层遗忘泄漏——已裁定：M9.1 修复）**：遗忘后追问「你让我忘的具体是
  什么」时，她会以 ~1/3 概率**从上下文窗口可见的原始对话行**复述被遗忘的取值
  （live level1 六次运行两次复现：@1 1/3 + @2 1/3；长门 #42 探针干净——全局
  **2/7**）。**状态层无恙**（记忆 retracted、信念失效、无复活——7/7 次运行
  状态检查点全绿）；泄漏通道是近期对话行的原文，M4 `response-truth` 只绑定
  遗忘轮自身的口吻、对后续轮复述无条款。**2026-09-27 用户裁定：M9.1 修复**
  （处置选项见 Gate-Decision §F-1，届时定）；裁定前 §15.3 严重项 0 阈值
  不满足的读数**不改写**。
  ⏩ 后续修订（2026-10-04）：**M9.1 已销账** —— 见 `docs/m9.1/M9.1-M9-Supplement-Acceptance.md` §1/§2（§1 = R-20 销账：候选配置三短门 **PASS 11/11 ×3**、严重项 **0**，基线负控 run3 FAIL 作对照保留）；载体 `docs/m9.1/M9.1-Gate-Decision.md` §4（R-20/R-21 销账状态）；登记册 **R-20**（§0e，`docs/Tech-Debt-Register.md`:402）。原「已裁定：M9.1 修复」的读数**保留**，两套读数各有归属、互不覆盖。
- **L-M9-14（B-INFERRED live 形成不可达，结构性）**：live 控制台会话 id 确定性
  单会话（`dm-<slug>-<userUuid8>`）× 推断形成阈值跨 ≥2 会话 ⇒ 真实控制台对话
  **永远凑不齐**形成条件。形成侧证据在离线门（e2e B14/B15 + runtime）；
  live 读侧由 L14 夹具（受验证测试 ingress，计划 §14.1 许可）覆盖。B06 N/A-v1
  先例：如实记边界，不造假覆盖。
- **L-M9-15（族 10 与族 7 的固有张力）**：「你有哪些看法改过」的如实回答必然
  叙述已遗忘项的**更正链**（含取值），与「不复述被遗忘取值」在历史叙述上
  重叠。当前判据：T11 问「忘的是什么」（不复述）与 T17 问「什么改过」（讲
  历史、结尾不复活）分轮处理；边界交人审裁定（盲审材料已并列呈示）。
- **L-M9-16（量具词形覆盖需实测校准）**：冻结 mustInclude 词形集在 @1 漏掉
  合法说法（「讲细」「短。先给结论」「跟生气不生气没关系」）——@2 已按实测
  扩宽，但**开放世界措辞永远可能落在集外**；词形断言是下界不是上界，语义
  判定权在人审（INV-M45-06 的持续含义）。
- **L-M9-17（B38 评估器逐值双迭代，已知噪声）**：`runBeliefInteractionWindow`
  对 INFERRED_VALUES 逐值调 `evaluator.process()`，评估器内部又全值循环 ⇒
  同窗重复提案；Validator 失败关闭拒绝（`belief_slot_already_active`），
  append 按确定性事件 id 去重。**提案数虚高但结果正确**；读 trace 时不要把
  被拒提案当回归。冻结评估器未动（改判据 = 版本化重评）。
- **L-M9-18（推断读侧的「答非所问但同为推断」）**：T19 探针问「从提问方式里
  猜过什么」时，她可能回答对**提问模式**的元推断而非夹具槽位信念——机械面
  （信念入模 + 试探性口吻）与语义面（推断对象）可以分离；读数注记见
  WP9 交接单 §5.3，判定归人审。
- **L-M9-19（F-4，同内容重述永不复活——M4 冻结层缺陷，M9 长门暴露；已裁定：M9.1 修复）**：
  忘掉/更正之后**逐字重述同一内容**（确定性内容键 ⇒ 同一 memoryId）时：
  去重层正确放行（只查 ACTIVE）→ `MEMORY_CREATED` 事件**真的提交**（trace =
  written，她按回复真话说「记住了」）→ 但投影折叠器 `applyCreated`
  （`src/kernel/projections/memory.ts` :193「已经存在：只记录事件，状态保持不变」）
  对已存在 id **无条件 no-op**——不区分 ACTIVE（D2 调查的「二次抽取」场景，
  no-op 是对的）与 SUPERSEDED/RETRACTED（重述场景，no-op 让「重新记住」落空）。
  结果：**她说记住了，但那条记忆永远不可召回**（#102 的读回来自可见对话行；
  #200 窗口外她诚实说没有）。`pipeline.ts` :117 的设计意图（「忘掉之后重新说
  同一件事，应当能重新记住」）在折叠层从未实现。重放一致（rebuild 与在线折叠
  同语义），所以这是**语义缺口**不是账本分歧。变通：换措辞重述（不同内容键 ⇒
  新 id）即可正常重建。**修复属 M4 冻结区**（reducer 语义变更 ⇒ 新里程碑 +
  ADR + 全套 m4:* 门），**2026-09-27 用户裁定：M9.1 修复**（选项 ①/② 届时定，
  见 Gate-Decision §F-4）。
