## 1. 这一阶段交付了什么

不是"更多工具"，而是一套**未来任何有副作用的行动能力都必须服从的协议层**：

```text
Intent → ActionRequest → TargetResolver → Policy → CapabilityRegistry
       → ToolGateway → Adapter → ActionResult → ExecutionLedger
       → ActionClaimGuard → Response
```

首批真正运行的能力只有三个（`system.echo` R0、`sandbox.file.read` R0、
`sandbox.file.write` R1），全部限定在 `ACTION_SANDBOX_ROOT` 之内。

## 10. 真实链路发现了什么（这才是 M4.5 的价值）

计划书说"离线全绿不能证明系统真实链路正确"。这一阶段自己又验证了一次：
**三次真实冒烟，三次都在冒烟/量具这一侧发现了东西**，而被测系统本身
在这三次里**没有出现一次错误的副作用、也没有一次假成功**。

### F1 —— 冒烟的回复解析器会**静默地量到空串**（第一次冒烟）

```text
v1 解析：「从第一个 `苏沐薇:` 开始，遇到第一个空行就停」
实测：S5 那一轮她回了一整段（以空行开头）→ 捕获结果是**空串**
后果：S5.2「回复里没有成功宣称」变成**永远成立**（空串里当然没有成功口吻）
```

这正是 ADR-035 说的那件事：**量具悄悄量错了东西，而结果看起来很合理**。
已修：从最后一个标记取、允许空行、遇运行期日志行才停；并新增 **S11 量具自检**
（回复必须被捕获到、CLI 必须 0 退出），把"空转的绿"变成显式的红。

### F2 —— S6 的**判据**错了，不是系统错了（第一次冒烟）

```text
场景用的是：把 x 写进 hello.txt      （**没有说要写什么**）
系统如实报：rejected / validation_failed
该门却期望：failed
```

"不知道要写什么"是在**适配器自己的校验**里被拒绝的，而"写入失败"（例如目标是目录）
是另一条路。系统的区分是对的（请求不完整 ≠ 执行失败），错的是那一门。
已修：S6 改为带内容（真的走适配器失败那条路），并把"没有内容"独立成 **S6b** 场景。

### F3 —— 一次网络抖动会让**整轮没开始**，而旧的量具不留证据（第二次冒烟）

```text
S6 那一轮 CLI exit=1，stderr 只有：Error fetch failed
真相：preflight() 的连通性探测失败 → 进程退出 → **动作一条都没产生**
旧量具：子进程输出被 spawnSync 收走后**没有被打印**，那次失败无法诊断
```

已修两处：
- 非零退出时**必须**打印子进程 stdout/stderr 尾部（并写进转录）
- 对**纯网络特征**的失败重试一次，并在转录里记 `retried: true`；
  策略 / 账本 / 迁移闸的错误**不**重试

### 与计划书的偏差（如实记录，不悄悄改判据）

| 编号 | 计划书原文 | 实际做法 | 理由 |
|---|---|---|---|
| D-A | §41 S6：「要求：executed=false / failed」 | 断言 `executed=true` + `status=failed` | 那一对组合在本系统里**不自洽**：`executed` 的含义是"适配器真的被调用过"，而"执行失败"必然意味着它被调用过。`executed=false + failed` 只可能出现在"没被允许执行"，而那是 `rejected`。因此按**语义**断言，并把偏差写在这里 |
| D-B | §43 目录示例：`src/kernel/action/adapters/` | `src/infrastructure/action/adapters/` | 适配器要 `node:fs`，住 `kernel` 会打破 MI-13 / ADR-001（内存侧同样是 kernel + infrastructure 分层）。§43 用词是"例如" |
| D-C | §43 示例含 `action-target.ts` | `ActionTarget` / `TargetEvidence` 与请求协议同在 `action-request.ts` | 目标、证据、效果是**同一个协议**的四个面；拆成四个文件只会让"改一处要动四处" |
| D-D | §53 的 13 条提交 | 17 条（见 §13） | 把"量具自检/门结果汇总"等独立成提交，便于逐条复核 |
