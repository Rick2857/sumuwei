## 3. 已知未完成 / 边界（**逐条**）

```text
· ⛔ **`D` / `E` 未修**（§2.2）—— 它们**特征化**在门里（`vb-07`/`vb-08`）：修好之后门**会报红**，强制回来更新。
· ⛔ **问句守卫未做**：`VALUE_STOP_SET` 挡的是"**取值是疑问词**"这一种，**不是**问句本身
  ⇒ `L-M97-02` **收窄**（那条问句假阳不再落库）但**没有关闭**。
· ⛔ **qualifier / 否定表达不了**：`B` 的根因是规则表产出 `{subject, predicate, value}`、**没有 qualifiers 位**
  ⇒ 本轮只能"如实不记"，**不能**记成「不是计算机专业」那种否定取值。**登记不修**。
· ⛔ **真实模型档未跑**：本轮全部离线（不调模型、不打开数据库）。
· ⚠️ **`B` 是**有意的覆盖损失**（一个登记表例子从可达变成不可达）—— 依据任务书 §19：
  「Coverage 不完美可以接受，False Success 不可接受」。它已逐字记进语料 `revisions[4].boundary`。
· ⚠️ **`A` 的填充语清单是收窄的**（只收 5 个明确形式），裸的「吧/呢/吗」走**整值级**拒绝而不是尾部剥除
  —— 两者分工写在源码里。
· ⚠️ **`VALUE_STOP_SET` 里只有 2 条是实测的**，其余是**同类的推断扩展**（逐条写在源码注释里）。
  这是**如实登记**：扩展项未被单独实测。
```
