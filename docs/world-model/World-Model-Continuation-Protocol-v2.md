# 续验协议 v2（2026-10-20，首个 v2 模型调用前冻结）

本协议替代旧工具 A/B 的收益解释与反思草案对照口径。旧证据原样保留。源码与本文件 SHA-256 随证据记录。预测绑定、空计划完成闸与默认关闭提示词的缺陷已在冻结前修复；留出执行后不调参重跑。

## 工具对照

沿用已公开检查过的 D1–D4（开发）、H1–H8（复测），故称前瞻复测，不称全新独立留出。固定件见 `scripts/world-model-tools-ab.ts`：写效果/读内容两因素，读写能力组合与原批次相同。评分侧知道效果真值，模型侧只看用户任务和已授权动作的真实返回。

A 使用真实生产任务规划器；B 使用同一规划器加可选预测器。两臂均为 MiniMax-M3.1-Flash-Preview，温度 0；每任务 maxPlans=3（包括预测）、maxActions=6、每调用最多 1200 输出 token、20 秒；整任务保留原 10 分钟授权上限。无额外探索、无传输重试。交替 A/B 与 B/A 顺序。模型输入只有预测处理所需的差异，两个端口自身的程序提示词不同并固定。

主读数为真实目标完成数、误报完成数。真值必须同时满足固定件环境允许达成、所有必需动作实际执行；done 只是声明。所有八例进入分母，拒收、预算耗尽、超时、无动作都保留。另列正确完成声明数、总行动/规划预算/API 次数/token/时延。核对通过率指完成声明的精确率，不称任务成功率。最多每臂每例三次真实调用，总上限 72 次（开发+复测）。不把固定件推广到真实工具或长期使用。

## 反思草案对照

保留旧 D1–D4、H1–H8 窗口与句柄，B 增加经过来源检查的原定意图、实际结局与待复核成功判据。目标受阻不等于假设被反驳；成功也不能单凭结局要求模型不建议槽位。两臂程序提示词只在 B 打开比较材料说明，A 逐字保持原基线。

同一模型、温度 0、1200 输出 token、20 秒、每臂每例一次、无重试（总 24 次）。主指标为引用辅助比较 ID 的边界违规数和格式拒收数；槽位建议频率、结局提及只作诊断，没有“失败必须建议/成功不能建议”的评分规则。此批不测下一轮行为，不能关闭行为收益或真人体验缺口。传输失败单列，不能当边界零违规或收益；全部 transport 时执行验收失败。原语料已读，不称新独立泛化验证。

## 端点、停止与证据

真实模型测试必须通过 with-test-model 显式选择本发行检出自己的测试配置，不使用生产凭证。开发后不按分数改提示词；复测每域仅一次。每次按域记录执行状态、源码哈希、逐例返回类别；状态 PASS 只表示采集完整，不表示收益通过。若无法获得有效回答或收益未出现，保持默认关闭并停止扩大。PostgreSQL 机械门独立验收；功能激活、真实用户体验不由这些读数自动批准。
