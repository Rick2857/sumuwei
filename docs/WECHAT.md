# 微信群功能与配置

微信群是可选的**文字聊天入口**，使用同一个 LG 人格、正式轮次、记忆与认知核心；不是旁路聊天模型。适配器源码和 .env.wechat.example 已在此前的服务器版中提供，这次补齐 README 入口和配置说明。

## 当前范围

- 仅受理配置群白名单内、可核验的近期文字消息。机器人本人、非文字、过期或原消息核验失败时不进入正式回复。
- 模型结合当前消息与有界群语境决定是否接话；普通消息可以接话，@或称呼也不保证回复。突发消息合并为有界注意判断，旁听缓冲不自动成为长期记忆。
- 微信 ID 用于身份映射，昵称不用于鉴权。同一微信号跨群保持同一平台身份；同名 QQ 号不会自动合并为同一人。主人按配置绑定，资料仍受来源房间和读取作用域约束。
- 群成员不继承主人的桌面、文件、任务或工作流权限。最终回复仍走正式 LG 轮次及现有权限/回复处理。
- 当前不提供微信私聊、图片理解、入站语音识别、语音回复或通话。QQ 的语音双开关不会让微信改发语音。

## 前置条件

1. 已配置本项目的模型、数据库和唯一核心，以及当前运行外壳需要的 .env.qq。
2. 自己运行并登录一个与适配器兼容的本机 HTTP 微信桥。公开仓库不包含桥镜像、微信客户端、登录态、账号、群授权或运行数据；需自行核对上游来源、许可和接口兼容性。
3. 从自己的桥取得机器人/主人微信 ID 和允许接入的稳定群 ID。程序使用实际 ID，不使用展示昵称或群名称作授权。

当前微信轮询由现有 QQ 外壳进程承载，入口名仍是 **pnpm qq:chat**；没有独立的 wechat:chat 命令。配置完成后不要另外启动第二个认知核心。

## 配置自己的桥和白名单

```sh
cp .env.wechat.example .env.wechat
```

填写自己的值，下面仅展示字段含义：

| 字段 | 要求 |
|---|---|
| WECHAT_ENABLED | 设为 true 才启用，模板默认 false |
| WECHAT_API_URL | 默认 http://127.0.0.1:16174，只允许本机 loopback HTTP 根地址 |
| WECHAT_API_TOKEN | 自己的桥 Bearer token，至少 24 个字母、数字、下划线或短横线 |
| WECHAT_BOT_ID / WECHAT_OWNER_ID | 两个不同的平台 ID，必须与自己登录的账户及主人匹配 |
| WECHAT_ALLOWED_GROUP_IDS | 逗号或空白分隔的稳定群 ID，形式如 10000000001@chatroom；此值是合成示例 |
| WECHAT_STATE_FILE | 默认 data/wechat/state.json，服务用户须可写，包含私有接收去重状态 |

.env.wechat 仅由服务用户读取，令牌、真实账号/群 ID 和状态文件不要提交。启动器只从该文件载入 WECHAT_ 前缀字段，不把它当作任意环境覆盖文件。

```sh
pnpm qq:chat --check
pnpm qq:chat
```

--check 只核对启动配置，不能证明微信已登录或真正收发。已有服务时有序重启原编排，观察 wechat_group_ready、回复判定和投递结果；HTTP 接受不等于用户实际看到。

## 桥 API 契约

所有调用带 Bearer token，拒绝重定向并有超时。接口形状以 [group-client.ts](../src/infrastructure/wechat/group-client.ts) 为准：

| 接口 | 适配器使用的事实 |
|---|---|
| GET /api/status/auth | status=logged_in，loggedInUser 与机器人 ID 匹配 |
| GET /api/chats/:groupId | 返回同一个 id，且 isGroup=true |
| GET /api/messages/:groupId?limit=100 | 消息数组，包含本地安全整数 localId、来源群、发言者、文字、时间及非本人标记 |
| POST /api/messages/send | 按核验的来源群发送本轮文字回复 |

接收使用查询轮询，不依赖上游事件 WebSocket。首次启动会预热当前消息游标，避免把积压历史当作新请求回复；状态和有界去重保存在私有 data 目录。核心在接纳/发送前核对账户、白名单群及真实原消息，外壳自报的身份不足以授予权限。

更换机器人账户、桥或白名单时停止原外壳，备份自己的状态与配置，按新账户重新核验；不要把其它人的登录卷或状态文件导入自己的实例。公开源码检查不打开微信客户端，也不替你验证兼容桥的长时在线、真实群回复或平台行为。
