新增实验开关的发行缺省均为 false：

```dotenv
CHARACTER_EPISTEMIC_BELIEF_ENABLED=false
CHARACTER_EPISTEMIC_BELIEF_HUMAN_SHADOW=false
CHARACTER_EPISTEMIC_BELIEF_HUMAN_ENABLED=false
CHARACTER_SIMULATION_PLANNER_ENABLED=false
CHARACTER_SIMULATION_PRECONDITION_RULES_ENABLED=false
```

其中模拟与否决还需要匹配的规则资格、任务装配和权限；单独打开布尔开关不代表试验已配置或已取得收益。现有工具仍经 ActionGateway，不扩展任意文件访问权限。F2 的正文从任务实际读取进入受预算约束的规划上下文，指纹只用于受信判断与完成核验，不当作模型预知的源正文。

新版 PostgreSQL harness 是本次公开的源码组成，但公共 `ci:offline` 仍明确拒绝旧的 PGlite 数据库回归入口。请按门自身约定使用空白 `lg_test_*` 库；完整公开验收状态以 [PUBLIC-VERIFICATION](PUBLIC-VERIFICATION.md) 为准。不会以开发环境的既往通过记录替代这个公开检出的检查。

F2 真实链校准仍有未解决项：每题准备读取权威源后，同值的缓存/权威内容无法判定独立来源，来源限定规则缺少可达的成功对照，可能停在 pending；不能据闭环夹具宣称规则迁移或收益通过。此批保留归属不变量，不实施尚待裁定的对照修订。
