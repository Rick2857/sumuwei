# 2026-10-30 累计更新

本次同步此前服务器使用的源码增量及新的群聊修复。公开发行仍要求用户自行配置账号、权限与环境；生产配置、真实对话、数据库、部署地址和私有运行证据不进入仓库。

## 用户可见变化

- 统一语义操作入口：模型结合当前原话、同会话前文和可用对象，提出记忆、提醒、目标、工具、转告或群任务操作。程序继续验证身份、参数、权限、持久化与执行结局。
- 目标、承诺、提醒的自然语言回复交还模型；删除相关关键词/正则话术改写，仍保留真实操作事实与安全检查。
- 可选转告任务：获准 QQ/微信群入口可请求转告绑定主人，首版唯一出口为绑定主人的 QQ 私聊，不能任意指定收件人。
- [主人授权群任务](QQ-GROUP-TASKS.md)：支持一次发送和有期限/明确长期授权的回复窗口。生效任务按成员、话题、期限、次数与间隔约束接管群消息；终止后恢复普通群聊规则。代码缺省关闭。
- 群任务总额度未指定或 null 时表示不设总量上限；有限总量仍严格执行。每条入站和时间窗限制仍独立生效。语义入口原生建单及工具读取后的继续建单修正了重复解码问题。
- 群聊显示名逐轮更新，同时保留稳定账号；提供 @ 对象、回复关系、可见引用原文和时间信息，区分当前待答、背景及排队期间的同一人补充。
- 初识关系使用当前有限基础的措辞；不由关系修订号声称“从未聊天”，也不因一次小幅关系变化立即暗示关系破裂。
- 普通群聊短消息合并默认 300 ms，`QQ_GROUP_BURST_MS=0` 可关闭；最多三条、同群同人、保留来源。开启群任务准入下沉时不合并群入站，私聊也不合并。
- 普通群回复引用目标按次传递；群语音遵守平台的独立 record 发送约束。独立引用文字、语音、来源附录分别计入对外消息额度，结果不明时不重发。
- 成员资格每轮重新查询，复用核验连接而不缓存十分钟授权；增加排队、核验、语义请求、主回复及投递耗时读数。

本次也同步服务器已有的技能域、任务局部读根与独立核验等实现。相关开关默认关闭；源码存在不代表已验证模型会自主选择、独立完成任务或产生收益。

## 验证范围

私有服务器候选在 Linux serversim 中编译通过；使用独立 PostgreSQL、假模型和假 OneBot 的群任务组合检查为 60/60，开发树群聊检查为 49 项。它们不是公开副本的运行证明，也不证明真人收发、模型对话质量或延迟收益。

公开副本的本次验证结果见 [PUBLIC-VERIFICATION](PUBLIC-VERIFICATION.md)。真实模型多成员对话规格已冻结，状态仍为未执行；模型或真人效果应单独评估。
