## 0. 本轮路线决定

用户原话：**「我的计划是先不进行能力建设,全力完成Lv2.5-4.5，我需要一份lv2的验收计划书」**。

当前顺序调整为：

~~~text
既有人格 / 认知主线及其必要修复
 → 本计划：Lv2 综合验收与内核交接
 → Lv2.5 有限世界线
 → Lv3 身体表现
 → Lv4 基础实时语音
 → Lv4.5 持续对话协调
~~~

隔离代码执行、GitHub、微信/QQ、邮件、日历、通用浏览器、桌面控制和自主后台任务等外部能力包暂缓；恢复时机以后按实际需求裁定。**Lv2 通过不自动开工 M6.5 能力包，Lv4.5 通过也不自动恢复它。**既有入站自动回复与后台不干扰的设计决定保留，其实现排期随能力包暂缓。

这里的“暂缓能力建设”指上述通用行动与应用接入。用户要求的世界线、身体、语音和协调仍是后续主线。它们的实现与验收见[后 Lv2 首版工程计划](../research/Post-Lv2-Storyline-Embodiment-Realtime-Plan-2026-10-02.md)，本计划交付其前置内核，不将这些阶段提前判成完成。

本计划使用 Lv2 作为**人格/认知综合验收阶段**；证据层级另写 Evidence L1/L2。M 系列编号不等于成熟度等级，本计划不自行占用或宣布 M12 开工。

## 1. 验收对象与成功定义

在单用户、单角色、明确会话范围内，证明同一套 LG 真实轮次装配可以持续处理：

1. 有来源的记忆、召回、更正、遗忘和不确定性。
2. 关系、情绪、信念对回应的合法影响，且角色身份与事实资格保持稳定。
3. 当前目标、双方明确接受的约定、结清与取消，不把口头应答当作完成事实。
4. 合格反思及有限行为调整；来源失效后及时阻断，效果根据真实回复判定。
5. 多模块共同入模、跨会话回访、真实进程重启与字段级重建。
6. 可被后续世界线、身体和语音层调用的输入、输出、状态读面与生命周期说明。

**成功交付**：必选工程与行为门通过、真人复核通过、当前源码证据可追溯，并形成 Lv2.5 可消费的内核交接包。行为增益、生产配置和自然首用分别报告。

验收范围不包含新增外部适配器、世界运行器、皮套、STT/TTS、实时协调器、通用任务调度、Seed 内容变更或新事实写入权限。既有搜索和行动边界继续按原授权运行；测试使用隔离库或生产库副本。
