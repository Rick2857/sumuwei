## 2. 轮后 await 形状实测（§8.1 陷阱排除）

`maybeRunAffectEvaluation` 共 **3 处**生产调用（本轮源码级定位；await 位置是无条件结构性代码，非条件分支）：

| # | 位置 | 语义 |
|---|---|---|
| ① | `main.ts:1419` | 开机追赶：建档播种（含中断恢复）+ 尾窗消费 |
| ② | `main.ts:1504` | **同轮**：`beginTurn` 之后、`compileTurn` **之前**同步 await——本轮用户消息的 TOUCH/IMPACT 落库后，`renderAffectSection`（:1558）读到的投影**含本轮**（M8 Level 1 出口条件） |
| ③ | `main.ts:1901` | **轮后补消费**：回复落账后、**`return replyText`（:1909）之前**同步 await——消费她的回复事件（永不合格 ⇒ 0 提案），水位前进保持尾窗有界 |

**陷阱结论（§8.1 的警告成立）**：现行"轮后"（③）仍是回复返回**前**的同步 await。M8 规则毫秒级无碍；**M8.5 语义 LLM 若放在 ③，回复将被模型延迟阻塞**——这正是计划禁止的"把本轮 LLM await 放在 replyText 返回前再称为后台"。

**M8.5 插入设计**（供 WP6/WP8 落地，WP1 冻结细节）：

- ② 保留：semantic 模式下跑**结构性 TOUCH-only**（词形 IMPACT 关闭，§4.2）——同轮、确定性、无 LLM；
- ③ 改造：semantic 模式下把同步消费替换为**非阻塞"尾窗可处理"通知**，交受管理 worker（§8.1/§8.2）；`rules`/`shadow` 模式下 ③ 形状不变（现行行为逐字保留）；
- ① 对应 worker 的启动补发现（从持久会话 + 终结闸补发现，内存通知不是工作真相）；
- `affectAppliedThisTurn`（reply-truth 绑定，:1501-1509）在 semantic 模式下语义需模式感知（同轮只应用了 TOUCH）——WP8 冻结渲染边界行。

## 3. 零 DDL 承载实验 —— **PASS（14/14，EXIT 0）**

脚本：`scripts/m8.5-wp0-carryability.ts`（隔离库 `m8.5-wp0-carryability`；真实库未打开）。
证据：`artifacts/m8.5/wp0-carryability-20260926-142546/carryability.json`。

| 组 | 结论 |
|---|---|
| ① `character_jobs` | 语义任务生命周期（pending→running→completed + retry_count + 区间幂等键 + 部分唯一索引）**原样承载**。⚠️ **该表没有 payload 列**——回执不能设计成"job payload"（修正计划 §11.2 的表述，见下） |
| ② `processor_watermarks` | **三水位**（扫描 / 语义完成 / 最后成功影响）以不同 `(processor, processor_version)` 组合共存、互不覆盖；`assertWatermarkAdvances` 只进不退**真实生效**（回退 41→39 被拒且值不变——负控实测） |
| ③ `processed_operations` | **跨版本稳定终结闸** `affect-semantic-finalized:<sourceEventId>` 承载成立：`on conflict do nothing` 幂等、**首写保留**（同键重写被忽略）、紧凑闭集回执编码进 `operation` TEXT 列往返完整、`domain_event_id` 在 COMMITTED 形携带 IMPACT 事件 id；未写闸的来源读 false（负控通过）；闸行与水位同库互不干扰 |

**回执拆分设计（零 DDL 前提下的候选拆分，WP1 冻结）**：

- **终结闸行**（`processed_operations`）= 稳定键 + 紧凑闭集回执（终态 / 家族 / 指纹等有界编码）+ `domain_event_id` + `processed_at`——这是工作真相（worker 恢复读它）；
- **明细审计**（候选列表 / span 偏移 / 尝试计数 / 延迟）= trace 步骤（`character_traces`，白名单字段：id / 计数 / 布尔 / 闭集码）——不是工作真相；
- **`character_jobs`** = 调度生命周期（今天为 M8 承载的正是这些字段）；
- 生产写入函数 `recordProcessedOperation`（job-store 追加函数，**非 DDL**）归 WP6；本实验用与 `event-store.ts:523` 同形的原始 SQL 证明表承载性。
- 若 WP1 认为紧凑编码不足以承载 §6.3 回执内容，**新迁移是诚实路径**（须用户批准，沿冻结迁移纪律）——不以"不想迁移"伪造审计记录（§2.3）。
