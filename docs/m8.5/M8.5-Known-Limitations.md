# M8.5 Known Limitations —— 语义情绪理解的已知局限

> 状态：**WP12 草案（待人审 + 用户批准后随收口定稿）**。
> 编号沿计划 §25 拟议（L-M85-01…08）+ 实测补充（L-M85-09…）；每条注明读数来源。
> 纪律：**不预先冒充读数**——每条局限都有实测证据或冻结设计条文背书。

## 限制清单

### L-M85-01：慢路径延迟——语义影响最早下一轮可见（设计边界）

语义 IMPACT 在 completeTurn 后的轮后 drain 提交；本轮回复用的是编译时已提交的
状态。"可能不止延后一轮"是诚实口径（计划 §0.3/§8.1），不承诺时效。模型慢时
更晚（盲测 p95=5142ms、p99=8304ms；live 追赶段评估含在 boot 时延内）。
**读数**：e2e E1/E2（47/47）实测 `created_at` = drain tick 的 `now`、下一轮
可见 ±0.04。

### L-M85-02：类别空间固定 7 族（设计边界）

A-GRATITUDE / A-WARM-CONTACT / A-COMFORT / A-REPAIR / A-URGENT / A-HOSTILE /
A-REJECTION。新互动类型（如用户自述难过引起她的担忧）不在本版（计划 §2.2）；
后续候选见计划 §27，不因本版完成自动立项。

### L-M85-03：中文 / 单 Character / 单 active user 边界（设计边界）

语料、指令、真历史读数全部是苏沐薇 × 单 active user 场景（M8 冻结面继承）。

### L-M85-04：模型非确定性——跨 run 判定可能翻转（实测）

同一输入跨 run 判定可翻转（b-host-010 两 run HOSTILE、一 run NEUTRAL）。
管理方式 = 重复实验 + 翻转率阈值（终读数 0.0472 ✓ ≤0.05）+ 最差 run 报告值
（D-WP10-3），不假装确定性。**live 佐证**：同一文本在不同上下文里判定不同
（live run 3 SEM2=NEUTRAL vs run 4 SEM2=COMMITTED——上下文依赖是语义路径的
本意，两读数各有归属）。

### L-M85-05：上下文有界——6 条 / 30 分钟外可能 UNCERTAIN（设计边界）

不读全史（计划 §6.2）；窗口外指代 ⇒ 弃权（UNCERTAIN），失败关闭不猜。

### L-M85-06：rules 模式下词形误判保留至切换（设计边界）

M8.5 不在 rules 模式修 M8 词形误判（计划 §4.2）；shadow 读数里的
LEGACY_MISS（3/39）是词形漏、语义补的对照证据，不是 rules 模式的修复承诺。

### L-M85-07：span 协议依赖模型输出质量（设计边界）

定位失败 ⇒ 拒绝（失败关闭），弃权可能增多。11 码解析失败闭集逐项有负控
（§16.2）；解析失败 = 确定性终态不重试。

### L-M85-08：预算估算非精确 token（设计边界）

若 provider/tokenizer 不支持精确预估（计划 §6.2）；出站预算超限 ⇒ 确定性
失败关闭（不出站）。

### L-M85-09：切换残余窗口的中性来源可能被评估一次（实测补充，R-6）

证据式兜底的残余窗口：切走启动后、切回前出生的**无词形命中**中性来源，
可能在 120s 时龄策略内被语义评估一次（单次计分，非双重）。主机制
（semanticCutoverSequence）覆盖切换时刻之前的全部来源；词形 IMPACT 兜底
覆盖间期词形命中的来源；唯一不在两层覆盖内的是"间期出生 + 无词形命中 +
时龄内"的中性来源。**读数**：wp8 门按计划正确行为重写后 106/106（含本
窗口的构造用例）；ADR-068 R-6 记录。

### L-M85-10：激活瞬态——长历史上首个语义 boot 的扫描追赶（实测补充）

激活时扫描水位从当前值以批次 32/跳追赶；若在追赶完成前切走模式，取消扫面
会把**尚未发现的语义时代来源**埋进边界（无双计、无需闸——间期词形 TOUCH
即该时代写入者条目；live run 2 实测复现）。激活程序的水位预置
（scanner/worker := 边界）在真实激活中消除该瞬态；未预置的旧副本/手工激活
仍可能呈现。**读数**：live run 2（FAIL 7/11）+ 取证（水位/任务行/时间戳）。

### L-M85-11：关键假阳性残差 2/29（已裁定接受，人审终态已落）

@5+5000 终读数唯一未达项（0.0690 > ≤0.05）：b-rep-006（金标 UNCERTAIN vs
模型稳定 A-HOSTILE——金标与模型各执一词的硬边界）+ b-host-010（不稳定翻转，
随翻转率读数一并复核）。用户裁定接受为残差、不重跑凑数；b-rep-006 金标归属
交 WP12 人审独立裁定——**若人审支持模型读法，金标按语料修订程序修正，指标
重算 = 1/28 = 0.036 ✓；若维持 UNCERTAIN，本条为终态**（WP10 交接单 §5.3）。

**终态（2026-09-27 人审）**：用户裁定 b-rep-006 **维持 UNCERTAIN**（金标不因
模型读法修订）· b-host-010 翻转**接受**（0.0472 ≤ 0.05 达标）· Q1–Q9 暂定金标
全部确认。⇒ 本条按原口径 **2/29 = 0.0690 落为终态**，指标不重算；盲测终读数
维持 **10/11 + 已裁定残差**。裁定记录见 Corpus-Spec §6 人审终局节。

### L-M85-12：盲测判的是模型语义质量，不是提交链（读数归属）

盲测直连路径（出站→provider→解析→映射）不含 worker/Validator/事务；提交链
机械性由 WP9 离线门全量证明。两件合起来才是完整主张（WP10 交接单 §7.1）。

### L-M85-13：shadow 读数无金标、读数面有界（读数归属）

七类计数是"分歧地图"不是"谁对谁错"；LEGACY_FALSE_POSITIVE 是候选归属
（D-WP10-4），最终由人审抽样定。读数面 = 最近 2000 条事件内最近 120 source
（实测 = 全部 78 事件 / 39 source——生产库当前就这么大）；库增长后重跑可
扩大读数面。

### L-M85-14：测试端点 ≠ 生产端点（激活时已核对，差异仍在）

全部真模型读数描述 `.env.test` 指向的模型（deepseek-v4.1-flash @ ark 测试
端点）；生产 key 的模型若不同，激活前需按 §22 重新核对模型指纹
（Activation-Candidate §前置核对）。

**激活时核对（2026-09-27，ADR-069 §3）**：生产 = `api.deepseek.com` /
`deepseek-flash` ≠ 验收端点（ark / `deepseek-v4.1-flash`）——差异**如实
登记且不阻断**（与 M5.5/M7/M8 激活同款形态：验收走 `.env.test`，生产走
原 key）。后果：验收读数不直接外推到生产端点；首个真实对话轮的观察面
（ADR-069 §4）承担这一差异的运行时核对。

### L-M85-15：指令迭代的停止线（过程纪律）

@4 后语义校准不再迭代（ADR-068 R-3 停止线）；机械格式钉死（@2/@5 类别）与
用户裁定的传输预算适配（R-5：max_tokens 3,000→5,000）除外。若后续仍需语义
改动，那是新裁定、新 ADR 记录——不是本里程碑的继续。

### L-M85-16：truncated 现象已根治但端点行为仍在观测面（实测）

推理型端点偶发把 completion 预算烧在 reasoning 上（content 空 +
finish_reason='length'）⇒ 解析归 `truncated`（确定性终态不重试）。R-5 上调
5,000 后盲测消失（0.0094 ✓）；span 计数滑步 @5-3000 轮 1/318 次、无指令层
解。端点行为变化时按 Contract-Freeze §6 条款重新裁定。

### L-M85-17：语义判定不是事实来源（边界重申）

Affect interpretation ≠ 外部事实（ADR-068 §2.2）；M9 采信走自己的证据资格。
本里程碑不因此自动批准任何后续里程碑（计划 §0.4/§27）。

### L-M85-18：生产激活与 WP12 判定分列（流程状态——已闭合）

截至 WP12：工程面全绿（离线链 10/10 · 盲测 10/11+残差 · e2e 47/47 ·
长轨迹 12/12 · live 11/11），**人审未做、激活未批准**——`CHARACTER_AFFECT_
SEMANTIC_MODE` 代码缺省仍 `rules`，生产 `.env` 未设该变量。三者（门 PASS +
人审 PASS + 用户显式批准）不可互相替代（§22.1）。

**闭合（2026-09-27）**：人审 PASS（声明式裁定，§4.3 / Corpus-Spec §6）+
用户显式批准（同轮分别裁定）⇒ WP13 已执行（ADR-069：seeded_fresh ·
cutover=117 · `.env` 设 semantic，**代码缺省仍 `rules`**）。本条作为流程
状态记录保留；运行时边界见 `L-M85-14`（端点差异）与 ADR-069 §4（流量
依赖读数待首个真实对话轮）。
