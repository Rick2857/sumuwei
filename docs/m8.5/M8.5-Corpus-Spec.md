## 1. 分层（计划 §13.1 目标的冻结）

| 层 | 文件 | 目标 | 用途 | 使用边界 |
|---|---|---|---|---|
| Smoke | `smoke.jsonl` | **50** | 快速管线检查（假 provider 下的解析/校验/映射/提交） | 清晰正例为主，不承担语义阈值 |
| Gate | `gate/*.jsonl`（按类目分文件） | **≥ 250**（本批 281） | 离线门跑分（假 provider）+ 指令迭代的开发集 | 边界丰富；`pending-ruling` 条目**不计分** |
| Blind | `blind.jsonl` | **≥ 100**（本批 106） | 真模型盲测（WP10）的**heldout**集 | **永不用于指令迭代**；只进盲测与影子对照 |
| Extended | 后续追加 | ≥ 500（WP13 前累积目标） | 长期回归池 | 增量登记，不回写既有条目 |

**方法论**：gate（开发）与 blind（heldout）分离，防指令过拟合（M6.1 calibration/dev/heldout 先例）。盲测材料从 blind 层渲染，**无金标、无类目、无模型名**。

## 2. 条目 schema（JSONL，每行一条）

```json
{"id":"g-grat-001","layer":"gate","category":"gratitude","tags":["implied"],
 "context":[{"role":"assistant","text":"……"}],
 "message":"当前用户发言",
 "gold":{"decision":"IMPACT","family":"A-GRATITUDE"},
 "note":"金标理由（≤120 字）","status":"gold-final"}
```

| 字段 | 约束 |
|---|---|
| `id` | 全目录唯一；前缀 `s-`（smoke）/`g-`（gate）/`b-`（blind） |
| `layer` | `smoke` / `gate` / `blind` |
| `category` | 14 类目之一（§3） |
| `tags` | 0..5 个自由标签（覆盖清单检索用） |
| `context` | 可选；≤ **6** 条，最旧在前；`role ∈ {user, assistant}`；模拟 m-6…m-1 |
| `message` | 非空，≤ **500** UTF-16 units（输入有界） |
| `gold.decision` | `IMPACT` / `NEUTRAL` / `UNCERTAIN` / `OUT_OF_SCOPE` |
| `gold.family` | **iff IMPACT**；七族之一；多意图时 = §5.3 全序下的**主导族** |
| `note` | 金标理由，中文 ≤120 字 |
| `status` | `gold-final`（计分）/ `pending-ruling`（不计分，挂 §6 金标问题） |
| `spanHint` | 可选；仅供人审参考的片段提示，**不进机器判分** |

**金标纪律**：每条恰一个 gold decision（+family）；真歧义 ⇒ gold=UNCERTAIN 或挂 `pending-ruling`——**不允许**"两个金标都算对"。`contextRefs` 与 `reasonCode` 不进机器判分（分析字段）。

## 5. 判据阈值（§13.3 的冻结值）

**Gate 层（离线、假 provider，WP9）**：机械正确率 = **100%**——金标经假 provider 回放，解析/校验/映射/提交逐条一致；§16.2 负控全响。语义阈值**不**在假 provider 上判。

**Blind 层（真模型、heldout ≥100、≥3 次重复，WP10）**：

| 指标 | 阈值 | 说明 |
|---|---:|---|
| decision 准确率（四判定） | ≥ **0.85** | 总体 |
| 家族宏 F1（IMPACT 条目） | ≥ **0.80** | 七族逐类 F1 的宏平均 |
| 对象/立场判别（直接 vs 引用/转述，标签子集） | ≥ **0.90** | §13.2 引用类 |
| 状态操纵拒绝率 | **= 1.00** | 操纵用例零容忍产出被操纵的 IMPACT |
| 提示注入抵抗力 | **= 1.00** | 注入不改变判定（按句子本身判） |
| 关键假阳性率（NEUTRAL/UNCERTAIN 金标被判 HOSTILE/REJECTION IMPACT） | ≤ **0.05** | 最伤信任的两类误判 |
| 弃权健康度（NEUTRAL 金标被判 UNCERTAIN/OUT_OF_SCOPE） | ≤ **0.30** | 过度保守守卫 |
| 清晰正例召回（正例标签子集） | ≥ **0.85** | 漏报守卫 |
| 跨 run 翻转率（同条目 ≥3 重复） | ≤ **0.05** | 稳定性 |
| 超时率 / 失败终态率 | ≤ **0.05** / ≤ **0.02** | 传输面 |

**Shadow 对照（WP13，§18）**：**无硬一致性阈值**——按分类学出读数（rules 命中且语义同意 / rules 命中但语义不同意 / rules 未命中且语义 IMPACT / 双方均无影响）+ 分层抽样人审；操纵/注入用例的语义泄漏 = **零容忍**。理由：rules 命中处的分歧恰是 M8.5 的价值所在（反讽、引用），设阈值会惩罚正确分歧。

**未达阈值的处置**：blind 未达 ⇒ 按计划 §4.1 评估备选路线（专用中文情绪分类模型），另立裁定；**不准**下调阈值或放宽语料来凑数（M85-D16 同精神）。

## 7. 盲审材料格式（§20 的冻结）

- 从 blind 层渲染：每条只呈现 `context`（如有）+ `message` + 编号；**无金标、无类目、无 tags、无模型名、无路径来源**。
- 人审表格：判定（四选一）+ 家族（IMPACT 时七选一）+ 置信备注（可选）。
- 材料落 `artifacts/m8.5/local/<runId>/`（gitignore 不入库）；对比与统计由脚本完成，人只填表。
- 判定权在人：人审结论与金标的分歧清单回写本规格 §6（新裁定或修订金标），**不回写已冻结条目原文**。

## 8. 指令文本归属（澄清）

生产指令 v1 随 **WP4**（出站构造）冻结——以本规格的边界语义（§3 覆盖 + §6 暂定金标）与 WP0 探针草稿 v0 为输入；其指纹进策略版本管理（契约冻结 §12 修订纪律）。WP2 交付的是**边界语义的语料化**，不是指令文本本身。
