## 3. 方法论要点（冻结进规格）

- **gate（开发）/ blind（heldout）分离**防指令过拟合；blind 永不进指令迭代（M6.1 calibration/dev/heldout 先例）。
- **金标纪律**：每条恰一个 gold；真歧义 → UNCERTAIN 或挂 pending-ruling（9 条，人审裁定后回写规格 §6，不回写条目原文）。
- **引用/虚构立场规则**：显式引语框架（"小说里说…"）→ NEUTRAL；裸台词按字面判。
- **操纵/注入双形**：纯注入 → OUT_OF_SCOPE；附带注入 → 真实互动成立、注入被忽略（gold = 底层互动）。
- **同句撤回**：被明确撤回的片段不进活跃候选（§5.3 立场先行）；"当我没说"式自撤 = 弱式修复。
