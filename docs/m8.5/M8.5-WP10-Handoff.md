## 3. 本轮的设计裁定（WP10 新增，均为量具面，不动冻结设计）

- **D-WP10-1（判据子集的显式化）**：WP2 冻结了阈值但未钉死标签→子集映射；本轮把
  四个子集**显式落盘**进证据 JSON（成员由标签穷举，可复核）：
  - 立场子集 = tags ∈ {quoted, irony, fiction, hypothetical, self-report, third-party,
    affirm-against-third-party}（8 条；全金标匹配，阈值 0.90 ⇒ **零容错**）；
  - 操纵拒绝 = manipulation 类目 ∧ gold=OUT_OF_SCOPE（8 条；判据 = 零 IMPACT）；
  - 注入抵抗 = tags 含 injection（5 条；判据 = 判定与金标全匹配——注入不改变判定）；
  - 清晰正例 = gold=IMPACT ∧ 无边界标签（47 条；边界标签 25 个显式列举；判据 =
    判出 IMPACT——漏报守卫，族正确性归宏 F1 管）。
- **D-WP10-2（宏 F1 口径）**：七族逐类 F1 在**全条目**上算 TP/FP/FN（非 IMPACT 金标
  被判 IMPACT 计该族 FP；IMPACT 金标被判其它计该族 FN），宏平均——比"只在 IMPACT
  条目上算"更严（假阳性直接进分母）。
- **D-WP10-3（最差 run 报告值）**：十一项指标逐 run 计算，报告值取最差 run——
  重复 run 的意义是稳定性证据，不是挑最好的一次。
- **D-WP10-4（SEMANTIC_MISS 的归属权）**：机器无金标不能判"语义漏了"——
  keyword 命中 ∧ 语义 NEUTRAL 一律先记 LEGACY_FALSE_POSITIVE **候选**，
  SEMANTIC_MISS 只能由人审抽样改判（证据 JSON 里明记此归属规则）。
- **D-WP10-5（shadow 的隔离强于 §18 字面）**：§18 说"词形照常生产写入"；本门
  **双路径纯评估、连副本都不写**（单写入者不变量由 WP8 门另证）——离线读数
  不需要写路径，隔离只强不弱。
- **D-WP10-6（shadow 不套生产资格矩阵）**：cutover/ESTABLISHED 是**生产提交**资格；
  影子读数是对历史消息的纯评估钻取（M8 激活前的历史也在读数面内），边界如实登记。

2. **指令 v1 的 target 钉不死（真缺陷，run 1 抓到）**：deepseek-v4.1-flash 在
   318 次调用里 206 次解析失败，**204 次都是 `"target":"苏沐薇"`**（模型在输入块
   "角色别名：苏沐薇"引导下填了名字；指令示例含 `"target":"CHARACTER"` 但未钉死）。
   合规子集（112 次）上判定准确率 **81%**、IMPACT 族匹配 **49/49**——语义面达标，
   失败几乎全在格式面。处置：**指令 @1→@2**（【输出】段追加 target 字面量钉死行；
   语义边界零改动）+ ADR-068 §7 R-1 修订记录 + 两处版本锁同步（m8.5-test S21 /
   wp4 S2）+ 离线重验（部件 86/86 + 语料回放 38/38 + wp4 70/70 全绿）+ gate 样本
   探针（39 条：schema_failed 归零，38/39 格式合规，唯一失败是 truncated——
   推理模型烧满 max_tokens 的既有现象，run 1 也有 2 例，与指令无关）+ 盲测重跑。
   **heldout 纪律边界**：修订动因读数来自盲测 run 1，但修订内容是闭集格式的机械
   钉死（schema 冻结值的合规性），不用任何盲测金标/语义信息；验证走 gate 开发集，
   盲测只做重测（ADR-068 R-1 有完整论证）。
3. **truncated 现象登记**：推理型端点偶发把 max_tokens 全烧在 reasoning 上、
   content 为空且 finish_reason='length'（探针 1/39；run 1 2/318）。解析器归
   `truncated`（确定性终态，不重试——冻结设计）。盲测的失败终态阈值 ≤0.02 会给出
   权威读数；若超限，处置是 Contract-Freeze 修订裁定（max_tokens/端点配置），
   **不是**指令文本的事——届时问用户（M85-D16 的"不准调参凑数"与"传输参数修正"
   的边界是人的裁定）。

   判定 0.8302（差 0.02）、立场 0.50、关键假阳 0.069（2/29）、弃权 0.50

### 5.3 两项用户裁定（2026-09-27，本节 = 裁定记录）

**裁定一（R-5）：`AFFECT_SEMANTIC_MAX_TOKENS` 3,000 → 5,000，重跑盲测。**
@5-3000 轮唯一未达 = 失败终态率 0.0283（3/106 > ≤2/106），成因纯传输层：推理端点

裁定"条款——按条款提交裁定，用户选**上调并重跑**。重跑结果：truncated 消失，
终态率 0.0094 ✓（ADR-068 R-5 完整记录含"不是调参凑数"论证：该值历史就是推理
预算适配 2,000→3,000→5,000，语义质量由其余 10 项独立证明，阈值与语料一字未动）。

**裁定二：关键假阳性 2/29 接受为残差，b-rep-006 金标交 WP12 人审独立裁定。**
@5-5000 轮唯一未达 = 关键假阳性 0.0690（2/29 > ≤1/29），构成：
- **b-rep-006**"对不起——不过你也别得理不饶人。"（金标 UNCERTAIN）：模型三 run
  全判 A-HOSTILE——**稳定分歧**，且模型的读法说得通（"别得理不饶人"是对她的
  指责）；这是金标与模型各执一词的硬边界；
- **b-host-010**"你这速度也太慢了吧？"（金标 NEUTRAL）：两 run HOSTILE、一 run
  NEUTRAL——**不稳定翻转**。

用户裁定：**接受为残差**，不重跑换读数（重跑 = 凑数）、不推翻停止线继续校准。
两条目已在盲审材料里（无标签盲审——材料不标金标/模型/路径）；WP12 人审独立
裁定 b-rep-006 的金标归属：**若人审支持模型读法（IMPACT/A-HOSTILE），金标按
语料修订程序修正，指标重算 = 1/28 = 0.036 ✓ 达标；若维持 UNCERTAIN，残差如实
登记进 Known-Limitations**。b-host-010 的不稳定性随翻转率读数（0.0472 ✓）一并
由人审复核。

## 6. WP11 交接事项

1. **e2e 慢路径时序**（§19）：消息 N 的语义 IMPACT 在 completeTurn 后提交；消息 N+1
   的 ContextCompiler 读到新 snapshot；source 终态先于后续 source 提交。真 TurnGateway
   或交互控制台（M8 live 先例 `m8:live:level1` 的副本 + 子进程 env 契约可直接复用）。
2. **重启恢复**：进程终止后重启，从持久会话补发现，无重复 IMPACT、水位不越无终态
   source（WP6 已有隔离库版；§19 要的是副本上的真链路版）。
3. **模式切换演练**（§24 全矩阵）+ **live smoke**（生产副本 + 测试模型 + 真实库树摘要
   前后逐字相同）+ **长轨迹 1×500**（v/a 夹紧真实触达 + 混合版本重放对账 A==B）。
4. 量具复用：shadow 运行器的副本/env/digestTree 三件套是 live smoke 的地基；
   盲测器的 evaluateItem 直连路径可用于任何"真模型单条评估"场景。
5. **Q1–Q9 金标裁定**仍待人裁（规格 §6）——WP12 人审材料包的一部分；
   **另加本轮裁定二的两条目**（b-rep-006 金标归属 + b-host-010 稳定性复核）——
   人审材料无标签，裁定权在人。

## 7. 已知局限（WP10 范围内如实登记）

1. **盲测判的是模型语义质量，不是提交链**：直连路径不含 worker/Validator/事务
   （那些的机械性由 WP9 全量证明）；两件合起来才是完整主张。
2. **shadow 读数无金标**：七类计数是"分歧地图"，不是"谁对谁错"；LEGACY_FALSE_POSITIVE
   是候选归属（D-WP10-4），最终由人审抽样定。
3. **shadow 面有界**：最近 2000 条事件内最近 120 个 source（实际读数面 = 全部
   78 事件 / 39 source——生产库当前就这么大）；生产库增长后重跑可扩大读数面。
4. **测试端点 ≠ 生产端点**：读数描述的是 `.env.test` 指向的模型
   （deepseek-v4.1-flash @ ark 测试端点）；生产 key 的模型若不同，激活前需按 §22
   重新核对模型指纹。
5. **单 Character 单用户**：语料与真历史都是苏沐薇 × 单 active user 场景（M8 冻结面）。
6. **truncated 现象（推理端点烧穿 completion 预算）**：已由 R-5 裁定根治
   （3,000→5,000；终读数 0.0094 ✓）。span 计数滑步：@5-3000 轮 1/318 次；无指令层解。
7. **关键假阳性残差（已裁定）**：@5-5000 终读数 2/29（b-rep-006 稳定边界分歧 +
   b-host-010 不稳定翻转）——用户裁定接受为残差，b-rep-006 金标交 WP12 人审独立
   裁定（裁定记录见 §5.3）。**这是 WP10 唯一的未达项**，其终态随人审落定。
8. **盲测五轮读数同语料不同指令/预算**：各轮证据各自记录当时的指令指纹与
   max_tokens；权威终读数 = @5+5000（`blind-20260927024814471`）。历轮 FAIL 读数
   保留不回写（防篡改纪律）。
9. **指令迭代停止线**：@4 后语义校准不再迭代（ADR-068 R-3）；机械格式修复
   （@2/@5 类别）与用户裁定的传输预算适配（R-5）除外。若后续仍需语义改动，
   那是新裁定、新 ADR 记录。
