# Lv2.5 世界线：可选功能

本发行版保留 Lv2.5 的运行器、内容包、账本、来源校验和认知消费者。它通过独立入口 `src/features/lv25/index.ts` 提供，普通聊天默认不加载这一入口及其专用实现，不为故事解析或故事消费发出模型请求。

这次调整不是删除远端故事源码，也不是启用某个运行环境。原有文件路径、命令和历史材料保留；不发布部署记录、配置、数据库或运行证据。

## 启用与停止

先按[发行边界](PUBLIC-DISTRIBUTION.md)配置自己的模型和 PostgreSQL，并通过原有受控迁移流程准备表结构。可选模块不会暗中迁移数据库。

需要在日常聊天中使用故事时，在自己的环境文件中显式设置：

```dotenv
CHARACTER_STORY_COGNITION_ENABLED=true
CHARACTER_STORY_CHOICE_DECISION_ENABLED=true
CHARACTER_STORY_DAILY_ENABLED=true
CHARACTER_STORY_CHOICE_DECISION_TIMEOUT_MS=8000
```

三项代码缺省和示例值均为 false。总开关决定故事装配与消费；选择开关决定是否调用私有选择模型；日常模式允许相关轮开局/续接。开启后会增加有界模型决策，反思消费也可能调用模型，需自行承担额度与时延。

原有 `pnpm story:start`、`pnpm story:withdraw` 命令保留。显式执行这些命令本身就是选用故事功能，可能写入故事账本或撤回事件；它们不代表常规聊天总开关已开启。参数约束和服务端绑定仍由原有校验器执行。

停止时将三个开关都改回 false 并重启自己的进程。停止不删除历史账本、不撤销已经产生的认知影响；不要为了停用功能 DROP 表或删除记忆。

## 保持的边界

- 用户决定故事选择。模型只提案，不替用户自动决定行动。
- 世界引擎经原有提交口产生结果，已提交且可见的经历才具有相应来源资格。
- 反思和三槽行为调整继续通过原有来源、独立根、会话与冲突门槛，不从模型续写直接写状态。
- 内容包与所有原有专用实现保持原路径，核心入口仅保留类型引用和受开关/显式命令保护的动态加载；不增加通用“世界内核”权限。

## 检查范围

`pnpm lv25:optional:verify` 检查默认值、显式启用，以及真实 `main.ts` 的导入图：仅在内存中去掉最外层 `main()` 调用，防止打开数据库，保留其余真实导入。另测显式加载、注入提前加载的反例和恢复后的默认行为。它不执行完整聊天轮，也不把导入成功当作故事数据库链路通过。

加载图探针需要支持 `node:module.registerHooks` 的 Node 构建；托管 CI 使用固定 Node 版本。较旧 Node 的 `ci:source` 会明确标记该探针 NOT RUN，其余既定源码检查仍运行。运行时的动态加载不依赖这个探针 API。

后续数据库验收必须使用隔离 PostgreSQL。旧 S8 数据库 harness、完整回归、真实模型、真人故事体验和生产启用在本次公开副本中均为 NOT RUN；历史读数不能替代当前验收。
