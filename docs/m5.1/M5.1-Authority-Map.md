## 2. 禁止方向（G-01 / G-02 / G-03 的可检查形式）

```text
Developer Page  → persistence               禁止（页面不得持有 db 句柄、不得 import infrastructure）
Developer Page  → 自行实现业务逻辑           禁止（只消费 Query / Control 的返回值）
Control API     → 直写 Event Ledger          禁止（必须走既有 Domain Command）
Control API     → 直写 Database              禁止
Control API     → 绕过 ActionGateway 执行副作用  禁止（否则触发 STOP 条件 14）
Query API       → 写数据库                   禁止
Query API       → append 事件                禁止
Query API       → 修改 memory                禁止
Query API       → 调用 executor              禁止
Query API       → 调用 external tool         禁止
Developer API   → Memory Store mutation      禁止
第三方 backend  → 成为事实源                  禁止（顶多是 Provider，且要过 ADR）
OTel / Phoenix  → 反向定义业务结构            禁止（`CharacterRunTrace` 不随后端改变）
Query DTO       → 直接暴露 persistence entity 禁止（必须经 DTO）
```

**可机检的落地约束**

| 约束 | 谁来检 | 何时 |
|---|---|---|
| `src/kernel/**` 不得 import 基础设施（`app/` 除外） | `scripts/kernel-tests.ts:504-537`（已有的依赖方向锁） | 每个 WP |
| Query 端到端 **Mutation Count = 0**（前后快照逐字段一致） | WP2 的负控 Hard Test | WP2 HARD GATE |
| Control 结果与 Ledger / 权威状态一致 | WP3 的执行真相测试 | WP3 HARD GATE |
| 删除 Developer Page 后 kernel / agent / 全部核心测试照常 | WP5 验收 | WP5 |
| 导出遥测零泄漏（secret / memory-body / api-key / system-prompt 哨兵） | WP4 的泄漏负控 | WP4 HARD GATE |
| Query/Control 不得直接持有 db | WP2/WP3 的静态锁（`grep` 断言 handler 内无 SQL） | WP2/WP3 |

## 3. 冻结声明

以下内容在本里程碑内**不得被取代、不得被绕过、不得被"顺手改好"**：

1. **Authority 清单（G-01）**：Identity / Character Kernel / Domain Model / Memory Lifecycle /
   Event Ledger / Policy / Reality·Execution Truth / Context Compiler —— 第三方库、Web UI、
   OTel Backend、Query API 一律不得取代它们。
2. **执行入口唯一（ADR-030）**：`ActionGateway` 是唯一的执行入口，`evaluate()` 是唯一的"只判定"入口。
3. **prompt 出口唯一（铁律 11）**：只有 `composePromptFromPacket()` 能拼 prompt。
4. **Trace 是业务数据**：观测后端挂了、换了，`character_traces` 与 `CharacterRunTrace` 一个字不改。
5. **资格判据唯一**：召回资格只走 `exclusionReasonForStatus` / `isRecallEligible`，
   不许任何新模块自己写 status 字面量比较。
6. **量具自己也要被验证（INV-M45-06）**：任何 M5.1 的 Hard Gate 必须同时证明
   "测量范围正确"与"测量结果正确"，且**正控 + 负控必须同时存在**。
7. **证据纪律（AGENTS §6）**：门汇总只读已落盘证据；文件不存在 = `not-run`，**不是 PASS**。
