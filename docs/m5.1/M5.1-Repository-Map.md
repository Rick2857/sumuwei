## 2. 已经存在的"开发者平面"（M5.1 必须投影，不得重写）

这是 WP0 最重要的一条结论：**"开发者平面"在 M5.1 之前不是零，而是散落在 CLI 上。**

| 既有只读入口 | 命令 | 权威来源 | M5.1 的动作 |
|---|---|---|---|
| 内核视图 | `pnpm kernel:status` | 事实账本 / 领域事件 / 投影 / trace / 身份快照 | **reuse**（`HealthDto` / `TraceSummaryDto` 的字段来源） |
| 记忆统计 | `pnpm memory:stats` | `MemoryStatsView` + `memoryIntegrityProblems()` | **reuse**（`MemoryStatsDto` 逐字段投影，**不重新实现状态判断**，AT2.4 明令） |
| 记忆审计 | `pnpm memory:audit` | `renderMemoryAudit` + 完整性探针 | **reuse** |
| 记忆检索 | `memory:list` / `memory:get` / `memory:history` / `memory:sources` / `memory:replay` | `MemoryStorePort` + 溯源视图 | **reuse** |
| 行动账本 | `action:list` / `action:show` / `action:trace` / `action:audit` | `ExecutionLedgerPort` / `foldExecutionRecord` / `ActionLedgerEvent[]` | **reuse**（`ExecutionSummaryDto` / `ExecutionDetailDto` 字段来源） |
| 身份 | `pnpm seed-status` | Seed 版本 / 指纹 / 历史 | **reuse** |
| 状态快照 | `pnpm inspect` | CharacterState | **reuse** |
| Prompt 形状 | `pnpm dump-prompt`（`buildGateway({dryRun:true})`，`main.ts:1120`） | ContextPacket | **reuse**（只读网关**不注入任何写路径**，有回归锁） |

**结论**：M5.1 的 Query API 是这些 CLI 视图的**统一只读投影**，不是新权威。
`Developer*Dto` 的每一个字段都必须能在上表或 §1 的权威形状里找到对应字段（WP1 有机械式 anti-drift 检查）。

## 3. "M5.1 接在哪里？"

```text
① Query 面（WP2）
   既有 readers（trace-store / event-store / memory-store / memory-integrity / action-ledger-store）
     ↓  只读聚合（新 port DeveloperQueryService，契约在 kernel/contracts/）
     ↓  adapter 落在 src/infrastructure/dev/**（WP2 决定具体文件）
     ↓  最小只读 HTTP（node:http，loopback，dev-only 开关；零新依赖）
   开发者页面（WP5：极简静态 HTML，只消费 Query/Control）

② Control 面（WP3）
   POST /dev/control/:type
     ↓  白名单 CONTROL_COMMAND_FACTS（fail closed，未知命令 REJECT）
     ↓  只读诊断 / 审计命令**不经过** ActionGateway（它们没有外部副作用）
     ↓  任何未来的 mutating 命令**必须**走既有 Validation → Policy → ActionGateway → Event Ledger
        （否则触发 STOP 条件 14：需要绕过 Execution Gateway）

③ 观测面（WP4）
   既有 CharacterRunTrace（业务真相，永不动）
     ↓  OBSERVABILITY_STAGE_FACTS 分类法（新契约，只有映射，没有第二个真相）
     ↓  既有 TelemetryPort（Noop / Phoenix）—— **不新建第二个端口**（见 F-7）
     ↓  key 级敏感数据白名单（新契约）+ 既有值级哨兵守卫（memory-trace.ts，不动）
```

**绝不新增**：第二套 prompt 出口、第二套 ContextCompiler、第二套 trace、第二套 provenance、
第二个数据库、第二个观测端口、第二个幂等/序列化实现、第二个权限系统。
