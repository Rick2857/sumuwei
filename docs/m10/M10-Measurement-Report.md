## 2. 三段式：正控 / 负控 / 恢复（AGENTS §6.7）

每一道被覆盖的门都走**完整三段**，缺一段就不算自证：

```text
① 正控  未注入的树上，那道门必须 **exit 0**（合法输入 ⇒ 安静）
② 负控  在**被测面**上注入一个**具名缺陷** ⇒ 那道门必须 **FAIL**，且**指定的那一条检查**变红
③ 恢复  字节还原（比对 sha）后重跑 ⇒ 必须**重新 exit 0**
```

⚠️ **② 的判据是"指定的那一条检查变红"，不是"门红了"**：
一道门可能因为**别的原因**红（编译错、无关的检查）⇒ 只看退出码会把"注入没生效"读成"负控成功"。

## 5. 构建量具时抓到的**缺陷**（量具自己的历史，不是产品的）

| # | 缺陷形态 | 教训 |
|---|---|---|
| 1 | 行尾：注入表按 `\n` 写，仓库文件是 **CRLF** ⇒ 多行注入点**匹配不上**（`N9` 一开多行就撞上） | 它**没有静默失效** —— 存在性检查把它报成 `MEASUREMENT INVALID`。**那条检查就是为这一刻写的** |
| 2 | 红检测器要求 `[group]` 标记，而早期门的输出**没有方括号** ⇒ "真的红了"被读成"没红" | **量具不该假设别人的表现层**：判据只依赖 **id 这个 token**，且要 `\b` 防 `I1` 匹配到 `I10` |
| 3 | 负控"相对**表里的值**翻一个" ⇒ 当被测对象已经异常时，翻转结果**恰好等于真值** ⇒ 控制失去意义 | **控制要相对"真值"翻**，不能相对"被测对象当前的状态"翻 |
| 4 | **注入档与真 FAIL 档在盘上完全同形** ⇒ 读证据的人分不清"她真的红了"与"我们故意让她红的"（实测把两道门误判 FAIL） | 修法：注入方子进程 env 带 `M10_INJECTION`，由 `writeM10Manifest`（全仓唯一写清单处）记进清单；`m10:gates` **排除注入档**。**"我故意造的 FAIL"与"真的 FAIL"必须可分** |
| 5 | 判结构时把 `child_process` 的 **import 语句**当成 spawn；剥字符串时又把判据自己要读的 `'git'` 剥掉 | **"判结构"的量具也必须往真实产物上跑一次**（三次修正全部只有跑真文件才发现） |

## 5.1 三道**自指**判据（`V2a`/`V2b`/`V2c`，本轮新增）

本门前三段（正控 / 负控 / 恢复）证明的是"**注入能弄红**"。
它们**不**证明"没有人靠'永远为真'混过去" —— 而 M10 自己的门里**真的有三例**：

```text
① `m10:e2e:verify` 的 `G39`：`members.length <= allRows.length
   && members.join(',') === […].sort().join(',')` ⇒ **恒真**
   ⇒ 一条"关于冲突"的检查，**观察到 0 个冲突**却始终绿（`L-M10-64`）
② `m10:completion:verify` 的 `I1`/`I3`：`goalCompletionUnitOf(marker)
   === goalCompletionUnitOf(marker)` ⇒ 纯函数同参调两次 ⇒ **恒真**
③ `m10:gateway:verify` 的 `S5`：判据就是字面量 `true`，而 `expected`
   却用断言口吻写着"排序规则不变"（那是一件**它没验**的事）
```

⇒ 本门现在**自指**地断言三条（实现在 `scripts/m10-gauge-audit.ts`，用 TS 编译器 API
解析全部 `m10-*.ts` 的 `record(...)`）：

```text
V2a **分母自证**：解析到的调用数必须 > 0（实测 scanned=368 · 调用点=417）
V2b **无条件为真必须自报家门**：pass 恰为 `true` 的检查，要么同一 `(file,id)`
    还出现过非 `true`（⇒ 两分支判据的绿半边），要么在 `expected` 里声明"不作断言"
    （实测：无条件为真 10 条 · 全部已自报家门/两分支 · **未自报家门 0 条**）
V2c **不许自比较恒真**：`f(x) === f(x)`（实测 0 条 —— `I1`/`I3` 已修）
```

⚠️ **它是筛子不是判决**：实测**误报过一次** —— 本门自己的 `V-<注入>`
被判成"无条件为真"，而它其实是**两分支**（找不到注入点记 `false`、找到记 `true`）。
⇒ 所以 `V2b` 的判据写的是"**必须自报家门**"，而不是"`true` 一律不许"。
⇒ 这条经验也说明了为什么**审计器不自动改任何东西**。
