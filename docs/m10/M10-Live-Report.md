
⇒ 本档的两条门因此**现在才跑得起来**。

## 2. `m10:smoke:live` —— 小批真实链（**PASS 8/8**）

```bash
pnpm with-test-model pnpm m10:smoke:live
```

**一条有状态的脚本轨迹 7 轮**（后面的轮次**依赖前面真的写下的目标** ⇒ 候选来自真库，不是手工给）：

```text
建目标 → 问清单 → 无关话 → 报完成 → 取消 → 再建一个 → 暂停
```

| 项 | 读数 |
|---|---|
| 判据 | **8/8** |
| 轮次 | 7（真模型） |
| **写路径命中** | **3** 轮（`measured_count > 0`） |
| 时延 | min/mean/max = 1811 / 2371 / 3763 ms |
| 库 | `%TEMP%\project-lg-exp-m10-smoke-live-…`（`C1` **断言路径**，不靠"我记得调了 `isolate`"） |
| 端点 | 测试端点（`C2` 断言守卫标记在场） |

### 2.1 它断言什么、**不**断言什么

```text
断言（**结构不变量**，与模型的选择无关）：
  · 每轮 `outcome` ∈ 闭集
  · ⭐ **写类 ⇒ 事件 +1；不写类 ⇒ 事件 +0**（"她说做了"与"真的写了"分开）
  · `trace` 五个读数在场
  · `no_operation` **无事实块**（`D29`）
  · **至少一轮真的走到写路径** 且 **至少一轮真的产出过事实块**（两个"非空分母"）
不断言：模型会不会建目标 —— 那会让门**看运气**（且是"为绿而抽样"的近亲）。
```

⚠️ **本门第一版有一条判据写错了**（实测当场红，已修）：我把"不写类"当成了"没有事实块"，
而 `D29` 的原话是「**无操作时**为 `undefined`」—— "无操作"是**具名 outcome `no_operation`**；
`query` / `clarify` **按设计就带事实块**。⇒ 教训：**判据的措辞要回到契约原文**。

## 3. `m10:long:live` —— 长轨迹真实链（**PASS 8/8**，200 轮）

```bash
pnpm with-test-model pnpm m10:long:live            # 缺省 200 轮
pnpm with-test-model pnpm m10:long:live --turns=500 # 长档（本轮未跑）
```

**话轮从冻结语料的 test split 确定性循环**（⚠️ 刻意**不**比金标：连续轨迹里状态是自己长出来的，
逐条金标在这里没有意义 —— 那是语义档的活）。

### 3.1 200 轮读数

| 项 | 读数 |
|---|---|
| 判据 | **8/8** |
| 轮次 | **200**（真模型） |
| outcome 分布 | `accepted×29` · `clarify×86` · `invalid_output×23` · `query×14` · `no_operation×46` · `transport_failed×2` |
| ⭐ 事件/trace 一致性 | **0 轮不一致** · trace 满 5 的有 **200/200** 轮 |
| ⭐ **不变量 ②** | **`rebuild` 逐字相同 = true**（重放事件 > 0）⇒ **投影是派生的**在 200 轮上**真的被验** |
| 写路径命中 | **29** 轮 |
| 时延 | min/mean/max = 1022 / 2735 / **20015** ms |
| 库 / 端点 | 同 `m10:smoke:live`（`C1`/`C2` 断言路径与标记） |

### 3.2 ⚠️ 发现 ①：**两次 `transport_failed`，且 max 时延 = 20015ms**

```text
它**正好**是 20 秒期限 ⇒ 这两次是**撞到期限被自己的超时闸掐掉**的。
⇒ 它们**如实记成 `transport_failed`**（不是隐藏、也不是当答错）—— 那是**护栏正常工作**。
⇒ 同时它**证实了**理解层期限那条注记：8s 太紧（实测最大 18.5s），而 **20s 的余量也很小**。
⇒ 要不要再抬（如 30s）是**延迟预算的权衡**（最坏情况的一轮等更久）：用户已授权"按实际情况延长"，
   本档只如实报分布，**不擅自再改**。
```

### 3.3 ⚠️ 发现 ②：`invalid_output` 率**不可互推**

```text
本档 200 轮：**23/200 = 11.5%**
语义档 420 次：**19/420 = 4.5%**
```

**合理解释**：长轨迹把语料原话喂进了**与它原本上文无关**的状态（状态是自己长出来的）
⇒ 模型产出的草案更容易结构不合法。
⇒ 这是**连续轨迹的性质，不是缺陷** —— 但它说明两个率**量的不是同一件事**，**不可互推**。
