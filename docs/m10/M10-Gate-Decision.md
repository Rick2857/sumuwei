## 1. 本里程碑**主张**什么（逐条有读数）

```text
① **有来源的目标能被建立、修订、暂停、恢复、取消与遗忘**，且每一次都经
   「有界输入 → 严格校验 → 放行口 → 写 → 投影」这条唯一链（`m10:test` 56/56 · `m10:source:verify` 43/43）。
② **跨会话她带着目标继续**：200/500 轮轨迹 + 跨会话重启（丢缓存 + 重读 + rebuild）
   ⇒ **投影是派生的**（不变量 ②）在 200 轮真模型轨迹上**逐字段一致**。
③ **条件变化时她合理停下**：前提失效 / 指代不唯一 / 能力不具备 ⇒ `clarify`（**不猜**）；
   "她说过要做"与"真的写了事件"**分开**（写类事件 +1 / 不写类 +0，200 轮 0 不一致）。
④ **每一个正式承诺都可解释、可核验、可修订**：承诺有 `commitmentCriterion`、
   兑现判定走确定性事件身份（**不依赖内容去重**）、假兑现与未兑现**分列**。
⑤ **人审**：逐案 70 张，一致率 74.3%，18 条分歧**全部裁定**（含我方两处语料缺陷的修法）。
⑥ **真实库从未被打开**：全部试验在沙箱或只读副本里；真实库 **1211 文件逐字未变**。
```
