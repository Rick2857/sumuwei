The QQ U1/G1 update on 2026-10-14 continues public main `d993322e4d61ff08943461fe4f3059d7824a2b9d`. It exports selected identity, room authorization, RLS, group admission, background attribution, and voice coexistence source, plus synthetic tests and setup documentation. Multi-user QQ is disabled by default and requires the operator's own accounts, allowed groups, credentials and migration decision. Migrations 0019–0022 are included; 0020 preserves the existing admin_jobs schema ordinal without publishing the management UI. Local activation records, actual group/account identifiers, runtime manifests, databases, dumps and private Git history remain excluded. The developer's successful migration or personal refusal review is not public runtime or semantic acceptance. Fresh checks are recorded in PUBLIC-VERIFICATION.md; real QQ/model/device use and zero-failure refusal certification remain outside those checks.

The following paragraphs describe the earlier releases and their boundaries at publication time; statements about planned multi-user work belong to those older releases. Current scope is described above and in [QQ-GROUPS.md](QQ-GROUPS.md).
